# Stage103 Related-Work And Novelty Review Plan

Date: 2026-06-30

## Goal

Resolve CB6 by grounding the novelty boundary in real related work and by
separating supported scoped systems claims from blocked broad novelty claims.

## Inputs

- Stage102 verified 2025/686 source anchors.
- Official/ePrint/DOI/DBLP/venue metadata for relevant amortized,
  batch/SIMD, common-mask, and post-686 bootstrapping work.
- Existing complete-SAB, noise, resource, and native perf evidence in `repro/`.

## Gates

- Every source in `source_verification.csv` must be real and externally
  identifiable.
- The novelty matrix must explicitly mark which broad claims are rejected.
- The allowed wording must stay scoped to the current implementation and
  evidence.

## Claim Policy

CB6 is considered resolved only by scoped wording. It is not resolved by
asserting broad novelty.
