## C 级：下界/不可能性类（认识论恰当形态）

下界定理（L2/LB/LB-F 下侧、S2）**不可能有直接实验**——其支撑 =
(i) 模型忠实性引理（五族实现逐一代码锚定为层式宽度 n）+ (ii)
**匹配的上界被实现且实测**（我方 (1+k/r)、686 (k+1)，主矩阵+r 选值
表）。"匹配下界"主张 = 定理 + 已实现上界，二者都有。F2 crossover =
实测常数 c_ks（尾声 3%）+ 精确算术；HYB 本体未跑（见证，非性能
主张）。A2 的 Θ(1/r) 极限 = 有限 r 数据 + 理论极限（论文措辞已如此）。

## 结论

**是**：全部性能/正确性/噪声主张由配对实测直接支撑（余量 0.00-0.3
bit / 零失配 / 声明容差内）；全部代数/语义主张由机器精确裁决；全部
下界/不可能性主张以认识论恰当的形态支撑（模型锚定 + 匹配上界实测），
边界在文中明示。无任何主张依赖未做实验的预期。
