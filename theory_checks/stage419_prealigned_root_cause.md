## 〇、一句话结论

**预对齐机制本身完全正确**：两条路径的终端旋转指数在全槽一致
（差 ≤ h+2 个 modswitch 舍入单位，256/256）。107/256 门失败是**探针

恰好落在值边界上，两条路径独立舍入的 ±1 单位差把 ~42% 槽翻了一级。

## 二、方向 A 闭式的机器裁决（任务 4 答案）

**实测定理（fine-LUT 仪器，指数提取唯一）**：

```
E(t) = −b̄[t] + Σ_{p≤t} ā[(t−p) mod n] − Σ_{p>t} ā[(t−p) mod n] + 257   (mod 2N)
```

- **oracle 路径**（mask ā_0, setup b̄_0）：h=6 全 256/256 槽、
  h=1 全 16/16 槽精确成立。
- **联合路径**（mask ā_c, setup b̄pa）：同样 256/256、16/16 精确成立。
- 即 **± 分裂 = 负循环卷积读取索引 (t−p) 的绕回符号**（p≤t 取 +），
  **与 probe bpa 修正项 corr 循环的符号约定逐项一致**（corr 中
  sign = −1 ⟺ (t−i) 绕回 ⟺ p>t）——bpa 的构造与管线站点和的代数
  结构精确对齐。
- **+257 为常数**（对路径、mask、h∈{1,6}、全部 272 槽不变；候选
  分解 256 = modswitch(po) + 系统性舍入 1，来源留作形式化义务）。
  因与 mask/路径无关，在 E_j−E_o 中**完全消去**——不影响预对齐。
- stage418 §七方向 B 形式 `−(b̄+Σ_{m<m*}ā)+Σ_{m≥m*}ā` 的**整体符号
  书写与实测相反**（其机器验证所验证的量与本次提取的终端指数符号
  约定不同）；方向 B 的否定性结论（末端校正不可公开计算）**不受
  影响**且与此不矛盾——预对齐不需要计算 ± 分裂：恒等式在代数层
  消去，只需 b' = b + (a'−a)⊗s（明文模拟中可算；真实系统中是 KS）。

## 三、107/256 根因（指数对、值翻）

失败现场 dump（细 LUT 下）：

```
MISM t=1  vs=12 vj=8  phase diff = −2^61.0   Eo=3584 Ej=3585   (ΔE=1)
MISM t=12 vs=-4 vj=0  phase diff = +2^61.0   Eo=2048 Ej=2050   (ΔE=2)
```

**相位差恒为整整一个 LUT 级（±2^61），而终端指数只差 ±1~3 个
modswitch 单位（h+2 门内全槽成立）。** 几何机制：

1. 800dfad 的 TV 按 256 系数一块分 8 级。经负循环镜像（TV2[u+2048]
   = −TV2[u]），值函数在 2N=4096 单位圆上有 **16 个 256-单位值槽**，
   而消息格宽 512 单位——LUT 分辨率**过细 2 倍**（16 槽 vs 8 值）。
2. setup 偏移 po = 2^60 = 256 单位使读取点 r = 512m + 256 = (2m+1)·256
   **恰在值槽边界上**。
3. 联合路径 setup 用 modswitch(b + d)、oracle 用 modswitch(b)，
   两者独立舍入，r 差 ±1 单位；~42%（107/256）的槽联合侧落到
   左邻槽 → 恰差一级（±2^61）。E 一致、值翻——与 dump 逐点吻合。

**修复**：TV 值按 512-单位跨度（标准 2^prec 级 / 2N 圆；系数空间
= 256-块成对）构造，读取点距任一值边界 256 单位，对 ±(h+2) 单位
路径舍入差免疫。旧细网格保留为 `SAB_PA_LUT_FINE=1` 追踪仪器
（指数提取唯一，用于 §二 闭式核验）。

对 c5816dc 诊断的修正："ramp TV 放大舍入差"方向反了——ramp 无值
跳变，恰好**隐藏**网格问题（stage417 因此 PASS）；任何带值跳变的
2× 过细 LUT 都会触发刃锋；标准 LUT 天然免疫。

## 五、对真实系统设计的含义

- 真实预对齐中 b'_l 是 KS 密文（噪声实现与分离路径不同），两路径
  modswitch 舍入差不可避免（±(h+2) 单位 @2N 刻度）；**LUT 必须按
  标准约定（值跨度 = 2N/2^prec 单位）构建**——值边界距读取点
  2N/2^(prec+1) 单位，舍入预算天然免疫。这是把"实验佐证"升级为
  "设计约束"的一条：LUT 网格分辨率 ≥ 2×(h+2) 舍入跨度。
- 复跑命令（WSL，build_wsl/pa2 同构建）：
  `SAB_PA_R1=... ./build_wsl/pa2/probe_prealigned2`；
  追踪：`SAB_PA_TRACE=1 [SAB_PA_LUT_FINE=1]`。

## 七、WS-8 补遗：常数定律的参数化验证与定理重述（2026-09-11）

**实测定理（升级版，SAB_PA_LUT_FINE 仪器，指数提取唯一）**：

```
E(t) = −b̄[t] + Σ_{p≤t} ā[(t−p) mod n] − Σ_{p>t} ā[(t−p) mod n]
       + 2^(log₂(2N)−prec−1) + 1   (mod 2N)
```

四参数点 × oracle/联合双路径 × 256 槽**全部精确成立**：

| out_N | prec | C 预测 | 实测匹配 |
|---|---|---|---|
| 2048 | 3 | 257 | o,j 各 256/256 |
| 4096 | 3 | 513 | o,j 各 256/256 |
| 2048 | 5 | 65 | o,j 各 256/256 |
| 1024 | 2 | 257 | o,j 各 256/256 |

**分解**：C = modswitch(po) + 1。前一项把 setup 偏移 po 从 −b̄ 中
对消——等价重述 **E(t) ≈ −modswitch(φ[t]) + 1**（φ = b − a⊗s 输入
相位；精确到逐站 modswitch 舍入），即终端指数 = 负化消息相位 +
一个结构单位。后一项 +1 与 h（1 与 6 均验证）、n、mask、参数点
无关——机制解释：蝶形跨界内容的 σ₋₁ 条件补偿的净单项式因子
（stage398 S1 语义分解的推论；每内容恰一次跨界 → 净 +1 指数单位）。

**诚实边界（按 6r 零猜测纪律）**：定律本身 4 点全槽机器验证 ✓；
+1 的 S1 机制解释为**待形式化假设**（需与 stage398 M0 检查器对接
做逐轨迹代数推导）；语义上 +1 单位 = 半个系数位移 ≪ 2^prec 量化格，
被任何标准 LUT 吸收，不影响正确性主张。
