==============================================================================
D. 686 asymptotic-regime check (their Sec 6.1: h = O(lambda/log lambda))
==============================================================================
Entropy H(h) = h*log2(e*n*w/h). 686's aggressive regime n=lam*log^k(lam),
h = c*lam/log2(lam) gives H = c*(k+1)*lam*loglog(lam)/log2(lam) = o(lam),
hence lambda-bit security FAILS asymptotically for ANY constant c (tier 2/3).
lam=128 k=0: h=2lam/log2(lam)= 36.6 n=   128 -> H= 142.04 (< 2*lam FAILS tier3)
lam=128 k=1: h=2lam/log2(lam)= 36.6 n=   256 -> H= 182.18 (< 2*lam FAILS tier3)
lam=128 k=2: h=2lam/log2(lam)= 36.6 n=   512 -> H= 220.09 (< 2*lam FAILS tier3)
lam=256 k=0: h=2lam/log2(lam)= 64.0 n=   256 -> H= 267.57 (< 2*lam FAILS tier3)
lam=256 k=1: h=2lam/log2(lam)= 64.0 n=   512 -> H= 338.07 (< 2*lam FAILS tier3)
lam=256 k=2: h=2lam/log2(lam)= 64.0 n=  1024 -> H= 405.10 (< 2*lam FAILS tier3)
