686 自己的安全口径（§7.1 原文）：Lattice Estimator（默认归约模型）全部攻击的最小值，**外加** CHHS19 的 dual-hybrid+MITM（对稀疏密钥常更强），**再减去 δ**（拒绝采样熵损失，Appendix C 蒙特卡洛估计）。δ 机制：keygen 要求相邻非零位置间距 |d[i]| < B（B≈n/h），接受概率 ≈ 2^−δ，等效密钥空间缩小 2^δ 倍。

686 的渐近主张（§6.1）：噪声开销 Õ(√(N·h·log(n/h)))、摊销时间 O(h·log(n/h))；取 N,n,h ∈ O(λ) 得时间 O(λ)；并明确提出激进档 **h ∈ O(λ/log λ), n ∈ O(λ·log^k λ)** 可把时间降到 o(λ) 而噪声仍 Õ(λ)。§4.3 将证明该激进档与 λ-bit 安全**渐近不相容**（这是本文新结论之一）。

### 2.1 A5（CRYPTO'26 旋转混合）机理与代价公式

这是当前对 686 密钥最强的攻击，也是本仓 B 线 +15bit 硬化的依据，机制须精确陈述：

1. **系数等距**：2 的幂分圆环中，乘单项式 X^j（0≤j<n）= 系数向量负循环旋转（带符号置换），保持密钥/误差分布不变 [279 Lemma 16]。
2. **派生样本**：(a, b=As+e) ⟹ (a, X^j b) = 同一 a 下、密钥为 X^j s 的合法 MLWE 样本 [279 Lemma 11：位移分布与 j 无关]。
3. **混合攻击中的复用**：primal hybrid 的昂贵离线部分（BKZ 基）只依赖 a 的固定列；旋转族 {X^j s} 全部与同一基兼容 ⟹ 猜测集从 S_plain 扩为 S = T × S_plain，T = {X^j}。
4. **命中概率放大** [279 Lemma 18，扩展 May–Silverman'01 的独立性启发]：

   > |S| = n·|S_plain|，Pr[s ∈ S] ≈ 1 − (1−p(h_g))^n，其中 p(h_g) = Σ_{i≤h_g} C(n−ζ,h−i)C(ζ,i) / C(n,h)。

5. **渐近收益** [279 Remark 4]：命中概率 p → 1−(1−p)^n ≈ n·p，即环结构带来 **O(n)，至多 log₂ n bit** 的安全损失（归约主导极限；实际最优平衡下略少）。
6. **代价**：T_BKZ(β,d) + √|S|·T_NP(d)（Heuristic 2 非平衡分解下取平方根），成功概率 p_NP·p_mitm·Pr[s∈S] [279 Lemmas 12–15]。

**A5 与 A6 的本质差异**（279 Table 4）：C&C 需要全维归约且猜测维绑定 Z 形基形状；A5 在降维格上做、猜测维自由选择——因此 A5 与标准估计框架对齐且更高效。

## 3. 可证明的界（Q2 第一部分）

记 H(n,h,w) = log₂C(n,h) + h·log₂w 为固定重量密钥空间的熵（binary w=1，ternary w=2）。

**引理 L1（熵）[P]**：H(n,h,w) = log₂C(n,h) + h·log₂w；当 h ≪ n 时 H = h·log₂(en·w/h) − O(h²/n)。
数值口径：脚本 §C 验证近似式在 686 参数处误差 +3.7~+4.5 bit（近似偏大，用于方向性论证足够；精确值全部用 lgamma 计算）。

**引理 L2（旋转轨道缩放）[P]**：设 s 均匀采自固定重量密钥空间，群 T = {X^j, 0≤j<n}（阶 n）按乘法作用于密钥空间且保持分布。则该作用以概率 1−negl(n,h) 自由（无非平凡稳定子），故密钥空间可划分为大小恰为 n 的轨道，代表元商空间大小 = C(n,h)·w^h/n。
证明概要：X^j s = s（某 0<j<n）要求支撑在指标环 Z_n 上对旋转 j 不变，即支撑为若干完整 j-轨道之并（每轨道长 n/gcd(n,j) ≥ 2）；此类支撑数量 ≤ Σ_d n·C(n/d, h/d)·(w')^{h} 量级，占全体比例 ≤ n·2^{−Ω(h)}。带符号解（−X^j s = X^{j'} s 等）需支撑对 n/2 位移反称，同类计数仍是 negl。∎
（此引理给出 A5 收益的**信息论天花板**：无论攻击多聪明，旋转对称性最多贡献 log₂ n bit——279 Table 1 中 h=128,n=2^17 的实测差距 14.8 ≈ log₂(2^17)=17 内侧，与天花板一致。）

**引理 L3（三档安全上界）**：对上述密钥的方案，其安全级 λ 满足：

| 档 | 上界 | 地位 |
|---|---|---|
| T1 | λ ≤ H − log₂n − δ | [P]：对商空间穷举即得攻击（A1+A5 的平凡组合） |
| T2 | λ ≤ (H − δ)/2 + O(1) | [H]：May CRYPTO'21 MITM（算法确定存在，成功分析依赖分解启发式） |
| T3 | λ ≤ (H − log₂n − δ)/2 + O(1) | [H]：279 Heuristic 2 旋转非平衡分解（其 Fig.1 数值验证与模拟吻合） |

注意 δ 的记账：δ 先从 H 中减去（密钥空间缩小 2^δ），再进入各档；这是对防御方较不利的保守处理（§7 O1 讨论 MITM 是否还能利用 B-约束的结构）。

**推论（δ 与旋转损失可加）**：拒绝采样熵损失与旋转轨道损失作用在不同自由度上（取值约束 vs 支撑位置对称），在 T3 档同时计入。

## 4. λ–h 关系（Q3：最终定律与"1/4 次方"澄清）

### 4.1 设计约束（必要条件）

要（在 T3 档下）保住 λ-bit 目标，必须

> **log₂C(n,h) + h·log₂w − log₂n − δ ≥ 2λ**　　（T3；T1 档将右端换成 λ）

用 L1 渐近式解出最小重量：

> **h·log₂(e·n·w/h) ≈ 2λ + log₂n + δ ⟹ h*(λ,n) = Θ((2λ + log₂n)/log₂(n·w/h))**

精确数值（脚本 §B，λ=128，δ=0）：

| n | binary h*(T1/T2/T3) | ternary h*(T1/T2/T3) | 686 实际取值 |
|---:|---|---|---|
| 2048 | 18 / 36 / **38** | 15 / 31 / **33** | B1=39（+1 余量）；T1=35（+2） |
| 4096 | 16 / 31 / **33** | 14 / 27 / **29** | B3=33、B5=34、T3=30、T5=32 |
| 8192 | 14 / 27 / **29** | 13 / 24 / **26** | **B4=27、B6=28；T4=25（<26！）** |

### 4.2 渐近形态

- **n = Θ(λ)**（FHE 常规档）：log₂(en·w/h) = Θ(1) ⟹ h* = Θ(λ)，686 取 h∈O(λ) 与安全一致。
- **n = λ·log^k λ**（686 激进档）：h* ≈ 2λ/(log₂λ + k·log₂log₂λ)。**渐近命题：若 h·log₂(en·w/h) = o(λ)，则 λ-bit 安全必然失效**——T1 档（穷举 2^{H−δ} = 2^{o(λ)}）此结论为 [P]；经 MITM（T2/T3 档）攻击在 2^{(H−δ)/2} = 2^{o(λ)} 内完成，结论为 [H]。686 §6.1 的 "h ∈ O(λ/log λ) ⟹ 摊销时间 o(λ)" 中，常数 c < 2 的任何取法在渐近下违反安全（c=2λ/log₂λ 恰是 T3 最小重量的量级）。686 的具体参数（λ=128）目前勉强过线（见 §5），但其渐近表述未含此约束——这是论文 §7（安全节）可以引用的批判性观察。
- **格侧约束**（与本组合侧独立并存）：core-SVP/MATZOV 口径下 n ≥ β_min ≈ λ/0.292（筛法），且稀疏性通过 hybrid 的猜测维反噬格侧——A5 的完整最优无闭式，两边界由 §5 的 [E] 档数值锚定。

### 4.3 "λ 的 1/4 次方"的澄清（对任务原始表述的修正）

原始意识流表述"稀疏密钥与 λ 的关系比如是 λ 的四分之一次方"需要修正。次方结构在四个不同位置合法出现，但**没有一个是"h ∝ λ^{1/4}"或"λ ∝ h^{1/4}"**：

| 真实的次方 | 出处 | 正确形态 |
|---|---|---|
| 1/2（时间） | MITM/生日碰撞（A2/A4/A5） | 攻击时间 ≈ 2^{H_eff/2} ⟹ h ≈ 2λ/log(n/h) |
| 1/4（内存） | Schroeppel–Shamir | 时间 2^{H/2} 时内存可压到 2^{H/4}；是**空间**界不是密钥–λ 关系 |
| 1/3（量子） | BHT 量子碰撞 | 时间 2^{H/3}（Grover 施于穷举则 2^{H/2}）；本文未含量子记账（开放项 O4） |
| 1/2（噪声） | 686 定理 | 噪声开销 Õ(√(N·h·log(n/h)))——同一 λ 同时进入噪声（√ 内）与熵（线性）两个约束 |

**正确的一句话定律**：在 2 的幂分圆环上，固定重量 h 的稀疏密钥对旋转强化混合攻击的安全上界为

> **λ_max(n,h,w,δ) = (log₂C(n,h) + h·log₂w − log₂n − δ)/2 + O(1)**　　[T3 档]

等价地，**必要重量 h 满足 h·log₂(en·w/h) ≥ 2λ + log₂n + δ**；渐近上 h = Θ(λ/log λ)（n 取 λ·polylog 时）或 Θ(λ)（n = Θ(λ) 时）。若把"关系"强行写成幂律，最接近的合法表述是 **λ = Θ(h·log(n/h))**（线性于 h、对数于稀疏度），而非任何固定分数次幂。

## 6. 与本仓预检（stage356"保守插值 15/9.2 bit"）的交叉验证

本仓 B 线现行做法（`docs/stage356_results_and_roadmap.md` §4）：input 侧密度 ≤0.05 → 差距取满 15 bit；output 侧 0.25 → 9.2 bit；工程对策 σ_out+15（aut-KS 联动）已实证闭环。本分析给出其第一性原理核对：

1. **15 bit 的来源与适用范围**：279 全表（含 n=2^17 行）最大差距 14.8 ≈ log₂(2^17)。旋转增量有两个参照系：**对任意固定混合配置**，命中概率放大 ×n 给出至多 log₂n 的安全损失（279 Remark 4，归约主导极限；L2 轨道天花板同值）；**在本文 T3 端点**（商空间上的纯 MITM），log₂n 先进入熵再开方，只兑现 (log₂n)/2 = 5.5 bit。279 对 686 实测的旋转增量 9.9–10.5 bit 落在两者之间（混合攻击的最优平衡点介于归约主导与 MITM 主导之间），三者自洽。对 n=2048 的密钥，一切口径的旋转损失均 ≤ 天花板 **11.0 bit** —— 15 是全表 sup（n=2^17 行），对本仓实际密钥**保守 ≥4 bit**。
2. **9.2 bit（密度 0.25，FBS1 h=512）**：≤ 天花板 11.0 ✓ 方向一致；FBS/RPC 组合熵 ≫ 声明（§5.1），其约束在格侧，密度高时旋转优势远小于天花板（279 Table 1 h=192,n=2^11 行差距仅 1.4 bit 同向佐证）。9.2 偏保守，安全。
3. **结论**：现行 +15 bit σ 硬化**覆盖** n=2048 密钥的旋转损失天花板且留 ≥4 bit 余量；stage356 的"±2bit 交叉验证"目标达成（15 vs 天花板 11 差 4 bit，方向为保守侧，可解释、非误差）。

## 7. 判定汇总与开放项

**判定**（全部基于 §5 可追溯数字）：

1. 686 的 B4、B6、T4 三个密钥在 [H] 档纯组合上界下已**低于其声明安全级**（−6.2/−4.7/−2.1 bit）；B1 贴线（−0.8）。
2. 在 [E] 档（CRYPTO'26 旋转混合全模型）下，T1–T6 全部**低于声明** 6.7–10.5 bit；本仓 +15bit 硬化（B 线）在 n=2048 档有 ≥4 bit 裕量，方向与幅度均成立。
3. λ–h 定律：**λ_max = (log₂C(n,h) + h·log₂w − log₂n − δ)/2 + O(1)**；必要重量 **h·log₂(en·w/h) ≥ 2λ + log₂n + δ**；不存在 λ^{1/4} 型幂律（§4.3 表）。
4. 686 §6.1 的 h ∈ O(λ/log λ) 渐近档在常数 <2 时与 λ-bit 安全渐近矛盾 [P]（§4.2 命题）。

**开放项**：

- **O1** δ 叠加：与 279 作者确认其估计器是否建模 686 拒绝采样；若否，T1 组合估计降至 ~109 bit。
- **O2** B 系（binary）密钥的旋转混合全估计：用 279 的估计器例程（其基于 lattice-estimator commit 1e28f66 的扩展）跑 B1–B6，把 §5.1 的 T3 缺口换成 [E] 档数值。B4 预期最低。
- **O3** guess-one-of-many（Glaser–May–Nowakowski）：279 Remark 5 明示旋转段若按完全独立建模可再降——目前不计入，作风险储备。
- **O4** 量子记账：Grover/BHT 对 T1–T3 档的修正（预期再 −H/6 量级），论文安全节需一句话声明口径。
- **O5** ternary 的 ±X^j 全等距群（2n 阶）比 279 使用的 n 阶群多 1 bit 天花板——数值上被 15bit 保守界覆盖。

**对论文（P1 任务"279 精确模型替换保守插值"）的直接交付**：§4.1 公式 + §5.1/5.2 表 + §6 交叉验证即为安全节的升级素材；绝对数值引用 279 Table 8（[E] 档），上界结构引用本文 L1–L3（[P]/[H] 档），逐条可审计。
