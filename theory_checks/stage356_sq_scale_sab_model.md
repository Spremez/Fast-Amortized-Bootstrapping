# stage356 理论模型: 尺度量化外积的噪声账本与 279 安全吸收

参照: eprint 2025/1711 Lemma 3.4（∆ = Q²/T 抑制）、eprint 2026/279（稀疏 RLWE 环同构混合攻击差）、本仓库 `docs/cost_model.md`（外积计数）。

## 1. 记号与契约

- torus T = 2^64，u64 存储；盲旋转维持 in_N 个 TRLWE slot。
- **stock 外积**（`trgsw_mul_trlwe_DFT`, l=1, Bg=23）: digit = round(c/2^{41}) ∈ ±2^{22}，out = digit·C mod T。
- **SQ 外积**（`sab_sq_external_product`, Bg_bit=q）: 累加器存储 s.t. torus 值 v 的存储 = round(v·2^q) ∈ ±2^{q-1}；选择子消息挂在原始尺度 2^{64-q}（`trgsw_monomial_sample` 现成契约）；out = round((C⋆c mod T)/2^{64-q})。
- DFT 信封: `execute_reverse_torus64` 按有符号原值转 double，`execute_direct_torus64` 以 mod-2^64 截断回收（D4 语义探针独立验证过该契约），故 `polynomial_mul_DFT` = 负循环整数卷积 mod 2^64。
- 消息路径精确性: (bit·2^{64-q})⋆c 后 >> (64-q) = bit·c，**无舍入误差**（乘积 ≤ 2^{63} 不回绕）。

## 2. 每外积噪声账本（torus 单位，rms，N=2048，2 行卷积）

| 项 | stock (q'=23) | SQ(q) | 说明 |
|---|---|---|---|
| 量化/舍入 | 2^{-24}（digit 分解残差） | 2^{-q-1}（重缩放舍入） | 每外积 |
| 密钥噪声（σ 项） | σ·2^{27.1} | σ·2^{q+3.5} | e_int·operand_rms·√N·2^{64-q} / 2^{64}；两式在 q=23 处一致（2^{26.5}≈2^{27.1}，digit 均值因子差异） |
| FFT 精度 | ~2^{-26.5} | 2^{2q-51} | 点乘相对 2^{-53} |
| NCMUX 自同构 KS | σ_ks 校准的 ~2^{-22} 量级 | 同左（升/降尺度精确，KS 语义不变） | 计数 (2^ρ−1)(h+1) |

SET_2_3_2048（R = ρ(h+1) = 280 轮，ρ=7，预算 2^{-4}）:

- stock: σ 项合计 σ·2^{31.2}；σ = 2^{-50} → 2^{-18.8} ✓；σ 上调 15 bit（2^{-35}）→ 2^{-3.8}，**吃满预算无余量（尾部失效）**。
- SQ(q=16): σ 项合计 σ·2^{23.6}；σ = 2^{-50} → 2^{-26.4}；σ = 2^{-35} → 2^{-11.4} ✓ 余量 2^7。
- SQ 舍入项: 2^{-17}·√280 ≈ 2^{-14.7}（σ 无关，成为 SQ 的新主导项之一）；KS 层 ~2^{-10.6} 两者共有的地板。
- **σ 吸收容量差 = 2(23−q) bit**（q=16 → +14 bit），与上表系数差 2^{31.2−23.6} 一致。

结论: 279 的保守 15 bit 安全差经由 σ 上调恢复时，stock 方案处于噪声预算边缘（且需同时保住 LUT/尾部余量），SQ(q≤16) 以 σ 项近可忽略的方式完整吸收；更高消息精度集合受 q ≥ b_prec+10 下限约束，残余差值由 h 上调补足（预检表给出逐集合判定）。

**边界条件（σ-硬化实验实测）**: 上述吸收只覆盖外积乘积路径。NCMUX aut-KS 与 packing KS 的噪声 ∝ σ·2^{Bg_ks}，随 σ 线性放大（实测 σ_out+15: 每 slot ~140 次 aut-KS 累计 ≈ 2^{-1.9}，超预算），故完整硬化参数集需联动细化 KS 分解基（Bg_ks↓ / l↑，密钥量小）；σ 单旋钮对 SQ 与 stock 同时失效（run_wsl_q16_sigma15.log）。

## 3. 核计数（每 CMUX/外积）

| 步骤 | stock | SQ |
|---|---|---|
| 系数环 | sub 2N + 分解 2×(加/移/掩) + add 2N | sub 2N + 舍入右移 2N + add 2N |
| FFT | 2 fwd + 2 inv | 2 fwd + 2 inv |
| 点乘 | 4 | 4 |
| NCMUX 附加 | — | 升/降尺度 2×2N（占比 (2^ρ−1)/ρN ≈ 0.9%） |

外积总数不变: (h+1)·ρ·N（二值）。预期核速度持平（分解环与舍入环同量级），以同二进制 scalar 对照 + 10 次重复计时实测；任何 >5% 的退化按机制卡回退条款处理。

## 4. 安全预检（相对模型，scripts/sq_security_preflight_279.py）

- 基线: 686 设计安全级（默认 128 bit）。
- 279 差: 密度插值（h/n ≤ 0.05 → 15 bit；≥ 0.5 → 2 bit；线性内插）。
- σ 弹性区间 0.5–1.0 bit/log2σ 显式参数化；SQ 吸收容量 = 2·(23−q)，q 下限 b_prec+10。
- 判定（保守 s=0.5）: output 侧（密度 0.25，差 9.2 bit）全部可吸收；input 侧低精度集合 optimistic；b≥7 集合部分吸收需 h 补。绝对值模型待 lattice-estimator + 279 全文公式接入后替换（脚本头部已声明）。
