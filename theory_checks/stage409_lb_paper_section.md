## 5. Complexity and Lower Bounds（正文）

### 5.0 计算模型 C0 与双代价口径

**类 C0（单项式累积盲旋转）**。算法处理 h+1 个稀疏间隙相位：每相位
按秘密间隙值 v_t ∈ [1, 2^ρ) 移动 n 个槽密文的内容（SHIFT_{n,ρ}），
相位间施加槽依赖的公开/密文选择运算，终态每槽 = X^{−φ_t}·TV（单项
式累积）。显式假设（全部进入定理陈述）：

- **H1（单项式累积范式）**：输出相位 = 单项式作用累积（无相位提取）；
- **H2（密钥束规模）**：选择钥总预算 O((h+1)·ρ·s₀(λ))（量化形式见
  引理 5.4；686 同阶）；
- **H2'（层式宽度 n）**：电路分层、每层恰 n 门、级间乒乓（模型忠实性
  引理 5.0：686/TFHE/FHEW/BatchBoot/本工作逐一核对）；
- **H3（代价口径）**：单门成本 M_lin = Θ(N)（系数写）或
  M_fft = Θ(N log N)（N 维负循环卷积），γ(N) ∈ {N, N log N}；
- **H5（拓扑均匀性）**：电路拓扑与秘密值无关（标准保密条件）。

**双口径**：M_lin 适用于计数论断（密文分量数），M_fft 适用于实现
论断（我们的全部核为 FFT 卷积）。两口径下界的 Γ 因子分别取 N 与
N log N；上界实现以 M_fft 达匹配。

### 5.1 每相位下界（三层结构）

**定理 5.1（弱式，无条件：任意 DAG + H5）**。SHIFT_{n,ρ} 的任一
正确电路每相位 ≥ n 门，且每输出的反向锥 ≥ min(2^ρ, n) − 1 门。
（触碰引理：直通/合线都与正确性矛盾；锥 = 像集 |S(y_j)| ≥ |V| 的
归纳。）

**定理 5.2（强式，主形式：层式 H2' + H5）**。层式宽度 n、元数 a
的电路每相位 ≥ n·⌈log_a min(2^ρ, n)⌉ 门。（可达性倍增 |S| ≤ a^ℓ
× 层数下界 × 每层 n 门。）

**引理 5.4（密钥预算-元数，H2 的作用形式）**。元数 a 的门钥体积
≥ c₀·a·s₀(λ)，且逐相位选择容量 = (ρ/log₂a) 位 ⟹ 预算 O(ρ·s₀)
迫使 a = O(1)（a/log₂a ≥ 1 且 a ≥ 4 递增：大元数反而费钥）⟹
⌈log_a⌉ = Θ(ρ)。686 与本工作取 a = 2。

**引理 5.5（相位独立性 L4，绑定 H1）**。h+1 相位不可合并（合并净
移位 ≡ 0 (mod n)；中间槽位秘密依赖；相位提取 = 范式外构造且自身
循环依赖）。

**定理 5.6（组装 LB）**。H1+H2+H2'+H5 下，每消息
  T ≥ (h+1)·n·Θ(ρ)·γ(N)·ℓ^{-1}（ℓ = gadget 深度归一）。
**一般 DAG 的 n·ρ 强形式：开放**（如实注记：层式覆盖全部已知实现，
非层式优势为电路理论开放问题，正面表述）。

### 5.2 前沿定理 LB-F（三制式）

**定理 5.7（LB-F）**。按密钥预算分三制式，每制式匹配上下界：

**F1（标准钥束 K = O((h+1)ρs₀)，与 686 同预算）**：下界 = 定理 5.6；
上界（本工作）= T(r) = (h+1)·ρ·ℓ·N logN·(1 + k/r)。
**匹配至行常数 (1+k/r) → 1（r→∞）；686 为 (k+1)。**

**F2（线性钥 K = Θ((h+1)·n·N)）**：下界 = 触碰（n 门/相位，与钥
无关）；上界 = HYB 见证（大环单项式移动 + 抽取/扭转/packing-KS
重打包）：T = (h+1)(1 + log n/log N + c_ks)·ℓ·N logN·(1+k/r)，
c_ks ≈ 9（尾声实测标定）。**HYB 胜 F1 ⟺ ρ > 1 + log n/log N + c_ks
（crossover ρ* ≈ 11：n > 2^17 @ h=42 才胜——实用全域恒慢，渐近
Θ(ρ) 快；噪声账 = 引理 N-HYB，与 F1 同阶，无新噪声类）。**

**F3（平方钥 K = Θ(n(h+1)s₀n)）**：per-(槽,相位) 预加密选择子达
信息地板 T = Θ((h+1)·ℓ·N logN)（下界 = 触碰地板；per-行选择子
密钥 Θ(n²) 达每消息单 EP）。**对称开放（对 686 同样可用，非分离
轴，推论 S3'）；实用参数密钥膨胀 n/ρ ≈ 341× 不可行。**

**推论 5.8（本工作复杂度主张，定稿措辞）**。标准钥束制式（F1）下，
本工作匹配类下界且行常数最优 (1+k/r)→1；批处理轴每消息代价
Θ(1/r) 递降至 686 的 1/(k+1)。离开 F1 的权衡（F2/F3）对类内全部
方案对称开放——它们界定模型而非任何单方优势。

### 5.3 匹配侧：摊销定律（上界）

**定理 5.9（A1 摊销定律）**。r-lane（r-LUT ⊗ r-input 可组合，
HT-10）每消息 T_msg(r) = (h+1)·ρ·ℓ·N logN·(1 + k/r)（+ r-input
的 sub_a 线性项）。**定理 5.10（A2 批处理渐近）**：
T_msg(r)/T(686) = (1+k/r)/(k+1) = Θ(1/r) → 1/(k+1)。**定理 5.11
（A3 匹配）**：以常数 1 + o(1) 匹配定理 5.6（686 以 k+1 匹配）。

### 5.4 类成员覆盖

**定理 5.12（CM）**。全部已知 ≥128-bit 声称的摊销 FHEW 式构造
（686 / TFHE 系 / FHEW 系 / BatchBoot / 本工作全族）均为 C0 成员
（CM-1..5 显式映射：选择门对应、H1-H5 逐条核验；TFHE/FHEW 为
宽度 1 退化成员）。下界适用于全部；"匹配 + 最优常数"为同界比较。
