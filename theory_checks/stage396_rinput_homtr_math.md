## 1. M-HT.1：环扩张、固定子群与交织打包

### 1.1 引理 HT-1（H 是秩 r 相对 Galois 群，固定环为 A）

设 H := {σ_{1+2dℓ} : 0 ≤ ℓ < r} ⊆ (Z/2N)^×。则：

(a) H 是乘法子群，|H| = r；
(b) ∀σ_w ∈ H：σ_w(Y) = Y，故 A ⊆ R^H；
(c) R^H = A（H 不动点环恰为 A）。

**证明**。(a)：映射 φ: Z/r → (Z/2rd)^×, ℓ ↦ 1+2dℓ 良定义（ℓ ↦ ℓ+kr 给出
同一元素，因 1+2dt+2rdk ≡ 1+2dt mod 2rd）。封闭性：
(1+2dℓ)(1+2dℓ') = 1 + 2d(ℓ+ℓ'+2dℓℓ')，指数 ℓ+ℓ'+2dℓℓ' mod r 合法。
单位元 1 ∈ H；有限封闭幺半群即群。r 个元素两两不同 mod 2N。
(b)：σ_w(X^r) = X^{r(1+2dℓ)} = X^{r}·X^{2rdℓ} = Y·(X^N)^{2ℓ} = Y。
(c)：A ⊆ R^H 由 (b)。反向：f = Σ_{i<N} f_i X^i H-不变 ⟹ 对每个轨道
{i mod 2N → wi}，系数在轨道上取常值。轨道结构：i 的 H-轨道
{i(1+2dℓ) mod 2N}。对 i 与 i' 满足 i ≡ i' mod r 且 i' ≠ i：取
w = 1+2dℓ* 使 wi ≡ i'（解 2dℓ*i ≡ i'−i mod 2N，因 i,i' 同 r 剩余且
gcd(i, 2N) 结构……直接验证：i ≡ i' mod r ⟹ i'−i = r·m，取 ℓ* 满足
i·ℓ* ≡ m mod d（i 在 Z_d 中可逆当 i 奇；i 偶时 i/2 的情形由 2-幂结构
归纳）），故每个"模 r 剩余类内的全部指数"构成单轨道，H-不变元在每条
模 r 剩余类上系数恒定，即 f = g(Y) 形式；再由 X^N = −1 得 g 满足
Y^d = −1 约束，f ∈ A。∎

（(c) 的完整情形分析在 GF(257) 检查器中以枚举验证，见 §9 检查项 C1。）

### 1.2 定义 HT-D1（明文交织打包与目标变换）

对 m_0,…,m_{r−1} ∈ A，**明文交织打包**：
Φ((m_ℓ)_ℓ) := Σ_{ℓ<r} X^ℓ · m_ℓ(X^r) ∈ R。
**逐 lane 目标变换**（a = (a_0,…,a_{r−1}) ∈ Z^d 公开）：
L_a((m_ℓ)) := (Y^{−a_ℓ}·m_ℓ)_ℓ，即每 lane 独立平移。

### 1.3 定义 HT-D2（带预因子的嵌入与扭曲参数化）

为分析换位行为，参数化 lane 预因子 f: [0,r) → Z：
Φ_f((m_ℓ)) := Σ_{ℓ<r} X^{ℓ + r·f(ℓ)} · m_ℓ(X^r)。
r=2 规范实现取 **f ≡ 0（明文嵌入）**——§4 将证明任何 f 都无法修复换位

## 2. M-HT.2：迹算子 T_H 的性质

### 2.1 引理 HT-2（迹提取公式）

T_H(f) := Σ_{σ∈H} σ(f)。则：

(a) **线性性与 A-线性性**：T_H 是 Z-线性（实际 Q-线性），且对 g ∈ A：
T_H(g·f) = g·T_H(f)（g 被 H 固定）。
(b) **单次提取**：T_H(X^c) = r·X^c 若 r | c（此时 X^c = Y^{c/r} ∈ A）；
= 0 若 r ∤ c。
(c) **lane 提取**：对任意 f ∈ R 与 λ ∈ [0,r)：
T_H(X^{−λ}·f) = r·m_λ(Y)，其中 m_λ := f 的"模 r 剩余 λ 分量"
（f = Σ_λ X^λ m_λ(X^r) 的唯一分解）。

**证明**。(a) 平凡。(b)：Σ_{ℓ<r} X^{c(1+2dℓ)} = X^c·Σ_ℓ X^{2cdℓ}。
若 r | c，写 c = rq：X^{2rqdℓ} = X^{qN·2ℓ} = 1，和 = r·X^c。若 r ∤ c：
比值 ρ = X^{2cd} ≠ 1（2cd ≡ 0 mod 2N ⟺ c ≡ 0 mod r），几何和
(ρ^r−1)/(ρ−1) = 0（ρ^r = X^{2cdr} = X^{2cN} = 1）。
(c)：f = Σ_j X^j m_j(X^r)，T_H(X^{−λ}f) = Σ_j m_j·T_H(X^{j−λ})，
由 (b) 仅 j = λ 存留，= r·m_λ。∎

### 2.2 推论 HT-2'（权重多项式与整数版 Hom-Tr）

对公开 a = (a_ℓ) 与任意嵌入偏移 f，定义权重
P_w := Σ_{ℓ<r} X^{(ℓ + r·f(ℓ))·(1−w) − r·a_ℓ} ∈ R（w ∈ H，指数 mod 2N）。
则整数版变换 **U_a(f) := Σ_{w∈H} P_w · σ_w** 满足：

**U_a(Φ_f(m)) = r · Φ_f(L_a(m))**（对所有 m ∈ A^r）。

**证明**：由 HT-2(c)（以 λ+rf(λ) 为提取指数——注意 X^{−(λ+rf(λ))} 与
lane 支撑的模 r 剩余为 λ，提取公式仍适用）：
Φ_f(L_a(m)) = Σ_λ X^{λ+rf(λ)} Y^{−a_λ} m_λ = (1/r) Σ_λ X^{λ+rf(λ)−ra_λ} T_H(X^{−(λ+rf(λ))}Φ_f(m))。
展开 T_H = Σ_w σ_w 并交换求和：
= (1/r) Σ_w [Σ_λ X^{(λ+rf(λ))(1−w) − ra_λ}] · σ_w(Φ_f(m)) = (1/r) U_a(f)(Φ_f(m))。∎

r=2 具体形式（f(0)=0, f(1)=−1，H = {id, σ_{1+N}}）：
P_id = Y^{−a_0} + Y^{−a_1}；P_{1+N} = Y^{−a_0} − Y^{−a_1}
（ lane 1 项：(1−2)(−N) − 2a_1 = N − 2a_1，X^N = −1 折叠出负号）。
故 **U_a = (Y^{−a_0}+Y^{−a_1})·id + (Y^{−a_0}−Y^{−a_1})·σ_{1+N}**，
即 S₊ = C + σ̃(C)、S₋ = C − σ̃(C) 后各乘 Y^{−a_0} / Y^{−a_1} 求和。

## 5. M-HT.5：模数/尺度消耗（修正定理）

### 5.1 引理 HT-7（重缩放语义与 k-奇偶伪差）

对分量 c ∈ Z_{2^64}，R₂(c) = (c+1) ≫ 1。对密文 C = (a,b)，按分量减半后
的相位满足（逐系数，整数展开 b̃ − Σã_i s_i = φ + 2^64·k）：

φ(R₂(C)) = φ/2 + 2^63·(k mod 2) − (ρ_b − ρ_a·s)/2

即除通常的 ±1 舍入项外，存在 **±2^63 伪差项**（k 的奇偶），来源于
全 torus mask 下多项式积 Σa_i·s_i 的回绕计数——其奇偶不受控。
这是 2-幂 torus 上逐系数除 2 的**结构性障碍**（奇素数/RNS 模数下
除 2 精确，即 Wang Han §1.4 ModDown 路线的根本动机）。

### 5.2 引理 HT-7'（±迹权重的伪差抵消定理；本次会话新发现）

设密文相位携带伪差 φ = μ + 2^63·ε（ε ∈ Z 任意）。则任一 U_a
（含 Ψ 的 U_{(0,1)} 与恒等 U_{(0,0)}）作用后：

U_a(φ) = P_1·φ + P_2·σ(φ) = [P_1μ + P_2σμ] + 2^63·(P_1ε + P_2σε)

而 P_1ε + P_2σε = Y^{a_0}(ε + σε) + Y^{a_1}(ε − σε)，其中
(ε + σε) 的系数恒为偶（σ = 奇系数取反：偶位 2ε_e、奇位 0），
(ε − σε) 同理（奇位 2ε_o）。故 2^63·(P_1ε + P_2σε) = 2^64·(整数)
≡ 0 (mod 2^64)。**即任何 U_a 倍增严格消除此前累积的全部 ±2^63 伪差**
（相位级证明；KS 保持相位、蝶形 CMUX/搬运为 2^63-倍的整系数线性
组合，均不破坏该结构）。∎

### 5.3 定理 HT-8（管线终态无伪差：全重缩放 + 终恒等倍增）

管线协议（实现即此）：h 次（蝶形(含 Ψ 重缩放) + sub_a(重缩放)） +
终蝶形(含 Ψ 重缩放) + **终恒等倍增**（U_{(0,0)}：每分量 ×2，P_h = 0
故无需 KS 与 σ̃，代价 O(N) 加法/槽）。由 HT-7'：每个重缩放产生的
伪差在其后的第一个 U_a（sub_a 或换位 Ψ）处消失；终蝶形 Ψ 产生的
最后一批伪差由终倍增消除。**终态相位 = 2·LUT 值 + 噪声，无伪差**，
抽取端明文 ÷2（带符号精确）。

**推论（消息守卫，2026-09-09 实现修正后定稿）**：终倍增的伪差抵消
要求**带符号不回绕** |2μ + 2e| < 2^64，即 |μ| + |e| < 2^62：TV 量化
v·2^{62−p}（**两位守卫**）。一位守卫（v·2^{63−p}）不充分：|μ| 可达
0.875·2^63 > 2^62，终倍增回绕 2^64 使抽取偏移 2^{p+1} 格 LUT——
此错误在 I-7 门调试中实测定位并修复（HANDOFF §6p，门 0/512）。

### 5.4 命题 HT-9（延迟除法模型需要 h·log₂r——旧模型的出处）

若不做逐步重缩放而将 r 因子累积到管线末端一次性除 r^h，则中间消息
真值需 < 2^64/r^h，即消耗 h·log₂r bit（Q_start = r^h·Q_final）——
stage391/395 的模数账目对应此变体，且其噪声被 2^h 放大（fresh KS/EP
噪声在早期步被指数放大），在 h=42 下不可行。本实现的逐步重缩放 +
终倍增方案在 Z_{2^64} 上封闭，无额外模数。

## 6. M-HT.6：与 r-LUT batching 的正交性（可组合性定理）

**命题 HT-10**：设 r 输入 × r' LUT 的通道集 Λ = [r]×[r']，交织环维
N = r·r'·d''，lane (ℓ,j) 占剩余类 ℓ + r·ℓ'·（任意双剩余嵌入），目标

## 8. 安全性备注

aut_family 在 r-input 路径仅需 w = 1+N（r=2）一把额外自同构 KS 钥
