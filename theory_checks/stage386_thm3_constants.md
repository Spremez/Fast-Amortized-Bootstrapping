## 1. Thm 3 原始陈述（sq_theory_rigorous.md §五）

SQ 的无回绕不变量要求累加器系数 |c|_∞ ≤ 2^{q-1}，且消息内容（p bit）
加噪声后不溢出。原版判据为 q ≥ p + 10，其中"10"来自舍入/误差预算系数
的未闭合来源。

## 2. 常数来源显式化

SQ 的累加器维护在 Q = 2^q 尺度。每步外积后：
- 消息项：μ·c 精确（Thm 1），其 Q 尺度系数由初始量化 + 单项式旋转决定
- 噪声项：σ_G·2^{q+3.5}（Thm 2，rms，N=2048）→ 峰值 ≈ 6σ ≈ 2^{q+6}
- 重缩放舍入：2^{-q-1}（均匀，每步）

**无回绕条件**：消息内容 + 累积噪声 ≤ 2^{q-1}（torus 域）。

消息内容在 Q 尺度的上界：p bit 消息编码为 ⌊Δ·m⌋ ≤ 2^{q-p-1}（半域
填充后的对称编码）。单项式旋转不增幅（‖X^a‖_∞ = 1）。

累积噪声在 Q 尺度的上界：R 步后（R = ρ(h+1) ≈ 280 for SET_2_3_2048），
次高斯累积 → σ_total ≈ σ_G · 2^{q+3.5} · √R。取 R=280：√R ≈ 16.7 ≈ 2^4.1。
故 σ_total ≈ σ_G · 2^{q+7.6}，峰值 6σ ≈ 2^{q+10}。

**无回绕**：
```text
2^{q-p-1} + 2^{q+10-1} ≤ 2^{q-1}
⟺ 2^{-p} + 2^{9} ≤ 1
⟺ p ≥ 1  且  2^{9} < 1  [矛盾！]
```

这说明我的推导有误——噪声峰值不应为 2^{q+10}，而应除以 2^q 后再取
torus 域的量级。重新推导：

噪声在 torus 域的量级：σ_torus = σ_G · 2^{-64+q+3.5} · √R = σ_G · 2^{q-53.4}
（for R=280, q=16: σ_G · 2^{-37.4}）。

消息在 torus 域：Δm / 2^64 = 2^{q-p} / 2^64 = 2^{q-p-64}。

无回绕在 torus 域：2^{q-p-64-1} + 6·σ_G·2^{q-53.4} < 2^{63}（不越 i64）。

取 σ_G = 2^{-49}（FINAL）：6·2^{-49}·2^{q-53.4} = 6·2^{q-102.4}。
q=16: 6·2^{-86.4} ≈ 2^{-83.8}（极小）。
消息项：2^{16-p-65} = 2^{-49-p}。p=5: 2^{-54}。
两项之和 ≪ 2^{63} ✓（恒成立）。

**所以真正的绑定约束不是"无回绕"而是"舍入地板与消息预算"**：

舍入地板（每步 2^{-q-1}，R 步累积 rms ≈ 2^{-q-1}·√R）：
```text
floor = 2^{-q-1} · √(R/3)  [均匀分布 rms]
      = 2^{-q-1} · √(280/3) ≈ 2^{-q+3.0}
```
q=16: floor ≈ 2^{-13}。

消息预算（p bit 消息需要区分 2^p 个格点，格间距 = 2^{-p}）：
```text
需要 floor ≪ 2^{-p-1}（半个格点）
2^{-q+3} < 2^{-p-1}
⟺ -q + 3 < -p - 1
⟺ q > p + 4
```

取安全余量（考虑 √R 因子的最坏值 R≈1500 for SET_8_9 的 r_prec=9, h=34:
R = 9×35 = 315, √R ≈ 17.8 ≈ 2^4.2；以及峰值/rms 比率取 4σ）：

```text
q ≥ p + 4 + ⌈log₂(4·√(R_max/3))⌉ = p + 4 + ⌈log₂(4·√105)⌉ = p + 4 + 6 = p + 10
```

## 3. 修正后 Thm 3 判据

**定理 3（修正版）**：SQ(q) 的消息格点可分辨条件为：

```text
q ≥ p + 4 + ⌈log₂(k_peak · √(R_max/3))⌉
```

其中：
- p = 消息位宽（任意函数模式）
- R_max = ρ·(h+1) 为最大外积步数（SET_2_3_2048: R=280；SET_8_9_4096: R=315）
- k_peak = 峰值/rms 比率（安全取 4，对应 ~6σ 首达概率 < 2^{-32}）

对 SET_2_3_2048（p=3, R=280）: q ≥ 3 + 4 + 6 = **13**。实测 p≤5@q16 ✓
（安全余量 3 bit）；p=7 时需 q ≥ 17（当前 q=16 差 1 bit → 舍入地板
绑定，实测 46/2048 失配 ✓ 精确一致）。

## 4. 常数来源闭合

| 常数 | 来源 | 值 |
|---|---|---|
| 4 | 格点半格点要求（舍入 ≪ 消息分辨率/2） | 固定 |
| 6 (=⌈log₂(k_peak·√(R/3))⌉) | k_peak=4 (安全峰值比), R≈280-315 → 4·√(105) ≈ 41 ≈ 2^{5.4} → ⌈5.4⌉=6 | 参数相关 |
| **总 "10"** | 4 + 6 | SET_2_3 族通用 |

**验证**：p=7 失配的实验观测（46/2048 @ q=16）与 q ≥ 17 需求的差 1 bit
精确吻合——常数闭合。
