## 1. 对象

- **系数选择子** V ∈ MAT_TRGSW：均匀对角**单项式**消息 X^{s̃}
  （s̃ = s_{j̃_t} ∈ [−ρ,ρ]；`mat_trgsw_monomial_sample` 的 e≠0 路径，
  e = s̃ mod 2N，负循环符号由 `if(e & N) m *= -1` 折叠）。
- **多体自同构** κ_w（w 奇）：`pvmtmlwe_eval_automorphism` + 多体自同构
  KS 钥（aut_minus1 同族；G-ρ 需要全部奇指数 w∈{1,3,…,2N−1} 的钥族）。
  逐 lane 作用：φ_q(κ_w(C)) = κ_w(φ_q(C)) + ε_aut。
- **G-ρ 步**（对每个输入系数 k）：

```text
y_k   = κ_{−a_k^{-1}}(C_k)
W_k   = V ⊡ y_k                    # 多体外积，对角单项式消息
out_k = κ_{−a_k}(W_k)
```

## 2. 引理 T4（逐 lane 正确性）

设 a_k 为奇（mod switch round-to-odd 保证，`odd_mod_switch` 复用），
V 如上，则对每 lane q：

```text
φ_q(out_k) = X^{s̃} · φ_q(C_k) + η_q
η_q = κ_{−a_k}( X^{s̃} ⊡-噪声项 ) + 2×ε_aut 项
```

即 G-ρ 步在多体上实现"指数域减去 a·s̃"，与标量 `sub_a_ga` 逐步等价。

**证明**。指数上的自同构线性：κ_w(X^u) = X^{u·w mod 2N}（负循环符号随
uw 越界折叠），故

```text
φ_q(out_k) = κ_{−a_k}( φ_q(W_k) )
           = κ_{−a_k}( X^{s̃} · κ_{−a_k^{-1}}(φ_q(C_k)) + ε_⊡ )
           = X^{s̃·(−a_k)·(−a_k^{-1})} · φ_q(C_k) + κ_{−a_k}(ε_⊡)
           = X^{s̃} · φ_q(C_k) + η_q
```

第三个等号用自同构对单项式的 w-线性与 (−a_k)·(−a_k^{-1}) ≡ 1 (mod 2N)
（a_k 奇 ⇒ 可逆；负循环符号在两次折叠中抵消——奇 w 下 κ_w 与符号折叠
可交换，同 `sub_a_ga` 的标量论证）。ε_⊡ 由 M1 的对角单项式版给出
（gadget 放置从常数 m 推广到 m·X^e，行相位仍是"对角消息 + 噪声"，
M1 的分块对角论证逐字适用）。∎（结构证明；逐步 oracle 等价见 §3）

## 3. 等价与实测义务（gate 设计）

1. **小规模逐步 oracle**（r∈{1,4}，n∈{16,64}）：对每个系数 k 断言
   φ_q(G-ρ 步输出) == φ(sub_a_ga 标量步输出)（同一钥/输入/种子），
   逐步：κ → ⊡ → κ 三边界。
2. **噪声门**：每系数每步噪声项 = 2×多体 aut-KS + 1×EP（行噪声×操作数
   数位）——与标量计数完全一致（686 Alg 4 每系数 2 自同构 + 1 外积），
   预测与标量同阶；门 = 预测/实测 < 1.3。
3. **FINAL A/B**（stage377 顺延）：h=42/σ_G=2⁻⁴⁹ 一次时序+门对照。
