## 一、设置：双通道交织-多体结构

**通道集** Λ = [r₁] × [r₂]：r₁ 个**不同输入密文**（input 轴）× r₂ 条
**LUT lane**（body 轴）。密文类型：环 R = Z[X]/(X^N+1)、N = r₁·d 的
**r₂ 体** Vec-MLWE（每槽一个密文，体 j 承载 LUT j）。消息映射：

Φ²((m_{ℓ,j})) = Σ_{ℓ<r₁} X^ℓ · m_ℓ(X^{r₁})，其中 m_ℓ ∈ A^{r₂}
（A = Z[Y]/(Y^d+1)，Y = X^{r₁}；体 j 的 m_{ℓ,j}）。

即：**交织结构只在 input 轴**（X-指数模 r₁ 剩余类 = lane），**LUT 轴
= 密文体维**（多体 TRLWE 的 body 分解）。两轴作用在不同张量因子上：
- input 轴：Hom-Tr / U_a / Ψ / H₁ = {σ_{1+2dλ₁}}（环作用）；
- LUT 轴：选择子的分块对角结构（M1 域，体代数）。

**目标变换**（每通道独立）：L_{a}((m_{ℓ,j})) = (Y^{ā_ℓ}·m_{ℓ,j})：
ā_ℓ = 输入 ℓ 的模切换掩码（与 j 无关——同一输入驱动全部 LUT）。

**虚拟标量族**：P_{ℓ,j} = 标量 SAB（输出环 d、粒度 2d、输入 ℓ、
TV_{ℓ,j}）。

## 三、证明

### (S) 语义：对步数归纳（HT-5 归纳 × M1 体对角性的逐层复合）

- **基例（setup）**：Φ² 的放置 = 每 body j 独立做 stage406 §3.1 的
  r₁-lane 交织放置（TV_{ℓ,j}）。与 P_{ℓ,j} 的 setup 逐通道同构。✓
- **蝶形 bit 级**：选择子 C_{t,j'} 加密环单项式（消息 = X^{d_t·2^j'·
  unit}·I_{r₂}：分块对角，对角块 = 同一环单项式，非对角块零——
  M1 的假设形态）。由 **M1**：输出的体 j' 分量只依赖输入体 j' 分量
  与共享掩码演化（无跨体消息项）。于是可逐体应用 **HT-5 的 bit 级
  论证**：体 j' 内，直达槽 = 数据搬运与 Φ 可交换；换位槽 = Ψ 的
  lane 一致 J 提升（引理 3.6 的证明只用环结构，与体无关——σ₋₁、
  σ_h、P_w 均为环作用，逐体系数同时变换）。✓
- **sub_a**：U_a = R₂(Y^{a₀}(C+σ̃_h C) + Y^{a^{...}}(C−σ̃_h C)) 为
  **环线性 + 逐体作用**（σ̃_h 的 KS 对每体分量独立执行；引理 3.4'
  的恒等式证明是逐系数线性的，从未使用单体假设）⟹ 逐体逐 lane
  实现 L_a。伪差抵消（定理 3.8(b)）逐体系数独立成立（±迹权重的
  偶性论证在每体系数上相同）。✓
- **终倍增/抽取**：×2 与列×体抽取均为逐分量线性。归纳完成。∎(S)

*要点*：两轴正交的机制根源 = **环作用（input 轴）与体作用（LUT 轴）
交换**：H₁ 的自同构与分块对角矩阵乘法逐体系数可交换，故两条归纳
论证可叠加而不相互干扰。

### (C) 成本

EP：每 bit 级选择子 × 每 CMUX 一次；选择子行数 = ℓ(k + r₂)（体轴
进入行常数——M3 计数）；input 轴不增加 EP 数（交织在同一密文内）。
sub_a：KS 与单项式乘加逐体执行（×r₂），重缩放逐系数（×r₂ 计入
分量数）；自同构次数不随 r₂ 变（环作用一次覆盖全体）。合计即陈述
的相加形式；以 r = r₁r₂ 合成的摊销常数与 stage398 A1 一致（A1 的
(k+r)/r 因子即体轴行常数）。∎(C)

### (N) 噪声

stage405 N1 的递推按密文分量陈述：DC 轨（确定性，依赖钥 s 与 μ_ε）
与白轨（事件计数）均逐体系数独立演化——体 j 的相位 = 该体系数上
的递推实例（M2：无跨体噪声放大——误差项只经对角块与第 0 列块，
共享行噪声实现与单 lane 同幅）。∎(N)
