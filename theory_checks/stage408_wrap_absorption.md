的 σ₋₁（lane 1 奇 Y-扭曲，引理 3.6'/HT-4'）能否被**对角 Mat-MGSW
选择子**吸收（即选择子的对角单项式消息直接实现 J，免去独立 aut-KS）？

## 一、定理 Ψ-Nec（不可吸收性；二值结论 = 否）

**陈述**。设 D ∈ R 为任意环元素（特别地含对角 Mat-MGSW 的任一对角
单项式消息 μ·X^e，μ ∈ {±1}，e ∈ Z/2N），Φ 为交织打包（N = 2d，
Y = X²）。则不存在 D 使

  D · Φ(m_0, m_1) = Φ(Jm_0, Jm_1)   对全部 (m_0, m_1) ∈ A²。

**证明**（两行反证）。取 (m_0, m_1) = (1, 0)：左 = D·1 = D，右 =
Φ(1, 0) = 1 ⟹ D = 1。再取 (m_0, m_1) = (Y, 0)：左 = Y，右 =
Φ(Y^{−1}, 0) = Y^{−1} = −Y^{d−1}（A 中折叠）。Y ≠ −Y^{d−1}
（d ≥ 2），矛盾。∎

**结构性解释**：左乘 D 是 R-线性算子，与一切 Y-平移交换
（D·Y^a = Y^a·D）；而 J 反交换（J·Y^a = Y^{−a}·J）。故任何乘法
算子（选择子外积的消息层作用——由 M1 恰为对角块单项式乘）都不能
实现 J。**换位修正必须引入至少一个真自同构**。

## 二、推论（Ψ 的最小性）

**推论 Ψ-Min**。任何正确的换位源修正 = 某算子族使 lane 一致诱导
J。由引理 3.6'（HT-4'）：σ₋₁ 单独不行（奇偶障碍）、任何预因子 +
单个自同构不行、任何单项式乘不行（定理 Ψ-Nec）；而 **Ψ =
U_{(0,1)}∘σ₋₁ 达成 lane 一致 J**（引理 3.6），且其第二自同构
σ_{1+N} 与 sub_a 共钥 ⟹ **Ψ 是最小新增钥成本的正确修正**（全管线
自同构钥恰两把：σ₋₁ + σ_{1+N}，后者复用）。任何替代修正至少引入
一把非 σ₋₁ 的自同构钥，钥成本 ≥ Ψ。

**证明**：必要性 = Ψ-Nec + HT-4'（穷尽"乘法/单自同构/预因子"三类
候选）；充分性 = 引理 3.6；最小性 = 上述钥计数。∎
