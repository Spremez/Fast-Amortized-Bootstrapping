## 3. The Algorithm（正文）

### 3.0 Overview

本节给出 combined packing and batching 的完整自举算法族：输入为 r 个
**不同**输入密文（r-input batching）共享一次盲旋转，输出环承载 r 条
lane（packing）。两条主线：代数基版（Alg 1'/2'，双模数 Mat-MGSW ×
Vec-MLWE，本节主体，记号承 V2 草稿）与矩阵版（Alg 3/4 = 同构实现，
附录 D 映射）。相对 V2 草稿的三处结构性修正（§3.7 逐条定位）：
**(F-i) 换位修正 Ψ**：裸 σ₋₁ 在 lane 1 产生奇 Y-扭曲（引理 3.6'，
不可由任何预因子修复）；**(F-ii) 行 9 替换**：明文单项式乘对 r 个
不同输入数学错误，改为 U_a 相对迹（引理 3.4'）；**(F-iii) 终倍增
协议**：Z_{2^q} 封闭的重缩放伪差消除（定理 3.8）。

sub_a 设计空间四后端（含两个负对照）：

| 后端 | 机制 | 每槽每步 aut-KS | 秘密类 | 判定 |
|---|---|---|---|---|
| 明文单项式乘 | mul_by_xai | 0 | binary | ✓（现行 r-LUT 主线）|
| sub_a_ga | 双自同构+EP | 2 | 一般稀疏 | ✓（G-ρ 语义完备）|
| **Hom-Tr U_a（本文）** | 相对迹 + 重缩放 | 1 | 任意（逐 lane 指数） | ✓（Alg 2'）|
| 朴素自同构 Hom-Tr | 单 aut | 1 | — | ✗ 负对照（lane 错位）|

### 3.1 Setting and Notation

输入环 R_Y = Z[Y]/(Y^n+1)；自举环 R = Z[X]/(X^N+1)，N = r·d（均 2 幂）；
交织子环 A = Z[Y]/(Y^d+1)，Y := X^r。指数群 (Z/2N)^×，σ_w(X^i) =
X^{wi mod 2N}，折叠 X^N = −1。固定子群 H := {σ_{1+2dℓ}}_{0≤ℓ<r}
（引理 3.1：|H| = r 且 R^H = A）。

**稀疏间隙密钥**：输入密钥 s ∈ {0,1}^n，hw(s) = h+1（含环绕），位置
i_0 > i_1 > … > i_{h}（含环绕差），间隙 d_t = i_{t-1} − i_t（d_h 为
环绕差），全部 1 ≤ d_t < 2^ρ，ρ := ⌈log₂(n/h)⌉。密钥束：逐
(t, j) 位选择子 Enc(X^{d_t·2^j·unit})（unit = 2N/n，j < ρ）+ 两把
自同构 KS 钥（σ₋₁ 与 σ_h，h = 1+N 指 r=2；一般 r 见 §3.3 末注）。

**消息打包**：明文交织打包 Φ((m_ℓ)_ℓ) := Σ_{ℓ<r} X^ℓ·m_ℓ(X^r)。
TV 量化：测试向量值 v·2^{q−p}（p 位 LUT 值），**两位守卫** q ≥ p+2
（定理 3.8 的要求；一位不充分——§3.7 F-iii）。

### 3.2 Algorithm 1'：Packing MPMUL（修正版）

**输入**：(i) 槽密文列表 c = (c_0,…,c_{n−1})，c_i 加密
Φ((X^{u_ℓ[i]·unit}·τ_ℓ)_ℓ)（τ_ℓ 为 lane 消息多项式）；(ii) 间隙位
选择子 C_{t,j} = Enc(X^{d_t·2^j·unit})；(iii) KSK（σ₋₁、σ_h）。

```text
Algorithm 1'  P-MPMUL(c, C, KSK)
1  for t = 0 to h do
2    for j = 0 to ρ−1 with bit b_tj = (d_t >> j) & 1 do
3      for i = 0 to 2^j−1:                          # 换位槽（源跨界）
4        c'_i ← c_i + C_{t,j} ⊡ (Ψ(c_{n−2^j+i}) − c_i)     # F-i
5      for i = 2^j to n−1:                          # 直达槽
6        c'_i ← c_i + C_{t,j} ⊡ (c_{i−2^j} − c_i)
7      c ← c'
8  return c
```

其中 **Ψ := U_{(0,1)} ∘ σ₋₁**（换位源修正，定义见式 (3.4)），
U_{(0,0)} 为恒等。草稿 Alg1 的行 6 使用裸 EvalAuto(−1)：对 r = 1
（686 域）正确；对交织打包在 lane 1 产生 Y^{−1} 扭曲（引理 3.6'）。

**定理 3.2（S1，蝶形语义分解）**。设第 t 相位的累计移位 V_t =
Σ_{t'<t} d_{t'}。则 Alg 1' 前 t 相位的复合作用在消息层恰为：

content'[j] = X^{−(Σ 访问行 ā)·unit}·content[轨迹(j)]（纯重标），
且轨迹 j ↦ j − V_t (mod n) 的跨界次数奇偶决定符号（= a·s 负循环
卷积的行符号）。间隙指数**不进入相位**；间隙的全部作用是行选择。

*证明*（归纳 + M0 机器证实；全文见附录 A.1）：每 bit 级移动
{c_j, c_{j−2^b}} 的 CMUX 选择为公开位 b_tj 的加密；归纳假设下内容
集合 = {X^{b̄−Σā_visited}·TV} 的重排，每次跨界施加 σ₋₁（lane 一致的
J 作用，经 Ψ），符号 = 轨迹跨界数的奇偶。GF(257) 判决：M0（重标+
跨界 σ₋₁）240/240 全等；M1（单项式一步化）240/240 失配；M2（纯重标）
240/240 失配。∎

### 3.3 Algorithm 2'：Packing BIN-SAB（修正版）

**输入**：(i) r 个输入 TRLWE 密文（同一 s，环 R_Y）；(ii) 选择子束
（§3.1）；(iii) 每 lane 测试向量 TV_ℓ ∈ T_A（q 位、两位守卫量化）；
(iv) KSK。

```text
Algorithm 2'  Packing BIN-SAB
1  for i = 0 to n−1:                       # 交织 setup（明文）
2    b̄_ℓ ← ⌊b_ℓ[i]·2d/2^64⌉ (mod 2d)；  c_i ← Φ((Y^{b̄_ℓ}·TV_ℓ)_ℓ)
3  for k = 0 to h−1 do
4    c ← P-MPMUL(c, C_{k,·}, KSK)          # 相位 k 蝶形（Alg 1'）
5    for i = 0 to n−1 do                    # sub_a：相对迹（F-ii）
6      ā_ℓ[i] ← ⌊a_ℓ[i]·2d/2^64⌉ (mod 2d)
7      c_i ← U_{ā(i)}(c_i)                 # 式 (3.4)；含重缩放 R₂
8  c ← P-MPMUL(c, C_{h,·}, KSK)            # 终相位蝶形
9  for i = 0 to n−1: c_i ← 2·c_i            # 终恒等倍增 U_(0,0)（F-iii）
10 return c                                  # 抽取：lane ℓ 列 ℓ，
                                            #   明文带符号 ÷2（见 (3.6)）
```

**U_a 相对迹算子**（替换草稿行 9 的 c_k·X^{−a_k[k]}）：

(3.4) U_a(C) := R₂( Y^{a_0}·(C + σ̃_h C) + Y^{a_1}·(C − σ̃_h C) )，
r = 2（一般 r：U_a = R_r(Σ_{w∈H} P_w·σ̃_w(C))，P_w 见引理 3.4'），

其中 σ̃_h = KeySwitch_{σ_h→s}∘σ_h；R₂ = 逐系数 ⌊·/2⌉；Ψ = U_{(0,1)}
（同一式取 a = (0,1)）。**共钥结构**：σ̃_h 与 Ψ 的第二自同构共用同一
把 KS 钥（r-input 全路径仅两把 aut 钥：σ₋₁ 与 σ_h）。

**引理 3.4'（U_a 恒等式，HT-2'）**。对公开 a = (a_0,…,a_{r−1}) ∈
(Z/2d)^r 与任意嵌入偏移：U_a(Φ_f(m)) = r·Φ_f(L_a(m))，L_a = 逐 lane
平移 m_ℓ ↦ Y^{−a_ℓ}m_ℓ（本实现取向 Y^{+a_ℓ}，与抽取口径一致）。
*证明*：迹提取 T_H(X^{−λ}f) = r·m_λ（引理 3.1 系）+ 交换求和。∎

**引理 3.6'（奇偶性障碍，负结果 HT-4'）**。σ₋₁ 在 lane λ（预因子
f_λ）上的诱导作用 = Y^{−(2f_λ+1)}∘J（J = Y ↦ Y^{−1}）。任何
f: [0,2) → Z 与任何单个环自同构均无法使两 lane 同得 J：需 2f_1+1 ≡
0 (mod 2d)，左奇右偶无解。⟹ 裸 σ₋₁ 管线在 lane 1 输出秘密错位；
修正在 Ψ（σ₋₁ 后做一次微型 Hom-Tr 把 lane 1 乘回 Y^{+1}，诱导作用
= lane 一致的 J，引理 3.6）。

**定理 3.8（终倍增协议，HT-7/7'/8）**。(a) R₂ 的逐系数减半对全
torus 密文产生 ±2^{q−1}·k 类伪差（k = 相位回绕计数的奇偶）；
(b) 任何 U_a 的倍增结构使先前累积的全部该类伪差 mod 2^q 严格消失
（±迹权重 P_1ε+P_2σε 恒偶）；(c) 全重缩放 + 终恒等倍增 U_(0,0)}
（×2，无 KS）+ 抽取端明文带符号 ÷2 的协议下，终态相位 = 2·LUT +
噪声，无伪差；(d) 两位守卫 |μ| + |e| < 2^{q−1} 是 (c) 的充分条件
（TV 量化 v·2^{q−p}，p+2 ≤ q）。*证明*：stage396 §5.1–5.3 全文；
(d) 的边界情形由 I-7 门调试实测定位并修复（一位守卫时终倍增回绕
2^q，抽取偏移 2^{p+1} 格 LUT）。∎

**一般 r 注**：H 的非平凡元不止一个时，U_a 需 r−1 把自同构钥
（σ_{1+2dℓ}），共钥结构退化为逐元一钥；r = 2 为本实现域（d = N/2）。

### 3.4 定理 C1'（正确性）：HT-5 + M1 + S1 组合

**定理 3.9（C1'，逐 lane 相位不变式）**。设 Alg 2' 以输入密文
(in_0, in_1)（同一 s）、TV (TV_0, TV_1) 运行；对每个 ℓ ∈ {0,1} 设
P_ℓ 为虚拟标量管线（输出环 A、粒度 2d 模切换、同一间隙选择子结构、
换位修正 = A 环上的 J + KS、sub_a = 明文乘 Y^{ā_ℓ}）。则对每槽 t
与每步：msg_{Alg2'}(t) = Φ((msg_{P_0}(t), msg_{P_1}(t)))。特别地终
态：lane ℓ 在其抽取列的系数 = P_ℓ 终态列 0 系数，逐槽相等（至噪声，
噪声项由 §4 定理 N1 定量）。

*证明*（对操作步数归纳；无跳步）：
- **基例**（setup，行 1–2）：两 lane 的 b̄_ℓ 模切换与 Φ 的放置由构
  造逐系数相同。G0 门：setup 输出与明文期望 0 失配（dell，2 点 ×
  6 试）。✓
- **蝶形 bit 级**（行 4 经 Alg 1'）：由定理 3.2（S1），相位作用 =
  纯重标 + 跨界符号。直达槽：数据搬运，与 Φ 逐 lane 分量可交换。
  换位槽：消息层作用 = Ψ ∘ 搬运 = (J, J)（引理 3.6）= 标量管线换
  位作用（J）在两 lane 的一致提升。选择子的 lane 独立性 = M1
  （分块对角：体 j 输出只依赖体 j 输入 + 共享掩码演化，无跨体消息
  串扰）。✓
- **sub_a**（行 5–7）：由引理 3.4' + 定理 3.8(b)，U_{ā(i)} 的消息
  层作用 = 逐 lane Y^{ā_ℓ}（标量侧同变换）；R₂ 的伪差由下一次 U_a
  倍增消除（定理 3.8(b)），暂态伪差不破坏消息不变式。✓
- **终倍增**（行 9）：×2 消除最后一批伪差（定理 3.8(c)）；消息
  恒等。✓
- **抽取**（行 10 注）：lane ℓ 列 ℓ 的系数 = Φ 的 ℓ 分量（明文嵌
  入下指数 ℓ + r·q < N 无折叠符号）；列抽取线性。归纳完成。∎

**机器证据**（§3.5 表）：C4 决定性 2560/2560；两件负对照（裸 σ₋₁
1280/2560 = lane 1 全部失配；朴素自同构 Hom-Tr）按预期失败。

### 3.6 算子计数（与 §5 复杂度章对接）

每槽每相位：直达槽 1 EP/bit（ρ bit）；换位槽 + Ψ（1 σ₋₁-KS +
1 σ_h-KS【共钥】+ 4 单项式乘加 + 1 R₂）；sub_a 每 h 相位：1 σ_h-KS
+ 4 单项式乘加 + 1 R₂。m=1/m=0 bit 计数由间隙位型决定（S1 轨迹）。
每消息摊销定律（定理 A1/A2，§5）：T_msg(r) = (h+1)·ρ·ℓ·N·logN·
(1 + k/r)，r→∞ → 1/(k+1)·(686)。
