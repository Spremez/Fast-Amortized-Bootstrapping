## 一、M1 精确陈述与证明（多体外积的逐 lane 正确性）

**设定**：输出环 R = ℤ[X]/(X^N+1)，输出密钥族 S = (s^(0),…,s^(r−1))，
s^(q) ∈ R^k（PVW_TMLWE_Key 第 q 列）。多体密文 c = (a^(0),…,a^(k−1);
b^(0),…,b^(r−1)) ∈ T_R^{k+r}。lane q 的相位函数：

```text
φ_q(c) = b^(q) − Σ_{i<k} a^(i) · s_i^(q)  ∈ R
```

**Mul-GSW 选择子** M ∈ Mul-GSW：(k+r)ℓ 行，每行为 PVW_TMLWE 样本，
gadget 放置为分块对角：行 (jℓ+i)（j<k 为掩码行块，j=k+q 为体 q 行块，
i<ℓ 为 gadget 级）只在分量 j 上加 m_j · h_i（h_i = 2^{64−(i+1)Bg}）。

**多体外积**：MV-EP(c, M) = Σ_{row=0}^{(k+r)ℓ−1} G⁻¹(c)_row ⊙ M_row，
其中 G⁻¹(c)_row 为 c 的第 row 分量的 gadget 数字分解的第 row 级项。

**定理 M1（精确版）**：设 M 的对角消息为 m = (m_0, …, m_{r−1})（非对角
为零），c 为 S 下的合法 PVW_TMLWE。则 MV-EP(c, M) 输出的每个 lane q
的相位满足：

```text
φ_q(MV-EP(c, M)) = m_q · φ_q(c) + ε_q
```

其中 ε_q 为误差项，且**体 q 的输出只依赖体 q 的输入与共享掩码的演化**
——即不存在从体 q' 到体 q 的消息串扰（q' ≠ q）。

**证明**（完整归纳）：

将 c 的 gadget 分解记为列块向量 [ã^(0); …; ã^(k−1); b̃^(0); …; b̃^(r−1)]，
每块 ℓ 行（数字分解的第 0..ℓ−1 级）。选择子 M 为行块矩阵。

MV-EP 的第 j 体输出（j < r）：

```text
b'_j = Σ_{row} dec_row(c) · M_row.b[j]
```

其中 M_row.b[j] 为第 row 行选择子的第 j 体分量。

由分块对角性：M_row.b[j] 仅在行块 j（体 j 行）与行块 [0, k)（掩码行）
处非随机（其余行块的 b[j] 分量为纯随机掩码，其对相位的贡献为零）。

因此：

```text
b'_j = Σ_{i<ℓ} dec_{kj+i}(c) · M_{(k+j)ℓ+i}.b[j]     [体 j 行块贡献]
     + Σ_{i'<k, i<ℓ} dec_{i'ℓ+i}(c) · M_{i'ℓ+i}.b[j]  [掩码行块贡献]
     + ε_j                                            [其余行的噪声]
```

对体 j 行块（对角）：M_{(k+j)ℓ+i}.b[j] 的第 j 体分量的**相位**为
m_j · h_i（gadget 放置），故贡献 = Σ_i dec_{kj+i}(c) · m_j · h_i +
dec_{kj+i}(c) · e_{(k+j)ℓ+i}^{(j)} = m_j · [Σ_i dec_{kj+i}(c) · h_i +
e-项] = m_j · [b̃^(j) 的 gadget 重构 + e-项]。

同理，掩码行块的贡献 = −Σ_{i'<k} s_{i'}^(j) · [Σ_i dec_{i'ℓ+i}(c) · h_i +
e-项] = −Σ_{i'<k} s_{i'}^(j) · ã^(i') 的 gadget 重构 + e-项。

合并（利用 gadget 重构恒等式 Σ_i dec_i(c)·h_i ≈ c + 舍入项）：

```text
φ_j(out) = m_j · b^(j) − Σ_{i'<k} s_{i'}^(j) · m_j · a^(i') + 舍入+噪声项
         = m_j · (b^(j) − Σ a^(i') · s_{i'}^(j)) + ε_j
         = m_j · φ_j(c) + ε_j                                          ∎
```

**无跨体串扰**：b'_j 的计算只涉及 dec_{kj+i}(c)（体 j 分量的分解）与
dec_{i'ℓ+i}(c)（掩码分量的分解），**不涉及 dec_{kq'+i}(c)（q' ≠ j 的
体分量的分解）**——这些分量只影响 b'_{q'}，不影响 b'_j。因此跨体消息
项不存在。∎

**验证**：`sab_pvw_extract_tlwe_lane`（逐 lane 提取 + 量化消息门）在
r=1..8 全域 0 失配即为 M1 的实验形态。

## 二、M2 精确陈述（多体外积的逐 lane 噪声）

**定理 M2（精确版）**：设选择子 M 的行噪声（作为 PVW_TMLWE 样本）的
lane-q 相位噪声为 ε_row^(q)，各行为独立次高斯（参数 E_G）。则 MV-EP
输出 lane q 的误差 ε_q 满足：

```text
ε_q = Σ_{row=0}^{(k+r)ℓ−1} dec_row(c) · ε_row^(q) + ρ_round
```

其中 ρ_round 为 gadget 分解舍入项（‖ρ_round‖_∞ ≤ ℓ·N·β_g/2，β_g =
2^{64−Bg}）。因此：

```text
Var[ε_q] ≤ Σ_{row} |dec_row(c)|² · Var[ε_row^(q)] + Var[ρ_round]
```

**关键性质**：
1. **无交叉项**：ε_row^(q) 与 ε_row^(q')（q' ≠ q）来自选择子不同行的
   独立采样（keygen 时各行独立），故 cov[ε_q, ε_{q'}] = 0（q' ≠ q）；
2. **每 lane 噪声界与标量同阶**：每 lane 收集 (k+r)ℓ 个选择子行噪声项
   （标量收集 (k+1)ℓ 个），多出的 (r−1)ℓ 项来自掩码行块的额外行——
   但掩码行的噪声方差与标量情形的相同（同一 keygen），故每 lane 的
   累积噪声界最多放大 √((k+r)/(k+1)) 倍（k=1, r=4: √(5/2) ≈ 1.58）；
3. **共享掩码噪声是同一次实现**：掩码演化引入的噪声对全部 lane 是
   同一随机变量，但其幅度与单 lane 情形相同（不乘 r 次）。

**实测对账**：S7 十次审计（81,920 点 pair 0）+ 50 种子战役（409,600 点
pair 0）确认 pair 失配为零；噪声 gap ∈ [−0.54, +0.64] log2（均值 ≈ 0），
与"最多 +0.66 log2 的次高斯求和上界"一致。
