# OB-2 执行：五族算法的 C0 类成员解释引理

Date: 2026-09-09
义务：stage400 WS-A / OB-2。目标：证明下界的适用范围覆盖全部已知
摊销 FHEW 式自举——每一族给出到模型 C0（stage399 §二 + stage401
的 H1/H2/H2'/H5）的显式解释映射。这是"下界不是仅对 686"的形式化
兑现。记号从 stage400 §1 统一表。

---

## 引理 CM-1（686 / SAB 是 C0 成员）

**构造**（ePrint 2025/686，CCS'25）：n 槽累加器，每槽 TRLWE
（k=1 mask + 1 body），(h+1) 个间隙步，每步 ρ = ⌈log₂(max gap)⌉ 级
逐位蝶形（CMUX/NCMUX），NCMUX 对换位源施加 σ₋₁；步间 sub_a 明文
单项式乘。

**解释映射**：
- 秘密选择：每个 CMUX 的选择子 = 加密该间隙位的 TRGSW ⟹ 二元选择
  门（定义 1.2，a=2）✓；
- 单项式累积（H1）：终态槽 t 内容 = X^{−φ_t}·TV（686 引理 4.1 类
  不变式；我们的 S1 语义分解即其逐位形式）✓；
- 层式宽度 n（H2'）：乒乓缓冲每级每槽恰一门（含位=0 的门）✓
  （stage401 引理 3.0 已核对）；
- 均匀性（H5）：拓扑与间隙值无关，秘密仅在选择子密文中 ✓；
- 密钥预算（H2）：(h+1)·ρ 把二元选择钥 ⟹ O((h+1)ρs₀) ✓。
∎

## 引理 CM-2（TFHE / CGGI 盲旋转是 C0 成员）

**构造**（ Chillotti et al., JoC'20，门自举）：累加器 TRGSW×TRLWE
单密文（等效"1 槽"）+ 逐位条件旋转 CMUX 链（n 位相位，深度 n 的
逐位门）。

**解释映射**：
- 秘密选择：每位一个加密控制 CMUX ⟹ 二元选择门 ✓；
- 单项式累积（H1）：输出 = X^{−φ}·TV（TFHE 定理），φ = 逐位累积 ✓；
- 层式（H2'）：逐位链天然分层；宽度 w=1（单密文累加器——n 槽摊销
  维度为 1，即 r=1、无行摊销的退化成员；下界的 n·ρ 项按其结构取
  n'=1、ρ'=n，得每自举 Ω(n) 门——与 TFHE 已知成本一致）✓；
- H5/H2 ✓（均匀逐位拓扑，n 把钥）。
**注**：TFHE 是 C0 的退化成员（无行摊销），其成员性说明下界同样
覆盖非摊销基线。∎

## 引理 CM-3（FHEW 是 C0 成员）

**构造**（Ducas–Micciancio, EUROCRYPT'15 + MP'21 改进）：累加器
按相位位逐位旋转/累加（LUT 自举的逐位映射）。

**解释映射**：同 CM-2：逐位秘密条件旋转 + 单项式累积输出；映射到
宽度 1、ρ = 相位位数的 C0。∎

## 引理 CM-4（BatchBoot 是 C0 成员）

**构造**（USENIX Security'26）：FHEW 式摊销自举的多 LUT 批处理
变体（Boot2/4/6/8 参数集，公开论文算法 1-3）。

**解释映射**：其批处理 = 我们的 r-LUT 维度在 FHEW 逐位骨架上的实例
（共享逐位选择、多测试向量）；逐位选择门 + 单项式累积 + 均匀拓扑
结构同 CM-2/CM-1。其行摊销维度即 r 轴 ⟹ 落入 C0 的 (n, r) 一般
形式。**注**：stage381 重评显示其参数在修正安全口径下全部 FAIL，
但类成员性与安全性无关——下界覆盖其成本结构。∎

## 引理 CM-5（本工作全族是 C0 成员）

**构造**：本工作全部已实现路径——(a) r-LUT 矩阵路径（sab_pvw 蝶形
族）；(b) r-input 交织路径（sab_rinput，Alg 1'/2' 的实例）；(c)
δ=2/ternary/include-zero/ρ-SAB 变体（stage369-379 全门记录）。

**解释映射**：
- (a)：CMUX 拓扑同 CM-1，body 数 r ⟹ 行常数 (k+r)/r（L3 的匹配
  侧）；H2' ✓（乒乓）；H5 ✓；
- (b)：蝶形同 (a) + 换位源 Ψ 修正（Ψ = U_{(0,1)}∘σ₋₁：一次 σ̃_{1+N}
  KS + 单项式权重乘 + 重缩放——仍是"选择门 + 公开线性运算"的 C0
  运算类型）+ sub_a = U_a 相对迹（秘密依赖全部经 σ̃_{1+N} 的选择/
  KS 门与公开单项式乘）✓ H1（终态 = X^{−φ^{(j)} }·TV 逐 lane，
  HT-5）✓；
- (c)：变体只改公开侧（差分/符号门为额外选择门，仍 C0 型）✓。
∎

## 定理 CM（覆盖定理）

**陈述**：全部已知达到 128-bit 安全声称的摊销 FHEW 式自举构造
（686、TFHE 系、FHEW 系、BatchBoot、本工作全族）均是模型 C0 的
成员（CM-1..5）。因此定理 LB/LB-F 的下界适用于上述全部构造的
成本结构；"本工作匹配下界且行常数最优"是在**同界内**的比较主张。

**证明**：CM-1..5 的并集即为陈述范围；每个成员性引理给出显式映射
（选择门对应、H1-H5 逐条核验）。∎

**诚实边界注记（入论文 §5.1 末）**：类成员性是**逐构造验证**的
（非全称证明）；新提出的非 C0 范式（若有）不在下界覆盖内——这是
范围声明而非缺陷，与分支程序/排序网络下界的论文形态一致。
