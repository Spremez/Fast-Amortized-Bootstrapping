## 一、ρ 消去调查（本会话核心探索，否定性结果 + 语义定理）

### 1.1 假设（OS-MPMUL）

686/Alg1 的 MPMUL 用 ρ = ⌈log₂(max gap)⌉ 级逐位 CMUX 蝶形实现"按间隙
v 移动槽内容"。观察：间隙值是 **keygen 已知常数**——假设选择子可直接
加密完整单项式 X^{v·unit}（unit = 2N/n），一步完成移动：
`content'[j+v mod n] = X^{v·unit}·content[j]`，去掉 ρ 因子。

### 1.2 机械裁决（GF(257)，n=8, d=16, 30 组随机）

| 测试 | 内容 | 结果 |
|---|---|---|
| M1 单项式移动 | 均匀 X^{v·unit} + 重标 | **FAIL 240/240**（c0 巧合吻合，其余错位） |
| M2 纯重标（无单项式） | 仅数组重排 | FAIL 240/240 |
| **M0 重标+跨界σ₋₁** | 重标 + 对 j+v≥n 的内容施加 σ₋₁ | **PASS 240/240** |

### 1.3 语义分解定理（M0 机器证实）

**定理 S1**：蝶形移动 ⟺ 纯重标 + 对**跨界内容**（j+v ≥ n）施加 σ₋₁。
间隙指数**不进入相位**——间隙的全部作用是**选择**每行累加哪些槽的
ā 值（轨迹 j, j−V₁, j−V₁−V₂, … 恰为稀疏密钥 s 的非零位置相对行 j 的
偏移）；跨界 σ₋₁ 恰为 a·s 负循环卷积的行符号。

**证明思路**（全文入论文附录）：M0 全等 + 归纳（每次移动后内容集合
= {X^{b̄−Σā_visited}·TV} 的重排，符号 = 轨迹跨界数的奇偶）。∎

### 1.4 不可能性推论（下界定理的最后一块）

**推论 S2（ρ 不可消去）**：移动 = 秘密依赖的置换 + 秘密依赖的条件
σ₋₁。加密实现 n 选 1 置换：二元选择树需 Θ(log n) 级、每级线性大小
选择子（= 蝶形本身）；单发 n 路 EP 选择子的消息为 n×n 置换阵，
代价 Ω(n²)。⟹ **每消息 Θ((h+1)·ρ·ℓ·N·logN) 为加密选择子盲旋转类的
时间下界（固定密钥束）**；686 与本工作均匹配至行常数。

**推论 S3（时间-密钥权衡曲线，通用非独占）**：若允许密钥束膨胀，
(槽,步) 粒度预加密选择子可把 EP 数从 ρ(h+1)n 降到 (h+1)n（密钥 ×n/ρ），
极限 n 个整行选择子达每消息单 EP 信息地板。**该权衡对 686 同样可用**
（非我方独占优势），且实用参数下密钥束不可行（n/ρ ≈ 341×）。论文记
为备注，防止审稿人以"更大密钥换时间"质疑最优性主张。

**推论 S4（N 自由度）**：槽-指数耦合 unit = 2N/n 需整数的约束可通过对
n 分组（每组 2N 的因子）绕开 ⟹ N 仅由 LUT 分辨率决定（与 n 无关），
对所有方案对称成立 ⟹ N 不是分离轴。

## 三、渐近复杂度最终定理（M-V2.5 升级定稿）

**定理 A1（每消息摊销定律）**：r-lane（r-LUT 与 r-input 同构，HT-10
可组合 r=r₁r₂）每消息成本

```text
  T_msg(r) = (h+1)·ρ·ℓ·N·logN · (k+r)/r        [+ r-input 的 sub_a 项]
           = (h+1)·ρ·ℓ·N·logN · (1 + k/r)
```

对比 686（无 lane 轴）：T_msg = (h+1)·ρ·ℓ·N·logN·(k+1)。

**定理 A2（批处理渐近优势 = 论文的可证渐近主张）**：
T_msg(r)/T_msg(686) = (1+k/r)/(k+1) **= Θ(1/r)，r→∞ 时 → 1/(k+1)**
（k=1：2×）。686 在批处理轴上无对应物。这是本类中**唯一**的结构性
渐近分离轴（S2-S4 关闭其余所有轴）。

**定理 A3（下界匹配）**：任何加密选择子盲旋转类方案（固定密钥束）每
消息 ≥ c·(h+1)·ρ·ℓ·N·logN。本工作以常数 1+o(1) 匹配（r→∞），686 以
(k+1) 匹配。**"渐近最优 + 最优常数"即论文复杂度章的定稿主张。**

**诚实结论（写给用户）**：超常数的时间渐近优势在本类**已被 S1-S4
证明不可能**；可投稿主张为 A2+A3（批处理轴 Θ(1/r) 渐近 + 类最优），
辅以多项式噪声（N1）、修正安全唯一 ≥128、实测 1.66–1.84×。这是
欧密级的完整复杂度叙事——下界定理（含三个否定性结果）本身是贡献。
