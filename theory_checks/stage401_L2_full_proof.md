## 1. 形式设置

**定义 1.1（任务 SHIFT_{n,ρ}）**。给定 n = 2^κ 个槽密文
X = (x_0,…,x_{n−1})（环 R = Z[X]/(X^N+1) 上，各加密消息 μ_i），
秘密 v ∈ V，|V| = 2^ρ（ρ ≤ κ；H4 下 V = [0,2^ρ) 为间隙值域）。
任务：输出 n 个密文 Y = (y_0,…,y_{n−1})，使得对全部输入消息赋值与
全部 v ∈ V：Dec(y_j) = μ_{j−v mod n}。

**定义 1.2（选择门）**。元数 a 的选择门 g：输入 a 条密文线与
⌈log₂ a⌉ 个控制位（控制为密钥生成方已知、以加密形式内嵌于门的自举
钥中），输出 1 条密文线：其值 = 被控制选中的那条输入线。门的密钥
体积 ≥ c₀·a·s₀(λ)（消息空间含 a 个不同单项式选择）。

**定义 1.3（电路）**。DAG：源线 = X；内点 = 选择门；汇线 ⊇ Y。
**层式（宽度 n）电路**：线分 L+1 层；第 0 层 = X（恰好 n 条）；第
ℓ+1 层恰有 n 条线，每条 = 一个门，其输入线全部取自第 ℓ 层（容许重
复取同一线）。注：686/TFHE/本工作的乒乓累加器严格满足层式宽度 n
（每级每槽必经一个门——含控制为 0 的门，见注 1.5）。

**定义 1.4（均匀性，假设 H5）**。电路拓扑（DAG 结构）与控制位的
**布线**独立于 v：v 仅存在于各门自举钥的加密消息中。等价地：运行时
数据流（访问哪些门/钥、何序）对所有 v 相同。
**H5 的必要性（注 1.5）**：无 H5 时可为每个 v 专用硬连线电路（0 个
门），但拓扑即泄漏 v。686/本工作均以均匀蝶形满足 H5；它是 FHE 服务
端实现的标准保密条件（时序/访存不泄漏）。**H5 进入主定理假设列表。**

**定义 1.6（像集）**。对线 w，定义像集
S(w) = {i ∈ [n] : ∃v ∈ V, ∃输入赋值, w 的值 = x_i 的传递选取}。
归纳刻画：S(x_i) = {i}；门 g（输入 w_1..w_a）：S(g) = ∪_t S(w_t)。

**引理 1.7（像集-锥界）**。对任意线 w，|S(w)| ≤ 1 + m(w)，其中
m(w) = w 的反向锥（backward cone）中门数。
**证明**：对线的深度归纳。源线：|S| = 1 = 1 + 0 ✓。门 g 输入
w_1..w_a，锥门数 m(g) = 1 + Σm(w_t)（g 的锥 = 各输入锥之并 ∪ {g}；
门不重复计入因 DAG 无环）：
|S(g)| ≤ Σ|S(w_t)| ≤ Σ(1+m(w_t)) ≤ a + Σm(w_t)。
若 a ≥ 2：≤ 1 + (1 + Σm(w_t)) = 1 + m(g) ✓（a ≥ 2 时 a ≤ 1 + (a−1)
·…直接：Σ(1+m_t) = a + Σm_t ≤ 1 + (1+Σm_t) ⟺ a ≤ 2：**仅 a = 2
时成立**；a > 2 时：|S(g)| ≤ a·max(1+m_t) ≤ a·(1+m_max)：改为
**|S(w)| ≤ a^{depth}** 形式（下文引理 3.1 用乘法形式）。二值情形
（a=2）保留加法形式。∎

## 2. 第一层：无条件弱下界（任意 DAG，仅假设 H5）

**引理 L2-i(a)（触碰）**。SHIFT_{n,ρ} 的任意正确电路（H5 下）每相位
门数 ≥ n。
**证明**。反设某输出 y_j 为源线的直通（或两输出为同一线）。直通：则
y_j 的值 = 某 x_i 与 v 无关；取 v ≠ v' 使 j−v ≠ j−v'（mod n）（V 中
存在，因 |V| ≥ 2）；取消息赋值 μ_{j−v} ≠ μ_{j−v'}：正确性要求 y_j
在两控制下分别等于两者，矛盾。同线：y_j = y_{j'} ⟹ 值恒等 ⟹ 对任意
v，μ_{j−v} = μ_{j'−v}，取 v 使 j−v ≠ j'−v（mod n）与赋值矛盾。故
n 个输出为 n 条互异门输出线 ⟹ 门 ≥ n。∎

**引理 L2-i(b)（锥深/锥大小）**。每输出 y_j 满足 |S(y_j)| ≥ min(2^ρ, n)
（因 {j−v mod n : v ∈ V} 的大小 = min(|V|,n)），故（a=2 时由引理 1.7）
其反向锥 ≥ min(2^ρ,n) − 1 个门；特别地 ρ ≤ log₂n 时锥 ≥ 2^ρ − 1。
**证明**。S(y_j) ⊇ {j−v : v∈V} 直接由正确性；引理 1.7 给锥界。∎

**第一层结论**：任意 DAG（H5）：门数 ≥ n，且每输出锥 ≥ 2^ρ−1。
**一般 DAG 的 n·ρ 强形式：开放**（见 §5）。

## 3. 第二层：层式宽度 n 电路（真实实现模型）的强下界

**假设 H2'（层式宽度 n）**：电路为定义 1.3 的层式宽度 n 形式。
**模型忠实性引理 3.0**：686（Algorithm 1 蝶形）、TFHE 盲旋转、本工作
（sab_pvw_RGSW_monomial_mul / sab_rinput_RGSW_monomial_mul）的移动相
位均为层式宽度 n 电路。**证明**：逐一核对：每精度位一级；每级对每槽
恰好执行一个门（CMUX/NCMUX，控制位 = 该间隙位的加密值，位为 0 时门
仍在拓扑中执行——拓扑与 v 无关 ✓ H5 ✓）；级间为乒乓缓冲 ⟹ 分层 ✓。
∎（论文附代码锚点。）

**引理 3.1（可达性倍增）**。层式宽度 n、元数 a：第 ℓ 层任意线的
|S| ≤ a^ℓ。
**证明**：对 ℓ 归纳：ℓ=0：|S(x_i)| = 1 = a^0 ✓；第 ℓ+1 层线 = 门，
S = ≤a 个第 ℓ 层线的像集之并，|S| ≤ a·a^ℓ = a^{ℓ+1}。∎

**引理 3.2（层-数下界）**。L ≥ ⌈log_a min(2^ρ, n)⌉。
**证明**：输出层线 y_j 的 |S| ≥ min(2^ρ,n)（引理 L2-i(b)），而
|S| ≤ a^L（引理 3.1）。∎

**引理 3.3（每层门数）**。层式宽度 n 模型中每层恰 n 门（定义既含）。

**定理 L2-ii（层式强下界；主形式）**。在 H5 + H2' 下，SHIFT_{n,ρ} 的
任一正确层式宽度 n、元数 a 电路的每相位门数
  ≥ n · ⌈log_a min(2^ρ, n)⌉。
**证明**：引理 3.3 × 引理 3.2。∎

**引理 3.4（密钥预算-元数；H2 的作用形式）**。元数 a 的门自举钥体积
≥ c₀·a·s₀(λ)。若自举钥总预算 = O((h+1)·ρ·s₀(λ))（与 686 同阶，
假设 H2 的量化形式），则每相位可用门元数 a = O(1)，从而
⌈log_a min(2^ρ,n)⌉ = Θ(ρ)。
**证明**。每相位的选择容量 = 层数 × 每层选择 = (ρ/log₂a) 位 ×
（n 门共享同层控制）；密钥体积 ∝ 门族数 × a ≥ (ρ/log₂a)·a·s₀ =
ρ·(a/log₂a)·s₀ ≥ ρ·s₀（a/log₂a ≥ 1，a ≥ 2），且在预算
O(ρ·s₀) 内迫使 a/log₂a = O(1) ⟹ a = O(1) ⟹ 层数 ≥ ρ/O(1)。∎
（注：a/log₂a 在 a≥4 递增，故大元数反而费钥——元数 2 或 4 为预算
最优；686 与本工作取 a=2。）

## 4. 第三层：组装与逐相位叠加

**引理 L4（h+1 相位的独立性；依赖 H1）**。在单项式累积范式（H1）中，
h+1 个间隙相位的移动必须分别实现（不能合并为单一大相位）。
**证明**。合并后净移位 = Σd_t = n ≡ 0（mod n）：合并仅得恒等。各相位
间穿插的公开 sub_a 作用依赖于内容所在的**中间槽位**（秘密），故相位
序列承载不可合并的选择信息；等价地，"一次算出全部行选择的相位之和"
= 同态计算相位 φ = b − a·s 并从中提取单项式 = 范式外构造，其提取步
自身是 2N 点函数查表，需 SHIFT 类操作（循环依赖，见 stage399 §四）。
∎（此引理把 (h+1) 因子的成立范围显式绑定到 H1——如实陈述。）

**定理 LB-per-phase（组装）**。H1 + H2 + H2' + H5 下，每个间隙相位
≥ n·Θ(ρ) 个门；每门在 M_lin 下 ≥ Ω(N) 系数写（输出密文 N 系数），
M_fft 下 = Θ(N log N)。整个盲旋转：
  W ≥ (h+1) · n · Θ(ρ) · γ(N)。
结合 L3（行常数，stage399 §三）：每消息
  T(r) ≥ (h+1)·ρ·ℓ·N·γ(N) · 1，且本工作以 (1+k/r) 匹配、686 以
  (k+1) 匹配。∎

## 5. 第三形式的一般 DAG 开放性（如实注记）

一般 DAG（去 H2'）下我们只证得 L2-i 的 n 门 + 2^ρ−1 锥界；n·ρ 强形
式对无界扇出 DAG **开放**。已知的上界匹配构造（蝶形，n⌈log₂n⌉）是
层式的。若存在 o(n·ρ) 的非层式 DAG，将需要全新的选择电路技术；我们
将其列为开放问题并在论文中以正面措辞表述（"层式模型覆盖全部已知实
现；非层式优势是有趣的电路理论问题"）。
