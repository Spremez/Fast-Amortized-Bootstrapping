# stage417：预对齐联合 Packing and Batching——突破性设计

Date: 2026-09-10
状态：理论推导完成，待实现验证。

## 一、动机：交织方法的不可能性（stage416 结论）

交织方法的每消息成本永远大于独立 packing（两个结构性代价的乘积 > 1）：
1. 环膨胀 log(r₁·d)/log d > 1
2. sub_a 开销 h·(k+1)/((h+1)·ρ·(k+r₂)) > 0

这不是实现问题而是数学结构性结果——"多输入信息"必须由环结构或
sub_a 操作携带，携带成本 ≥ 摊销收益。

## 二、预对齐方案：消除多输入信息携带成本

### 2.1 核心洞察

不同输入需要不同 sub_a **当且仅当它们有不同的 mask a_ℓ**。
如果所有输入共享同一 mask，sub_a 就是单一明文单项式（免费）。

**在自举之前做一次同秘密钥切换**把所有输入对齐到公共 mask：
- 输入 ℓ: (a_ℓ, b_ℓ) under s_in，相位 φ_ℓ = b_ℓ - a_ℓ·s_in
- 预对齐: b'_ℓ = b_ℓ + KS(a_common - a_ℓ)，得 (a_common, b'_ℓ)
- 相位不变: b'_ℓ - a_common·s_in = b_ℓ - a_ℓ·s_in = φ_ℓ ✓

### 2.2 管线（退化为标准 packing）

1. 预对齐: r₁ 次同秘 KS on 输入环（维 n），成本 r₁·ℓ·n·log n ≈ 可忽略
2. Setup: r₁·r₂ 体密文（维 d），体 (ℓ,j) = TV_{ℓ,j} 旋转 b̄'_ℓ
3. Butterfly: 标准 packing 蝶形（共享选择子，体数 = r₁r₂）
4. sub_a: Y^{ā_common}（明文单项式，免费）
5. Extract: 逐体

### 2.3 密钥需求

- 标准: (h+1)·ρ 个间隙位选择子（与 packing-only 相同）
- 新增: **1 把同秘 RLWE→RLWE KS 钥**（加密 s_in under s_in）
- 移除: 交织设计的 2 把自同构钥（σ₋₁、σ_{1+N}）——钥束净减少！

## 三、理论优势（严格推导）

### 3.1 每消息成本

联合（预对齐）：
T_joint = (h+1)·ρ·n·ℓ·(k+r₁r₂)·d·log d + r₁·KS_align
per_msg = T_joint/(r₁r₂) = (h+1)·ρ·ℓ·(1+k/(r₁r₂))·d·log d + KS_align/r₂

独立跑 r₁ 次 packing（各 r₂ 体）：
T_sep = r₁·(h+1)·ρ·n·ℓ·(k+r₂)·d·log d
per_msg = (h+1)·ρ·ℓ·(1+k/r₂)·d·log d

### 3.2 加速比（联合 < 独立 ⟺ 真正的理论优势）

speedup = per_msg_sep / per_msg_joint = (r₂+k)·r₁ / (r₁r₂+k)

| r₁ | r₂ | 消息 | speedup | 判读 |
|---|---|---|---|---|
| 2 | 2 | 4 | 1.20× | ✓ 优势 |
| 4 | 2 | 8 | 1.33× | ✓ 显著 |
| 8 | 2 | 16 | **1.41×** | ✓ 最大（小 r₂ 大 r₁） |
| 4 | 4 | 16 | 1.18× | ✓ |
| 2 | 8 | 16 | 1.11× | ✓（r₂ 大时优势缩小） |

**最优区间**: r₁ 大、r₂ 小。直观：r₁ 增大 packing 摊销基数而不增成本；
r₂ 已大时独立 packing 本身已接近最优常数。

### 3.3 与下界的关系

下界（LB-F F1）: 每消息 ≥ (h+1)·ρ·ℓ·N·log N（匹配至行常数）
预对齐联合的行常数: (1+k/(r₁r₂)) → 1（r₁r₂ → ∞）
**联合仍然匹配下界，且行常数优于独立 packing 的 (1+k/r₂)。**

### 3.4 与纯 packing 的可叠加性（论文核心贡献的形态）

预对齐联合的每消息成本与"纯 packing 用 r = r₁r₂ 体"完全一致：
  (1+k/(r₁r₂))·d·log d per message

即：**batching 轴不引入任何额外成本，纯粹扩大 packing 的摊销基数
从 r₂ 到 r₁·r₂。** 这就是"可叠加"的严格含义。

叙事重构：
- Packing 轴: 每消息 (1+k/r) → 1（r 是 LUT 数）
- Batching 轴（预对齐）: 使 r ← r₁·r₂（把输入维度也纳入摊销基数）
- 联合: 每消息 (1+k/(r₁r₂))，比独立跑 r₁ 次 packing 快 (r₂+k)r₁/(r₁r₂+k) 倍
- **"Combining Packing and Batching" = 用 batching 扩大 packing 的
  摊销基数，无额外开销**

## 八、正确性定理（形式化全文）

### 8.1 设置

- r₁ 个输入 TRLWE 密文 {(a_ℓ, b_ℓ)}_{ℓ<r₁}，同一秘密 s_in ∈ {0,1}^n
- 相位 φ_ℓ[t] = b_ℓ[t] - Σ_i a_ℓ[i]·s_in[t-i]（负循环卷积）
- 公共 mask a_common ∈ R_n（任意公开值，如全零或随机公开多项式）
- r₂ 个测试向量 {TV_{ℓ,j}}_{ℓ<r₁, j<r₂}，每 (ℓ,j) 对一条消息
- 输出秘密 s ∈ {0,1}^N（标准稀疏间隙密钥）

### 8.2 定理 PA-1（预对齐相位保持）

设 KS_key 为同秘 KS 钥（加密 s_in under s_in，gadget ℓ=1, Bg=2^bg）。
定义预对齐操作：
  Δ_ℓ = KS(a_common - a_ℓ) := Σ_j digit_j(a_common - a_ℓ) · KS_key[j]
  b'_ℓ = b_ℓ + Δ_ℓ

则对每个 t：b'_ℓ[t] - Σ_i a_common[i]·s_in[t-i] = φ_ℓ[t] + e_KS[t]
其中 e_KS 为 KS 噪声（‖e_KS‖ ≈ 2^43 @ n=2048, Bg=2^23, σ_G=2^-49）。

**证明**：标准 KS 恒等式（与 N-KS 引理同构，输入环维 n）：
  Σ_j digit_j(x) · (s_in·2^{64-jBg} + e_j) = x·s_in + Σ_j digit_j(x)·e_j
代入 x = a_common - a_ℓ，加 b_ℓ：
  b_ℓ + (a_common - a_ℓ)·s_in + Σ digit_j·e_j
  = b_ℓ + a_common·s_in - a_ℓ·s_in + e_KS
  = (b_ℓ - a_ℓ·s_in) + a_common·s_in + e_KS
  = φ_ℓ + a_common·s_in + e_KS
两侧减 a_common·s_in：
  b'_ℓ - a_common·s_in = φ_ℓ + e_KS ∎

### 8.3 定理 PA-2（联合管线终态正确性）

预对齐联合管线（setup r₁r₂ 体 + 标准 packing 蝶形 + sub_a 单一
明文单项式 Y^{ā_common}）的终态：

体 (ℓ,j) 的槽 t 加密 TV_{ℓ,j}[q - φ_ℓ[t] mod 2d]（至噪声），
其中 φ_ℓ 为输入 ℓ 的原始相位（预对齐前）。

**证明**（归约到 M1/C1' 的标准 packing 正确性）：

预对齐后，r₁ 个密文共享 mask a_common 但保留各自相位 φ_ℓ。
设虚拟标量管线 P_{ℓ,j} 为标准 SAB（输入 (a_common, b'_ℓ)，TV_{ℓ,j}）。

P_{ℓ,j} 的正确性由 SAB 标准定理保证（相位 = φ_ℓ + e_KS）。
联合管线 = r₁r₂ 个 P_{ℓ,j} 共享一次蝶形旋转（多体结构）。

由 M1（MV-EP 的 lane 正确性与独立性）：多体外积在分块对角选择子
下逐体独立。由蝶形共享性（S1 语义）：同一旋转作用于全体体。
由 sub_a 一致性：ā_common 对全体体相同，明文单项式作用于整个密文。

归纳步骤与 C1'（stage406 定理 3.9）同构，唯二差异：
(a) 输入相位含 e_KS（增量噪声，不影响正确性格式）
(b) 不同体可有不同 b̄'_ℓ（setup 逐体放置）——标准 packing 已支持

终态：体 (ℓ,j) 槽 t 加密 TV_{ℓ,j}(X^{-(φ_ℓ[t]+e_KS[t]) mod 2d}) ∎

### 8.4 噪声推论

终态噪声 = 标准 packing 噪声（N1 递推）+ e_KS（输入级，被自举刷新）
= N1 噪声（e_KS 被自举过程消除，不进入输出）

实际影响：预对齐使输入噪声从 ~2^49 增至 √(2^98 + 2^86) ≈ 2^49（不变），
自举刷新后输出噪声与标准 packing 完全一致。✓

### 8.5 密钥束与安全

| 钥 | 数量 | 与标准 packing 差 |
|---|---|---|
| 间隙位选择子 | (h+1)·ρ | 相同 |
| 同秘 KS 钥 | 1 | **+1**（新增） |
| 自同构钥 | 0 | **-2**（交织设计的 σ₋₁、σ_{1+N} 不再需要） |
| 净变化 | | **-1**（钥束减少！） |

安全：同秘 KS = 标准 MLWE 假设（TFHE bootstrapping key 同构）。
密钥束减少 1 把 → 安全估计不变或略优。

## 九、复杂度定理（联合优于独立的充要条件）

**定理 PA-3**。预对齐联合的每消息时间
  T_joint = (h+1)·ρ·ℓ·N·γ(N)·(1 + k/(r₁r₂)) + O(r₁·n·log n)/(r₁r₂)

独立 packing（r₁ 次各 r₂ 体）的每消息时间
  T_sep = (h+1)·ρ·ℓ·N·γ(N)·(1 + k/r₂)

**T_joint < T_sep ⟺ (r₂+k)·r₁ < r₁r₂ + k ⟺ r₁ > 1（且 k < r₂）**

即只要有多于一个输入且选择子有摊销空间（k < r₂），联合就严格更优。

充要条件的推导：
T_sep/T_joint = (1+k/r₂)/(1+k/(r₁r₂)) = (r₂+k)·r₁r₂/(r₂·(r₁r₂+k)) = (r₂+k)r₁/(r₁r₂+k)

(r₂+k)r₁ > r₁r₂+k ⟺ r₁r₂+r₁k > r₁r₂+k ⟺ r₁k > k ⟺ r₁ > 1 ∎
