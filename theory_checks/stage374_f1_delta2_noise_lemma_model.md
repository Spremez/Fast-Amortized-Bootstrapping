## 1. δ=2 恒等加数步（对象）

对多体累加器槽 j，步（bit 对偏移 a=2^{2t}, b=2^{2t+1}）：

```text
out_j = U_j + Σ_{m∈{a,b,ab}} ( Src_m(j) − U_j ) ⊡ M_m
M_m ∈ MAT_TRGSW(ind_m, E_G)   # 均匀对角，ind_m = 联合指示子（三个中至多一个为 1）
Src_m(j) = 环绕时 −τ₋₁(U_{(j−off_m) mod n})，否则 U_{j−off_m}
```

digit=(0,0) 时三项指示子全零，out_j = U_j（自由加数，无外积）——
这就是 T2 行积账的 2^δ−1=3 次外积/槽/步。

## 2. 引理 G2（逐 lane 噪声）

**(i) 消息路径精确**：φ_q(out_j) = φ_q(U_{σ(j)}) + Σ_m ε_q^{(m)}，其中
σ(j) 为按 (v_a,v_b) 的平移（环绕含负循环符号）。由 M1 逐项 + 相位线性 +
G1' 恒等加数恒等式（机器验证）直接给出。

**(ii) 噪声项计数与最坏情形放大**：每个 ε^{(m)} 与一次 radix-2 CMUX 的
噪声项**同构**（= 选择子行噪声 × 操作数数位 + 分解/重缩放舍入；操作数
为步前状态的差分，量级由尺度不变量约束：SQ 核 |系数|≤2^{q−1}，标准核
数位 ≤Bg——每项界的形式不变）。全程 = (h+1)·(ρ/2) 个 δ=2 步，每槽每步
恰 3 项 ⇒ 每槽总 EP-噪声项数 = 3(h+1)ρ/2，对比 radix-2 的 (h+1)ρ。
次高斯求和（686 独立性启发式）最坏放大：

```text
√(3/2) ≈ 1.224   ⇔   +0.29 log2 单位
```

**(iii) 操作数量级注记**：三项操作数均为步前状态差分（radix-2 第二轮
操作数是过一次更新的状态）——每项界的形式与量级由同一尺度不变量控制，
不引入新的量级项。

**(iv) 选择子材料**：每步 3 个指示子（第 4 路=恒等，免）vs radix-2 每轮
1 个 ⇒ 盲旋转选择子族计数 ×1.5（非 ×2）；单个指示子尺寸与 bit 选择子
同。**密钥账修正**：F1 文档旧估"≈2×"按恒等加数形式修正为 **×1.5**
（仅盲旋转选择子部分；全钥束占比待 G4-ρ 式实测）。

## 3. 证明骨架

对 (i)：三个 ⊡ 项逐个用 M1（消息 ind_m ∈ {0,1}），相位线性求和；
digit≠0 时恰一项 ind=1 得 φ_q(Src_{m*})，其余贡献纯噪声；digit=0 时
三项全零指示，自由加数保持 φ_q(U_j)。恒等加数恒等式本身 = G1' 检查器
（GF(257)，N∈{8,16}，全偏移×全指示子×全槽 + 3 种子全链 + 双负控制）。
对 (ii)：计数论证 + 次高斯求和（引理 2.1/4.1 同式框架）。
对 (iv)：计数。∎（结构证明 + 机器验证；实测对账见 §4）
