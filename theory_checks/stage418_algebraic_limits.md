# stage418：多输入批处理的代数限制全面分析与新方向

Date: 2026-09-10

## 一、问题的代数本质（限制是什么）

SAB 盲旋转的正确性公式：
```
终端旋转(t) = b̄[t] + Σ_k ā[轨迹站点_k]  ≈  modswitch(φ[t])
```
其中 φ[t] = b[t] - (a⊗s)[t] 是输入密文的相位。

**代数限制的严格表述**：
sub_a 的功能 = **同态计算 a·s（相位提取）**。这不是任意的修正，
而是 LWE→RLWE 转换的核心运算。多输入 batching 的本质问题是：

> 能否用少于 r₁ 次独立的相位提取，同时处理 r₁ 个不同输入的相位？

**不可能性的直觉**：r₁ 个不同输入有 r₁ 个独立的相位 φ₀,...,φ_{r₁-1}。
相位提取需要"知道"每个输入的 a 值与秘密 s 的交互。由于 a 值不同
（不同密文的 mask），提取必须 per-input。

**但限制可能被突破的地方**：提取的 EXPENSIVE PART 是与秘密 s 的
交互（KS 运算），而 s 是共享的。如果能把"与 s 的交互"批量化，
限制就可以突破。

## 二、全部已知方向（含外部工作）

### 已在调查中的三个方向（子 agent 并行）
A. 轨迹感知预对齐
B. 分离修正（末端 per-input 校正）
C. 交织方法优化（KS 融合/批量/消除）

### 从文献发现的新方向

**D. CRT/模数打包（TCHES Li & Liu, 已实现）**
- 打包 r₁ 个不同模数的 LWE 密文到一个累加器（模数 CRT，非环 CRT）
- 一次盲旋转同时刷新全部 CRT 分量
- **已证明可行**（TCHES 论文有实测数据）
- 与我们的交织方法完全不同的打包机制

**E. 多值函数自举 CIM19 系（eprint 2023/1223 等）**
- 一次盲旋转评估多个 LUT（多值输入函数）
- 本质 = 我们的 packing 轴（r-LUT）
- 不直接解决多输入问题，但提供了不同的打包视角

**F. 环张量积（新提出）**
- 使用 R⊗R（双变量环），X 和 Y 独立旋转
- 每个输入用不同变量的旋转
- 问题：盲旋转需要处理两组自同构（代价可能翻倍）

**G. 非二幂环的 CRT 结构**
- Z[X]/(Φ_M) 当 M 非二幂时有 CRT 分解
- 自同构可能保持 CRT 结构（不同于二幂环的不可分性）
- 理论性方向，需验证与 FHEW 框架的兼容性

**H. 密钥共享（同间隙不同值秘密）**
- r₁ 个秘密共享相同的支撑位置（同间隙结构）
- 蝶形选择子共享（同间隙 → 同选择子）
- sub_a 仍 per-input（不同 a_l）
- 部分共享，不是完全解决

## 四、方向 D（CRT/模数打包）的深入分析

### 原理
将 r₁ 个 LWE 密文（不同模数 q_0, ..., q_{r₁-1}，两两互素）通过
CRT 打包到一个大多项式中。盲旋转的每步操作（单项式乘/条件移位）
自然作用于所有 CRT 分量。

### 关键性质
- **无环膨胀**：环维不变（与交织方法的 r₁·d 对比）
- **无 per-lane sub_a**：CRT 分量自然分离
- **已有实测数据**：TCHES 论文证明可行

### 与我们框架的兼容性
- CRT 打包作用于**输入密文**（LWE 样本），不是输出环
- 盲旋转仍然是标准 SAB 蝶形
- 选择子仍然是标准间隙位加密
- **兼容**：CRT 打包可作为我们框架的前处理步骤

### 预期性能
- 蝶形：与 packing-only 相当（同环维、同选择子）
- sub_a：可能免费（CRT 分量自然分离，不需 per-lane 修正）
- 总性能：理论上接近 packing-only（如果 sub_a 确实免费）

### 需要验证
1. CRT 打包的相位提取是否与 SAB 的间隙调度兼容
2. CRT 分量的噪声增长是否可控
3. 与稀疏密钥的交互（间隙结构是否被 CRT 保持）

## 七、方向 B 否定性结果（2026-09-10 子 agent 完成分析）

### 新数学发现：含 sub_a 的终态闭式

**定理（子 agent 机器验证，2400/2400 slots）**：
```
E_full(t) = −(b̄[t] + Σ_{m<m*(t)} ā[p_m(t)]) + Σ_{m*≤m<h} ā[p_m(t)]  (mod 2N)
```
其中 m*(t) 为该内容的秘密穿越相位（V=n 时每个内容恰穿越边界一次）。

**含义**：sub_a 修正不是简单总量 Σā ≈ a⊗s，而是按秘密分裂点 m*(t)
带 ± 号的站点累加。± 号的分裂点本身是秘密信息。

### 否定理由（三层）

1. **末端校正值不可公开计算**：Δ_l(t) = Σ_m ±ā_l[p_m(t)]（±由秘密
   m*(t) 决定）。若 Δ_l 可公开计算，取 a_l 为 delta 脉冲可解出密钥
   （矛盾）。机器验证：同一 (a,b) 不同秘密 s 给出不同 Δ。
2. **TRGSW 同态校正是循环的**：产生 Enc(X^{Δ_l(t)}) 需要以秘密稀疏
   钥为指针的盲旋转 = 正是 butterfly+sub_a 本身。成本 ≥ 重跑管线。
3. **与 packing 轴不兼容**：per-body 明文乘法破坏共享 mask。

### 与其他负结果的关系

此否定与 S2-S4（下界定理族）属同一家族：秘密置换信息只能由路由
消耗，不能事后廉价注入。入负结果目录 **C-12**。

### 对方向 A（轨迹感知预对齐）的启示

A 必须让 b' 的站点累加精确匹配上述秘密 ±分裂——比 stage417 §八
原证明更强。子 agent A 的分析正在检验这一点。
