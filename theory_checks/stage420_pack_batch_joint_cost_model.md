Date: 2026-09-10（本会话，stage419 之后的定量轮）。
环境：本机 WSL Ubuntu 24.04 / gcc 13.3，`build_wsl/pa2` 同构建配对
（正确性+相对性能口径；论文绝对性能口径仍以 dell 为准）。
探针：`probe_prealigned2`（预对齐联合管线，本轮加 setup 计时与
speedup 输出）、`probe_rinput`（interleaved Hom-Tr 批处理对照）。
参数族：in_N=256, out_N=2048, h=6, ρ=7, prec=3, k=1, l=1, Bg=2^23

## 一、成本模型（行计数定律）

**EP（外积）次数在所有变体中相同**——蝶形结构不变，只加宽行：

```
EP 数 / 管线 = (h+1) · ρ · n          （每个 EP 处理 (k + bodies)·l 行）
```

推导：sparse_mul = h+1 个选择子族 × 每族 ρ 个蝶形层 × 每层恰好 n 个
NCMUX/CMUX 对（NCMUX j<power + direct CMUX 共 n−power 个，和为 n）；
每个 CMUX/NCMUX = 1 次 mat-EP，作用于 (k+r) 行样本（代码锚定：
`mat_trgsw_alloc_mul_scratch((out_k + lanes) * l, ...)`）。
标量 TRLWE 路径（686 基线）：k+1 = 2 行。

**预对齐使 sub_a 退化为明文单项式**（共享 mask 下每站 n 次
X^{ā} 旋转，零 EP），联合管线的行模型因此**精确**成立：

```
每消息分摊行操作 = (h+1)·ρ·n·l · (1 + r₁r₂)/(r₁r₂)      [+ r₁ 次 KS（预对齐）]
基线（每 LUT 一次标量自举）= (h+1)·ρ·n·l · 2
基线（分离 packing，r₁ 次打包自举）= … · r₁(1+r₂)/(r₁r₂)
```

**渐近**（r→∞）：每消息 → k·(h+1)ρℓN log N，即标量 (k+1)=2 行的
**1/2 → 加速上限 2×**；与 stage398/399"匹配下界 + 行常数 (k+1)→1"
定案一致。预对齐 KS 是**每输入一次**（非每 (输入,LUT)），摊在 r₂ 上
后为低阶项。

**interleaved Hom-Tr 对照**：每站额外 2 aut-KS + rescale（Ψ + U_a），
行模型之外的正开销 → 理论即预示玩具尺度负收益（实测见 §三）。

## 四、理论-实测对账结论

1. **机制验证 ✓**：batch 与 pack 实测对称（§三表 2）——预对齐把
   多输入批处理精确归约到打包行模型，无额外同态开销。
2. **行扩展效率是唯一缺口**：bodies≤4 实现率 78-90%；bodies=8
   （9 行/EP）跌到 56-58%。原因：本探针走**未优化通用 mat-EP**
   （无 R4/R6 行瓦片旗标），9 行样本工作集（n=256×9×16KB≈37MB）
   逸出缓存且行瓦片不匹配。生产 packing 路径的 R6_FULLTILE 等旗标
   正是为此设计（历史生产数字 1.21×/1.81× 已证明旗标栈有效）。
   **修复路径明确：联合管线接入行瓦片化 EP 内核后重测**（预期
   bodies=8 回到 ≥85% 实现率）。
3. **FINAL 尺度优于玩具**：2×2 实现率 81%（1.300/1.600），且门
   0/8192——大规模下固定开销摊薄。
4. **诚实边界**：(a) 预对齐 b′ 在本探针为明文模拟，真实系统为
   r₁ 次 KS（理论低阶，需实测确认）；(b) WSL 为相对口径，论文
   绝对数字需 dell；(c) vs 分离 packing 的直接计时臂只在 dell
   stage417 有过（旧探针），新探针下待复测。

## 五、复现

```bash
# WSL, build_wsl/pa2 同构建
SAB_PA_R1=<r1> SAB_PA_R2=<r2> ./build_wsl/pa2/probe_prealigned2   # 6 reps: SAB_PA_REPS=6
SAB_PA_IN_N=2048 SAB_PA_H=42 SAB_PA_R1=2 SAB_PA_R2=2 SAB_PA_RPREC=7 ./build_wsl/pa2/probe_prealigned2
SAB_RINPUT_REPS=3 ./build_wsl/pa2/probe_rinput                     # interleaved 对照
```

计时口径：joint_total = setup（acc 装配）+ 蝶形（sparse_mul_binary）；
基线 = b 个 sab_rlwe_bootstrap_wo_extract 串行（含各自 setup）；
bpa 明文模拟（= 真实系统的 r₁ 次 KS）不在 joint_total 内，单列理论项。
