## 三、渐近复杂度定论（核心节）

### 3.1 统一成本模型（两类算法同框）

参数：输入环维 n（槽=r 输出行数），累加器环维 N，稀疏度 h，间隙位宽
ρ = ⌈log₂(max gap)⌉，gadget 深度 ℓ，秩 k，lane 数 r。
单次外积（EP）成本 = Θ((k+r)·ℓ·N log N)（行数 × N 维 FFT 卷积）。

**类约束（槽-指数耦合）**：蝶形槽圆覆盖指数圆 2N ⟹ 2N/n 为整数
单位 ⟹ **N ≥ n/2**（两类算法同受约束；实证：我们的 4096-in/2048-out
参数组恰在 N = n/2 上运行且全门通过）。

**每自举总工作**：
- 686（r=1）：(h+1)·ρ·n 次 EP × (k+1)ℓ 行 → 消息数 n（槽）
  ⟹ **每消息 = (h+1)·ρ·(k+1)·ℓ·N log N**。
- 我们（r-lane，r-LUT 或 r-input 同构，HT-10 正交可组合）：
  (h+1)·ρ·n 次 EP × (k+r)ℓ 行 → 消息数 n·r（槽×lane）
  ⟹ **每消息 = (h+1)·ρ·ℓ·N log N·(1 + k/r)**。

### 3.2 比值与定论

```
ours/686（每消息，同 N）= (1 + k/r)/(k + 1)   →  r→∞ 时 1/(k+1)
k=1：686 = 2×下界常数；我们 r=4 时 1.25×、r→∞ 时 → 1×
```

**定理（类内下界，待正式化 M-V2.5）**：任意"加密选择子盲旋转"类方案
（n 槽累加器、h+1 个秘密依赖旋转、每次决策为 N 维环上的 EP/门），每消息
成本 ≥ c·(h+1)·ρ·ℓ·N log N，且 N = Ω(n)。

**定论（诚实）**：
1. **类内不存在超常数分离**。686 与我们同为 Θ((h+1)ρℓ·N logN) 每消息
   （N = Ω(n)），二者都达到类下界（至常数因子）。
2. 我们的常数为 (1+k/r)，686 为 (k+1)：**常数优势 = k+1 倍（k=1 时
   2× 渐近上限）**，与 M3 行积定律 2(k+1)r/(k+r) 精确一致（M3 是该
   每消息定律的行计数形式）。
3. **"自举渐近复杂度优于 686"在时间维度上只有常数意义（≤2×）**。
   任何声称超常数分离的表述会被顶会审稿人按下界论证击穿——我们必须
   主动把这个下界写成定理，把主张定为"**渐近最优（匹配下界）+ 最优
   常数**"，而不是"渐近更快"。
4. 噪声维度：两方案均为 h-线性（多项式误差增长）——V2 标题的
   "polynomial errors" 对两类都成立；引理 1.7（Δ=Q²/T）给出紧常数，
   与我们 Thm 2（σ·2^{q+3.5}，±1 bit 实测）互证——这是融合点而非差异点。

### 3.3 若坚持"渐近更好"表述，可辩护的替代主张（按推荐序）

1. **（推荐）渐近最优定理**："本方案在每个消息摊销成本上达到盲旋转类
   的信息论下界（匹配至常数），且常数为最优 (1+k/r)→1，优于 686 的
   (k+1)；实测 1.66–1.84×（标准参数点，修正安全下唯一 ≥128）。"
   ——下界定理本身是新的、欧密级的理论贡献。
2. **双正交维度组合**（HT-10）：r-LUT ⊗ r-input 合并成 r₁r₂ lane，
   常数逼近 1/(k+1)：写成组合定理 + 小规模验证。
3. **参数-安全渐近**：修正混合攻击下 686 参数族系统性失效（124.5）而
   我们存活（130.4）——"唯一在修正安全模型下可行的摊销自举"是比
   常数加速更强的差异化主张。
4.（不推荐）出类尝试：跨自举选择子共享、mega-环打包等——与 FFT
   线性性冲突，预分析均无收益，仅当审稿人逼问才展开。
