## 1. 记号与实现锚定（定理只对以下实现结构陈述）

- 环 R = Z[X]/(X^N+1)，N = out_N（实验点 2048）；输出钥 s 二元
  {0,1}^N（pvmtmlwe_new_binary_key），hw = #s ≠ 0 ≈ N/2。
- 累加器 PVW_TMLWE（k=1, r=1）；选择子 MAT_TRGSW：gadget ℓ=1，
  Bg = 2^23，消息置于尺度 2^{64−Bg} = 2^41（mat_trgsw_monomial_sample，
  行 0 的 a 部与行 1 的 b 部各加 m·2^41·X^0；两行 = 独立 TMLWE
  (a_i; a_i⊗s + e_i)，σ_kg 为钥生成噪声，本构建实测 σ_kg = 2^16——
  采样器对 σ=2^−70 钥的经验常数，理论按参数携带）。
- **两种数位化约定（本工作的关键区分，全部代码锚定）**：
  - EP 侧 `pvmtmlwe_decompose`（l=1）：offset = 2^63；
    digit = ⌊(c+2^63)/2^41⌋ − 2^22 ⇒ **残差 ε_EP ∈ [0, 2^41) 单边**
    （下取整 + 平衡数位），μ_ε = 2^40，σ̃_ε = 2^39.21。
  - KS 侧 `polynomial_decompose_i`（t=1）：offset = 2^63 + 2^40
    （**半数位偏移 = 四舍五入**）⇒ 残差 ε_KS ∈ [−2^40, 2^40) 平衡，
    无均值。
- DFT 数值路径：spqlios 双精度（digits ⊗ selector 行）；
  实测相位级数值项 ν_DFT ≈ 2^43.0（micro 双路径差）。

## 2. 原语引理（每条：陈述—证明—机器佐证）

### 引理 N-ε（分解残差分布）

设 c 均匀于 Z_{2^64}。EP 侧数位化给出 ε(c) = c − digit(c)·2^41
（带符号代表），则 ε ~ U[0, 2^41)：μ_ε = 2^40，σ̃_ε = 2^41/√12 = 2^39.21，
E[ε²]^½ = 2^40.26。KS 侧 ε' ~ U[−2^40, 2^40)：零均值，σ̃ 相同。

**证明**：直接由两条数位化公式的整除结构（§1）；单边性来自 EP 侧
offset 缺少半数位项：对 c < 2^63 有 digit = ⌊c/2^41⌋ 故 ε = c mod 2^41；
对 c ≥ 2^63 对称地得 ε = (c−2^63) mod 2^41。∎
**佐证**：profiler calib_eps 实测 rms 2^40.22（预测 2^40.26）；
micro 实验直接转储 ε[0..5] 全正 + sum(ε) = N·μ（2.234e15 vs 2.252e15，
偏差为抽样涨落）。**勘误记录**：本会话早期"平衡 ±2^41"假设错误，
由白噪声对照实验（合成对称 ε → 45.28 vs 真实 49.16）裁决修正。

### 引理 N-EP（外积噪声恒等式，四项分解）

设 D = (D.a; D.b) 为操作数（m 意义下的差密文），S 为消息 m∈{0,1}
的选择子（两行 TMLWE 如 §1）。则 EP 输出相位**逐系数恒等**

φ_EP = dec(D.a)⊗e_0 + dec(D.b)⊗e_1 + m·(ε_a⊗s − ε_b) + ν_DFT

其中 e_0 = S0.b − (S0.a+m2^41δ)⊗s、e_1 = S1.b + m2^41δ − S1.a⊗s 为行相位
（含消息放置），ε_x 为操作数分量的分解残差，ν_DFT 为双精度数值项。
特别地：m=0 时第三项消失；D.a = 0 时 ε_a = 0。

**证明**：EP.a = dec(D.a)⊗S0.a + dec(D.b)⊗S1.a（b 部同构）；
按相位展开并用 2^41·dec(D.x) = D.x − ε_x（mod 2^64 逐系数）即得。∎
**机器佐证**：micro-EP 判别实验——探针内以精确整数负循环卷积重构
hand_EP，对四种 (m, 掩码) 组合 hand-vs-identity **max dev = 0**（恒等
式逐系数精确成立）；同选择子实例喂库路径与手工路径，库-手工相位差
= ν_DFT（rms 2^43.0，m 无关）。**勘误记录**：stage403 上界模型的
合成 EP 标定把消息差当噪声（选择子 bit=1 时 phase(R)−phase(A) 含
msg_B−msg_A ~ 2^61），上界 2^63.94 无效；正确参照 = 被选输入相位。

### 定理 N-DC（DC-游走：ε⊗s 的确定性主导项）★本会话核心发现

设 ε ∈ R 各系数 iid U[0, 2^41)（EP 侧残差），s ∈ {0,1}^N，hw = Σs。
记 H(i) = #{j ≤ i : s_j = 1}。则负循环卷积

(ε⊗s)[i] = Σ_{j≤i, s_j=1} ε[i−j] − Σ_{j>i, s_j=1} ε[i+N−j]

的均值（对 ε 取期望）为 **w[i] = μ_ε·(2H(i) − hw)**，且

(a) rms_i(w) = μ_ε·N/√12（s 均匀随机时；线性扫掠主导，涨落项
    2·√(i·p(1−p)) 贡献 √(N/3) ≪ N/√12）；
(b) max_i |w| = μ_ε·hw；
(c) 零均值涨落部分 rms = √hw·σ̃_ε = 2^44.2。

**证明**：期望线性；2H(i)−hw 为从 −hw 单调扫到 +hw 的阶梯，其均方
= 线性扫掠项 N²/12 + 涨落项 O(N)。∎
**佐证**：实测 w_rms = 2^49.18（推导 2^49.20），max = 2^49.99
（推导 μ·hw = 2^49.98）。**含义**：w 只依赖 (s, μ_ε)——**同钥同尺
度下每次 m=1 事件的 DC 图样完全相同**，跨事件**相干线性叠加**；
这是"孤立原语对得上、管线上界差 2^8"的完整解释（见 N1）。
**实现级优化候选（入册，不改动已测基线）**：pvmtmlwe_decompose 加
半数位偏移（与 KS 侧一致）即消灭 μ_ε ⇒ 每次 m=1 EP 噪声从 2^49.2
降至 ~2^44.5（−4.7 bit）。

### 引理 N-KS（自同构密钥切换噪声）

pvmtmlwe_keyswitch 的相位误差 = Σ_j digits_j(输入 mask)⊗e^{KS}_j +
ε_KS(mask)⊗s。平衡残差下无 DC 项：

σ_KS = √hw·σ̃_ε = 2^39.21·√1007 = 2^44.19。

**佐证**：ks_h 2^44.12 / ks_m1 2^44.37（0.07–0.2 bit，余量来自
digits⊗e^{KS} 白项与 hw 涨落）。零掩码输入时 dec = 0，KS 逐位精确
（CONV-CHECK 0/2048×2 双向验证，兼作库置换约定核对）。

### 引理 N-Ψ / N-suba（单步 Ψ 与 sub_a 噪声）

Ψ = KS(σ₋₁)→KS(σ_{1+N})→U_(0,1)→R₂：相位误差方差 =
σ_KS_m1² + ½σ_KS_h²（推导：t0/t2 各一次 KS，U 权重结构下
8σ²+4σ² 合成后 ÷4），实测 2^44.34–44.59 vs 推导 2^44.63。
sub_a（U_a→R₂）：σ² += ½σ_KS_h²（权重分析见 stage396 §3.1，
本轮实测复核 43.54 vs 推导 43.61）。重缩放 R₂ 的逐系数舍入 ≤1 单位
（**勘误**：stage396 §4 的"ρ ~ U(±½)·2^63、方差 2^126/12"项不存在
——整数 (c+1)>>1 的舍入是 ±½ LSB = 1 单位级；2^63 级结构是 HT-7
伪差，由 HT-7'/HT-8 协议吸收，不属于噪声）。

## 3. 定理 N1（管线噪声递推：相干轨 + 白噪声轨，精确事件计数）

**设置**：r-input 交织管线（stage396 HT-5 结构）：h 次（蝶形 × ρ bit
+ sub_a）+ 终蝶形 + 终倍增。每 bit 阶段对每槽恰一次 CMUX（选择子
消息 m = 该间隙该位）。记每槽确定性 DC 多项式 DC_t ∈ Z^N 与白噪声
方差 σ_t²：

- **setup**：DC = 0，σ² = 0（G0 门：逐位精确）。
- **bit (m=1)**（非首 bit，操作数掩码已污染为满熵）：
  DC_t ← DC_{src(t)} ∘ (Ψ 变换，若换位) + **w**；
  σ_t² ← σ_{src(t)}² + (1.5 若换位… σ_KS_m1²+½σ_KS_h²) + σ_EP1_white²；
  其中 σ_EP1_white² = σ_EP(1)² − w_rms²。
- **bit (m=0)**：σ_t² += σ_EP(0)²（DC 不变；数据不动）。
- **首 bit（setup 制式）**：操作数零掩码 ⇒ dec(D.a)=0 ⇒ 无 DC、
  无 ε 项：σ² += σ_EP(0/1)_setup²（实测 44.86/—）；换位槽 KS 精确。
- **sub_a**：DC ← U_a 移位变换（Y^{2a0}/Y^{2a1} 偶奇分裂，精确整数
  算术）；σ² += ½σ_KS_h²。
- **终倍增**：DC ← 2·DC；σ² ← 4σ²。
- **每槽终噪声**（even 抽取类）：σ_slot² = σ_t² + rms_even(DC_t)²。

**闭式界**（推论形式）：设 n₁ = 路径上 m=1 事件数、按相位分组
n₁ = Σ_p c_p（c_p ≤ ρ 为该相位内 m=1 计数）。上界（相位内全相干）：
σ_final ≤ √(Σ_p (c_p·w_rms·2)² + 4·Σ白项²·…)；下界（全白）：
σ_final ≥ √(n₁·σ_EP1²·4 + …)。实测（toy 点）落两者之间且与精确
递推差 ≤0.03 bit。**FINAL 参数外推**（h=42, ρ=7, n₁ ≤ 301，跨相位
U_a 移位部分去相关）：σ_int ≈ 2^55–2^56 ≪ 守卫预算 2^62 − |μ|max
——DFR 安全余量 >2^6；精确值以 FINAL 参数跑 profiler 复核（义务
I-6 时并入）。

**守卫位耦合**（6r 清单第 5 项）：HT-8 两位守卫 |μ|+|e| < 2^62 对
**消息通道列**成立（TV 量化 v·2^{62−p}，|μ| ≤ 0.875·2^62；本定理
噪声 ≤ 2^54 级）⇒ 终倍增不回绕、抽取精确（I-7 门 0/512 的理论
基础现已闭环为 N1 + HT-8）。**非消息列无守卫不变式**（见 §8）。

## 5. M-HT.4 定稿（替换 stage396 §4 的 EP 项形式）

**命题 HT-6'（管线噪声，定稿）**：r=2 交织管线终噪声

σ_int² = rms_even(DC_final)² + σ_white_final²

（DC 轨与白轨如 N1；σ_white² = Σ_events w_e σ_e²，事件权：m=1 EP
权 1（相干部分入 DC 轨）、m=0 EP 权 1、sub_a KS 权 ½、Ψ KS 权
1+½；所有 σ_e 为 §2 闭式原语）。**pair 噪声**：

σ_pair = √(σ_s² + σ_int_native²)，σ_int_native = σ_int/2。

对账：点 1 实测 pair rms 2^52.47 vs 预测 2^52.15（+0.32 bit）。
stage396 §4 的旧形式（"噪声增量 ≈ √(h/2·s_KS² + h·2^124/12)"）**作废**：
缺 EP 项、缺 DC 相干、舍入项错误。1711/Lemma 1-2 的次高斯合成
（π-可吸附）仍用于白轨的严格化（论文 §4 引用）；DC 轨是确定性的，
无需概率论证。

## 6. 尺度化 gadget 泛化（Wang Han Lemma 1.7 统一）

**推论 N-S（双模数变体）**：设 gadget 消息置于尺度 T/Q、容器 T、
输出重缩放 ≫(64−q)（SQ 路径，Thm 2 设置）。N-EP 恒等式逐项平移：
操作数数位舍入 ~ U(±2^{63−q})（Q 尺度操作数幅度 ≤ 2^{q−1}）；
选择子噪声项被 Δ = Q²/T 压制；重缩放舍入 2^{63−q}。合并即
γ' = √(Q²/T²·γ₁² + γ₂² + Q²/T²·γ₃² + γ₄²)（V2 草稿 Lemma 1.7
形式；γ₁ 选择子误差、γ₂ 操作数舍入、γ₃ 数位-钥误差、γ₄ 重缩放）。
在 q=16、N=2048、σ_G·T 实测标定下给出 **σ·2^{q+3.7}**，与 Thm 2
实测 2^{q+3.5} 差 0.2 bit（负循环折叠边界项，sq_theory §四已释）。
**N1 × N-S 的关系**：本文 §2-§3 是单模数平衡 gadget（矩阵路径）的
完整版；N-S 是双模数版的系数映射——论文 §4 以 N-EP 为主引理、
两条推论分别落到矩阵路径（N1）与 SQ 路径（Thm 2 升格为推导+验证）。
（DC-游走项在 N-S 中不出现：SQ 的数位化带半格偏移（四舍五入），
平衡残差——与 KS 侧同理，已在实现层面证实两类约定的分野。）

## 7. 引理 N-HYB（HYB 噪声账形式化，替换 stage404 §2.3 注记）

**陈述**：HYB（大环混合，stage404 §二）每相位的噪声 = (i) 大环 EP
噪声：N-EP 恒等式对环维 nN 等变（ gadget/卷积结构逐系数同分布，
消息单项式范数 1），故逐系数分布与 F1 的每槽 EP 相同（含 DC-游走，
若沿用 EP 侧数位化则 w' = μ_ε·(nN)/√12 相应放大）；(ii) packing-KS
噪声：N-KS 在大环的实例，σ = √(hw')·σ̃_ε'。**证明**：恒等式的
代数结构与环维无关（§2 证明未用维数）；KS 引理同理。∎
**推论**：LB-F 前沿（stage404）的 HYB 见证在噪声维度与 F1 同阶
（每消息系数级一致），不引入新的噪声类；crossover ρ*≈11 计算所
依赖的成本账不受影响；噪声余量按 N1 的 FINAL 外推同款复核。
