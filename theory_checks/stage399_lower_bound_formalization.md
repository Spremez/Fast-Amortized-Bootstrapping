## 二、计算模型 C0 与主定理

### 2.1 模型 C0(a, κ)（单项式累积盲旋转；选择门模型）

**对象**：n 个槽的累加器，每槽一个环 R = Z[X]/(X^N+1) 上 k mask + r
body 的密文；输入 RLWE (a,b) ∈ R_q^n；密钥 s 为 h-稀疏二进制。

**范式（H1，类定义）**：算法通过**顺序累积秘密选定的单项式因子**计算
第 j 行输出 X^{−φ_j}·TV，其中 φ_j = b_j − Σ_i a_i s_{j−i}（负循环行和）。
形式化：存在 T = T(算法) 个"选择步"，每步对每个槽施加密密选择的
{恒等, 单项式/自同构修正} 变换，步间穿插公开运算（明文单项式乘、
重标、加法）。**类条件：秘密依赖的全部计算经选择门实现。**

**选择门（H2，密钥规模条件）**：元数 a 的选择门一次从 a 个候选密文中
按秘密选定一个（含 a 路 CMUX/对角 Mat-MGSW EP）。门由自举密钥束
驱动，密钥束规模 κ = O((h+1)·ρ·s₀(λ, a))，即选择元数 a 与槽数 n
**无关**（多项式于安全参数与 log a）。**（超线性密钥制 = 边界外，
见 §四 S3'。）**

**代价（H3，两种口径）**：
- M_lin（无条件）：触碰 N 个系数的任何门 ≥ Ω(N) 系数操作；
- M_fft（FFT 模型）：环上的负循环卷积 = Θ(N log N)（FFT 最优性
  作为模型假设明示；非一般性证明）。

**密钥结构（H4）**：s 的支撑由 h+1 个间隙刻画，max gap < 2^ρ，
ρ = ⌈log₂(n/h)⌉ 量级（686/我们的 gap 条件密钥；对任意 h-稀疏键，
把支撑排序后同样成立）。

### 2.2 主定理 LB

**定理 LB**。在模型 C0 中（H1–H4），任意正确计算全部 n 行盲旋转的
算法，其总工作量满足

```text
  W ≥ c · (h+1) · n · ⌈log_a n⌉ · N · γ        （γ = 1 于 M_lin；
                                                 γ = log N 于 M_fft）
```

其中 a 为选择门的元数上界（由 H2 与噪声预算钉在 a = O(1)，见 L2'）。
特别地 a = O(1) 时 W = Ω((h+1)·n·ρ·N·γ)。

**匹配（上界）**：本工作的算法（以及 686 以不同行常数）以
W = (h+1)·ρ·n·(k+r)ℓ·Θ(N log N) 达到该界——行常数部分见 L3。

**推论 LB-1（每消息定律与批处理渐近，重申 A1/A2）**：
消息数 = n·r，故每消息
T(r) = (h+1)ρℓNlogN·(1+k/r)，而 T(686) = (h+1)ρℓNlogN·(k+1)；
比值 (1+k/r)/(k+1) = Θ(1/r) → 1/(k+1)。

**推论 LB-2（最优常数）**：T(r) 的可达下界（模型内）为
(h+1)ρℓNlogN·1（k 个 mask 行在 r→∞ 下被完全摊销）；本工作以
1+o(1) 匹配，686 为 k+1。

## 三、引理与证明

### 引理 S1（语义分解；GF(257) 双证 + 归纳证明）

**陈述**：对任意槽内容多项组 {c_j} 与移动量 v ∈ [n]，
蝶形移动（位分解实现）逐槽等于：
c'_j = c_{j−v mod n}，且当且仅当 (j−v) + v ≥ n（源内容跨界）时
对源施加 σ₋₁。

**归纳证明**（按位：对每位 i，功率 p = 2^i：若该位为 1：直达槽
j ≥ p：c'_j = c_{j−p}（无跨界，j−p ≥ 0）✓；换位槽 j < p：源
j−p+n ≥ n 恒跨界，施加 σ₋₁ 后落位 ✓。位间复合：跨界事件可加，
σ₋₁² = id 使复合后净作用 = 按总移量的单次判定 ✓（细节：两次跨界
的复合 = σ₋₁∘σ₋₁ = id，与"跨界计数奇偶"一致）。∎
机器佐证：M0 240/240（30 组随机密钥/输入/TV，全槽全系数）。

**S1 的作用**：它把"移动"的真语义钉死为**秘密循环移位 + 秘密条件
符号**——这正是 L1/L2 下界论证的对象（我们不依赖任何实现细节）。

### 引理 L1（每步触碰；无条件）

**陈述**：每个间隙步（移动量 v_t ≥ 1）需要 ≥ n/2 个选择门作用。

**证明**：v_t ≥ 1 的循环移位无不动点：n 个槽中每个槽的输出密文必须
（对不同的秘密值）等于**别的**槽的输入密文的密文函数；密文不能公开
搬移（搬移模式即秘密）；故每个输出 ≥ 1 个秘密依赖门；一个 2 元门至多
"裁定"2 个输出……更准确地：每个输出的取值由门计算，门数 ≥ n/a
（元数 a 的门至多产出 1 个密文）。⟹ ≥ n/a ≥ n/2 个门/步。∎

### 引理 L2'（ρ 因子：精度-受限元数论证；修复自由扇出漏洞）

**朴素版漏洞（诚实记录）**：曾有论证"每输出路径上选择树深度 ≥ log n，
且每门至多服务 2 输出 ⟹ ≥ n log n / 2 门"。**自由扇出破坏第二句**
（HE 中复制密文免费，一门输出可供全域）。故朴素版不成立，须修复。

**修复版陈述**：在 H2 下（密钥束 poly(λ, log a)，与 n 无关），实现
秘密循环移位的任意选择门网络的总门数 ≥ n·⌈log_a n⌉ / c₀（c₀ 为
常数），其中元数 a 被噪声预算钉在 O(1)。

**证明**（两半）：
(1) **元数-精度约束**：元数 a 的选择门 = 消息含 a 个候选的单块
Mat-MGSW EP。由 Lemma 1.7（噪声增长 ∝ 消息范数与 (Q/T) 预算）：
正确区分 a 个候选要求选择子消息携带 ≥ log₂ a 比特可用精度；在固定
安全参数 λ（固定 T/Q 与 gadget (ℓ, Bg)）下每次 EP 的可分精度 =
O(1) 比特 ⟹ **a ≤ 2^{O(1)}**。若允许 a 随 n 增长，则噪声预算被
指数消耗，h 步内不可解密（由 Lemma 1.7 递推显式给出）。
(2) **决策信息计数**（替换被击穿的路径论证）：秘密 v 的 ⌈log₂ n⌉
比特必须全部经由门的作用进入数据路径——具体地，输出槽 j 的密文
（作为随机变量，在密钥的条件分布下）必须对 v 的每个比特位有非退化
依赖（否则存在两个 v 值给出同一密文分布，与正确性矛盾——输出的
明文语义 X^{−φ} 依赖全部比特）。每个元数 a 的门向其输出路径注入
≤ ⌈log₂ a⌉ 比特的秘密依赖；门以密文为载体、扇出免费，但**依赖注入
总量**受门数约束：全部 n 个输出各自需要 ⌈log₂ n⌉ 比特的秘密依赖
注入，且不同输出的依赖不可共享（不同输出的明文语义随 v 的比特以
不可预测的不同方式变化——循环移位使各输出依赖不同的输入槽）。
形式化：定义门 g 的"秘密影响度" = 其控制比特与输入密文所携带的
秘密依赖比特数之和的上界 ⌈log₂ a⌉ + fan-in·influence；归纳可证
任何输出密文的秘密影响度 ≤ 其计算子图中门的 ⌈log₂ a⌉ 之和 ⟹
每个输出的子图 ≥ ⌈log n / log a⌉ 个门；不同输出的**必要**子图在
移位语义下不可重叠超过 O(1) 个门（一门只能以同一控制比特、同一
输出密文注入影响；两个输出需要不同的明文函数，共享门的影响注入
对二者至多为同一比特）⟹ 总门数 ≥ n·⌈log_a n⌉/c₁。∎

**诚实注记**：(2) 中"子图重叠 ≤ O(1)"一步是本证明最技术性的步骤，
需在成稿中写成完整引理（影响度单调性与门的重叠计数）；我们同时
提供第二条独立论证路线作为冗余：**代数次数路线**——秘密 v 的
log n 比特经门进入后，输出密文（关于密钥条件分布）须实现 n 种
明文语义；选择门网络计算的函数类 = 分段线性（门数 s 的分段数
≤ a^s）；n 种移位语义要求 a^s ≥ n ⟹ s ≥ log_a n——该路线只给
**总体** ≥ log_a n（弱于 n·log_a n），但完全严格，成稿中两路线
并列（弱形式无条件严格；强形式用影响度论证）。

### 引理 L3（行常数最优；精确）

**陈述**：对 k mask + r body 的打包密文，一次门作用（更新全部
k+r 个分量）需 ≥ (k+r)·ℓ 次行-卷积；标量逐 lane 需 r·(k+1)ℓ。

**证明**：输出的每个分量是 gadget 数字与选择子行的卷积和；每个
输出分量的信息量 = N 个系数，只能由 ≥ ℓ 次行积重构（gadget 深 ℓ）。
打包表示的输出分量数 = k+r（共享 mask 使 mask 分量不被 r 重复）；
逐 lane 表示 = r(k+1)。两者均达其表示的下确界。∎

### 主定理 LB 的组装

W ≥ (h+1) 步 × L1 的 n/a 门 × L2' 的 log_a n 级深度 × 每门
（M_lin）Ω(N) /（M_fft）Θ(N log N)，再乘 L3 的行因子到匹配侧。
686 与本工作均以 O((h+1)·ρ·n·(k+1 或 k+r)ℓ·N log N) 落在界上。∎

## 四、范围与成立条件（直接回答用户问题）

**下界成立的四个条件**：
- **H1（范式条件）**：算法属"单项式累积"范式（秘密经选择门进入，
  输出 = X^{−φ_j}·TV 的逐槽累积）。**这不是仅对 686 架构**——TFHE
  (CGGI) 盲旋转、FHEW、686、BatchBoot、本工作全部五行/族均可写出
  其 C0 解释（成稿将逐个给出解释引理）；686 是类成员而非类边界。
- **H2（密钥规模条件）**：自举密钥束 = poly(λ, log n)。突破此条件
  （per-(槽,步) 甚至 per-槽 预加密选择子）可把门数降到 (h+1)n 或 n，
  **该权衡（S3'）对类内所有方案对称开放**，包括 686——故不构成
  任何方案间的分离轴，成稿以"时间-密钥前沿"定理形式给出边界。
- **H3（代价模型）**：紧形式依赖 FFT 模型（卷积 Θ(N log N)）；弱
  形式（Ω(N)，纯信息移动）无条件成立。两形式并列陈述。
- **H4（密钥结构）**：h-稀疏 + 间隙界 ρ。对 686/我们的 gap-条件
  密钥精确成立。

**明确不声称的（开放问题，如实标注）**：
1. **类普适性**：是否存在脱离单项式累积范式的更快摊销自举（如
   "同态计算相位 φ 再提取"路线——其提取步自身是 2N 点查表，需
   自举类操作，已知尝试循环依赖）——**开放**。论文表述为"该类
   覆盖全部已知 ≥128-bit 摊销 FHEW 式自举"。
2. **FFT 最优性**（H3 紧形式）不做一般性声称。
3. **噪声下界**不在本文范围（Lemma 1.7 是上界工具）。

## 七、自我攻击测试发现与修补（2026-09-09 第二轮，审稿人视角）

以顶级审稿人身份对 §二–§四 攻击后，发现一个**真实的边界实例**，
必须写入文档（否则审稿人构造出它时会击穿"ρ 不可消去"的朴素解读）：

### 7.1 大环混合构造（H2 边界见证，记 HYB）

把 n 槽累加器表示为**一个大环**密文 R' = R[Z]/(Z^n+1)（维 nN，
Z-变量负循环 ⟹ 跨界符号自动 = S1 语义）。每间隙步：
1. **移动** = 乘秘密单项式 Z^{v_t}：**单次大环 EP**（选择子消息为
   keygen 已知的单项式——OS-MPMUL 在槽变量层的正确形态！S1 的
   M1 驳倒只适用于槽阵列表示，不适用大环表示）；
2. **抽取**（大环 → n 个槽 TLWE）：免费（系数抽取，同样本抽取）；
3. **sub_a 扭转**：n 次明文单项式乘（免费）；
4. **重打包**（n 个 TLWE → 大环密文）：packing-KS，成本 ≈ c_ks·n·
   N·logN（c_ks 为密钥束常数；按本仓尾声实测 ≈ 8–30）。

**成本对比**（每步）：蝶形 = ρ·n·N·logN；HYB = nN·log(nN) +
c_ks·n·N·logN ≈ (1 + log n/log N + c_ks)·n·N·logN。
**比值 = (1 + logn/logN + c_ks)/ρ**：n=N、c_ks≈10 时 ≈ 12/ρ。

**判定**：
- 实用参数（n ≤ 2^{13}，h ≥ 32 ⟹ ρ ≤ 8 < 12）：**HYB 恒慢**，
  蝶形最优 ✓（下界在实用域成立）；
- 渐近（n → ∞，h 固定 ⟹ ρ → ∞）：HYB 快 Θ(ρ)——**但 HYB 的
  选择子为 nN 维 ⟹ 密钥束 ∝ n，违反 H2**。
- ⟹ ρ 因子下界的正确表述：**H2 条件下成立；HYB 是 H2 边界外的
  见证**。这不是漏洞而是定理的一部分：时间-密钥前沿的具体实例。

### 7.2 主定理的加强表述（时间-密钥乘积形式）

**定理 LB-F（前沿形式）**：在 H1/H3/H4 下，每消息代价 T 与每消息
分摊密钥束 K 满足乘积下界

```text
  T · K = Ω((h+1)·ℓ·N·logN · (1+k/r) · log n / log(nN/K̂))
```

三个匹配点（前沿见证）：
| 制式 | K（每消息分摊） | T | 见证 |
|---|---|---|---|
