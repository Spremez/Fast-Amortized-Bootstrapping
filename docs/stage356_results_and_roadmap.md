### 2. 噪声（最大相位偏离，log2，消息预算 60）

### 3. 速度（每自举 27~32s 量级，同二进制 SQ/scalar 背靠背比值）

| 内核 | 结果 | 判读 |
|---|---|---|
| v1（分解→重缩放等价替换） | q16 +1.0%、q23 +1.7%（更慢） | 等速：分解环与舍入环同量级（理论预期） |
| **v3（融合重缩放+重组、零拷贝 ping-pong）** | **9 轮: 中位 −4.5%、min-of-9 −7.3%（28.89 vs 31.16s）、均值 −2.8%、7/9 轮更快** | **速度主张翻正**；SQ 每轮先测含冷启动劣势（偏保守）；待服务器 AVX-512 高统计确认 |

### 4. 安全（2026/279 预检 + 硬化实证）

- 预检表（11 参数集）: input 侧密度 ≤0.05 → 差距取满 15 bit；output 侧 0.25 → 9.2 bit；SQ 可吸收 = 2(23−q)，下限 q ≥ b_prec+10。
- **实证闭环**: σ_out+15 bit（恢复全部保守边际）+ aut-KS 联动细化下 SQ gate Pass、stock scalar 崩溃（上表）。
- 边界（诚实记录）: 硬化需 KS 联动，非 σ 单旋钮；残余 +1.7bit 在 packing KS（`SQKS_PACK_*` 已可调待扫）；绝对安全数用相对模型（基线=686 设计级），待 279 全文公式替换。

### 5. bind 契约（SQ×D4 汇合探针，直接服务 D4 UNIT3）

| 形状 | 结果 |
|---|---|
| ¼ 谱域预缩放 + <<2 恢复（满 torus F） | **代数不可能**: \|F\|·\|U\| ≈ 2^125 ≫ 53 位尾数，实测偏差 2^62.81（= UNIT3 整倍数误差形态） |
| 预缩放 2^-73 + <<11 恢复 | **Pass**: 相对偏差 2^-50.2（FFT 地板），消息预算余量 2^46 |
| 一般规则 | 两侧操作数尺度乘积 ≤ ~2^52；恢复移位 = 预缩放指数 − 通道尺度指数 |

### 6. 过程性发现（已入档，供全仓复用）

- 上游 bug: Windows 原生 `PORTABLE_BUILD` RNG 走 `/dev/urandom` NULL 流 → 堆损坏（建议 fopen 失败回退确定性 RNG）。
- 工程: 仓库 CRLF 源上 Python 文本替换静默失配（必须带 assert）；MinGW `-o x` 实际生成 `x.exe`；WSL /tmp 调用间会被清（D4 同样中招）。

## 二、效果一句话

**1711×686×279 的组合候选已完整落地并隔离**: 比 scalar 基线快（中位 −4.5%）、在恢复 15 bit 稀疏密钥安全边际的参数下仍正确（stock 同参数失效）、内核更简（无 gadget 分解）、q 成为独立设计旋钮，且已向 D4 输出经验证的 bind 契约。
