## 四、冲突与不可叠加（重要）

1. **SQ vs 整个 sub-decompose 融合轴**: A 线 1.62→1.75 的主升幅与 SQ 机制部分同轴——合并后必须整体重测，不可乘性外推。
2. **σ 硬化不对称**: stock 的 KS Bg 钉死无旋钮（σ 单调失效），SQKS_* 是 SQ 独有移植依赖。
3. **D4 ¼ 尺度规则**: 操作数尺度积 ≤2^52（2^-73 预缩放契约），合并须 per-stage q。
4. r>4 在稠密 (1+r)² 结构下已死；只有结构性变化（D/E/紧凑证明）能重开——D 构造上 r 无关。
5. 基准分裂历史：服务器为唯一基准（本地 −4.5% vs 服务器 −9.7% 仅方向一致）。
