## 1. 原语层：两条路线独立收敛到同一契约

| D4 认知（各有探针数据） | SQ 对应物（stage356） | 关系 |

## 2. bind 契约探针（本分支 `bind_contract_check`，直接服务 UNIT3）

- **¼ 谱域预缩放 + <<2 恢复对满 torus F 代数不可能**：|F|·|U| ≈ 2^125，53 位尾数远撑不住 mod-2^64 归约——实测偏差 2^62.81（纯垃圾）。这正是 UNIT3 "clean integer-multiple error" 的形态之一。
- **修正契约 Pass**：公开侧谱域预缩放 2^-73（乘积压回 ~2^52 安全区）+ <<11 恢复（spike 在 2^62）：相对偏差 **2^-50.2**（FFT 地板），对 2^-4 消息预算余量 2^46。
- 一般化规则：**两侧尺度乘积 ≤ ~2^52**，恢复移位 = 预缩放指数 − 通道尺度指数；与 SQ 内核的 `>>（64-q)` 是同一契约在不同 q 下的实例。

## 3. 算法层：正交，叠加优势相乘而非冲突

- D4 在"**累加什么**"轴（LUT 无关算子通道 + 晚绑定 + 强制 rerand KS）→ 摊销多次绑定。
- SQ 在"**怎么乘**"轴（无分解外积 + 融合重缩放 + 零拷贝 + q 旋钮）→ −4.5% 内核 + 279 硬化。
- 叠加路线：D4 蝴蝶跑在 SQ 内核上（通道尺度 q 参数化，¼→q=2 成为特例）；bind 直接复用 `product_raw`+重缩放（§2 契约已验证）；rerand KS 沿用 SQKS_* 可调 gadget（σ 硬化兼容）。合并噪声账本：D3 绑定放大 √2·‖ΔF‖₂ + SQ σ 项（被 ∆ 抑制）+ 共有 KS 地板——同单位可加，预计兼容。
- 合并收益：**晚绑定摊销 × 快内核 × 279 硬化** 三轴相乘；且原语统一后一份实现替代两份分歧代码。
- 时机约束：D4 gate 未绿（UNIT3 + 蝴蝶三重特征未闭）；§2 契约可作为其 UNIT3 的候选修复输入，但是否采纳由 D4 线程按其止损规则决定（隔离纪律）。
