# 自举后余量/深度作为实验输出维度（2026-09-01 定稿）

> 用户定调：自举后电路深度不作为输入约束，而作为**实验结果参数**输出，
> 体现"自举越快 + 自举后噪声余量越大越好"的二维评价。参照相关工作口径。

## 一、指标定义（三层，全部可由现有探针直接产出）

**层 1：瞬时余量（686 原口径，我们探针已内建）**
```
budget = 2^{-(prec+1)} · q        （686 一位 padding 编码的判决半径；
                                    prec=3 → 2^60，即我们一直用的"budget 60"）
H_max  = (prec+1+64) − log₂(max phase deviation)
```
一致性检查：实测噪声 57.5–58.7 → H_max = 1.3–2.5 bit ✓ 与此前"余量"口径完全一致，
只是现在形式化并作为**输出列**。

**层 2：生命周期余量（外部框架 H_bits，采纳）**
```
V_cap = ((T_dec − |μ| − b_det)/z_sg)²,  z_sg = √(2ln(2M/ε_life)),  M = N_out·Q_BS
H_bits = ½log₂(V_cap / V_out^certified)
```
ε_life 与 M 同样作为**输出扫描维度**（报告 H_bits(M) 曲线），不再要求用户预设。

**层 3：自举后容量曲线（本日新增实测，stage364）**
自举后施加 k 次外积（乘 1 的 TRGSW 选择子，输入密钥域），逐次测噪声：
```
slope_EP = 噪声增长（bit/次外积）      ← 实测斜率
depth_EP = ⌊(budget_log2 − noise_0) / slope_EP⌋   ← 输出的"还能算多少"
```
线性/加法、KS、旋转等算子类按同法各报一列（slope 近似可由 EP 类推 + 选测验证）。

## 二、相关工作口径（写入论文 evaluation 的措辞基准）

| 工作 | 口径 | 我们的对应 |
|---|---|---|
| 686 | phase deviation vs message budget（我们探针镜像的打印即其口径） | 层 1（同口径直接可比）|
| TFHE/TFHE-rs 惯例 | noise margin（bit）+ 剩余门数/层级 | 层 1 + 层 3（比其更细：逐算子斜率）|
| 1711（SQ 理论来源，FHEW 系）| gate 级噪声增长表 | 层 3 的 EP 列 |
| BatchBoot | 失效概率 + ms/msg | 层 2（ε 扫描）+ 主表 |
| 外部联合定参框架 | H_bits=½log₂(V_cap/V_out) | 层 2（采纳其形式，参数改输出）|

**差异化**：没有竞品同时给出"同安全门槛下的 (自举时间, 初始余量, 每算子斜率, 最大深度)"四元组
——这正是用户要的全面性展示。

## 三、平衡档完整数据（stage363 全量收割，2026-09-01，全 gate Pass）

**标量（3-bit）**：

| 分支 | SQ 噪声 | stock 噪声 | SQ 时间 | stock 时间 |
|---|---|---|---|---|
| 最小修正 h=41, σ+11 | 57.73 | 58.72 | **12.7s** | 13.9s |
| 平衡档 h=52, σ+0（原ρ） | 57.79 | **57.81** | 16.7–18.4s | 19.0–21.7s |

**r-lane r=4（含路径A；rp=7 与 rp=9 实测等价——实际采样距离均为 7）**：

| 分支 | stock | SQ | pathA | pathA/stock |
|---|---|---|---|---|
| h=41 σ+11（stage358 静场） | 52.4s | 50.5s | 43.5s | 1.20× |
| **h=52 σ+0（平衡档）** | 61.3s | 60.8s | **50.5s** | **1.21×** |

**平衡档的完整判读**：
1. **代价**：r-lane +17%（61.3/52.4），标量 SQ +32–45%（含负载抖动；EP 计数 +26%）
2. **收益**：stock +0.9 bit 余量（58.72→57.81）；SQ 零收益（57.73→57.79）
3. **路径A 因子对 h 稳健**：1.20×（h=41）→ 1.21×（h=52）——工程收益不依赖安全分支
4. **SQ 与 stock 在平衡档下仍平价**（0.99）
5. **结论**：SQ 选 h=41+σ+11（同余量更快）；只有 stock 型部署才值得为 +0.9 bit 付 17%；
   B_gap 目标 7 与 9 实测等价（接受到的密钥实际距离都是 7）
6. ⚠ 以上安全判定基于 279-only 校准；366/1060 组合审计（E4）未完成前，
   平衡档的 ~20 bit 预留余量正是为未整合攻击准备的——E4 结果可能改变推荐
