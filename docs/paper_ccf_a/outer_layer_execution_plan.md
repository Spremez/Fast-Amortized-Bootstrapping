## 0. 闭环纪律（所有工作流的公共规则）

1. **理论主张三选一闭环**（可叠加，主张等级随之升高）：
   a. 手写证明（可审查的归纳/代数论证，落到 theory_checks 文档）；
   b. 机器检查器（GF(257)[X]/(X^N+1) 精确验证 + ≥3 个负控制，复用 D2/F1
      检查器框架）；
   c. 实测对账（预测/实测比值 <1.3，样本与门测试齐全）。
2. **性能主张**：同构建内部对照唯一口径；主表 ≥6 试；correctness 门
   0 失配；跨构建数字只作背景并标注。
3. **投影义务**：任何投影数字必须给出公式、参数来源与假设清单，标注
   "投影"；对应 G 门不过即关闭该候选或降级为组件结果。
4. **等价先行**：任何调度/结构/核算术变更，先过逐步 oracle 等价
   （686 标量路径为不可变 oracle），再进性能测量。

## 1. T2 种子推导（本轮新理论产出，first-cut）

**问题**：radix-δ（每步消化 δ 个位差 bit）在行积意义下何时优于 686
radix-2 蝶形？F1 的 δ=2 是首个实例。

**模型**（假设 A1–A4，待 stage373 校准）：每次 MPmul 作用于 n 槽；
每槽每步做 2^δ 路联合指示子选择，其中"原地不动"（数字=0）项为**自由
torus 加数**（无需外积）⇒ 每槽每步 **2^δ − 1** 次 MV-EP；每槽每步的
操作数谱**分解一次、复用 2^δ − 1 次**（每个槽作为源恰被全部非零数字
偏移用到）。记 k=1, ℓ=1；D/F/I = 单分量 分解/正向 DFT/逆向 DFT 代价，
A = 单次 DFT 域乘加；r = lane 数。

每 MPmul 总量（radix-δ，δ | ρ）：

```text
事件数      E(δ) = (ρ/δ)·(2^δ − 1)·n
分解+正向   (ρ/δ)·n·(1+r)·(D+F)
dense 乘加  E(δ)·(1+r)²·A
逆向 DFT    (ρ/δ)·n·(1+r)·I
选择子材料  (ρ/δ)·(2^δ − 1) 个/步（radix-2 为 ρ 个 ⇒ 钥匙 ×(2^δ−1)/δ）
```

**定理种子（胜利条件阶梯）**：radix-δ 优于 radix-2 ⟺

```text
D + F + I  >  (1+r)·A · (2^δ − 1 − δ)/(δ − 1)
δ=2:  D+F+I > (1+r)·A          （阈值系数 1）
δ=3:  D+F+I > 2·(1+r)·A        （系数 2）
δ=4:  D+F+I > 3.67·(1+r)·A     （单调变陡）
```

**三个直接推论**：

- **P-a（F1 投影修正，重要）**：f1_mat_empmul_theory.md 的
  "EMPmul 2.2×（对标量）× 矩阵 1.75× ≈ 3.8×" 复合投影**无效**——两者
  消费同一份"分解共享"资源，属双重计数。诚实边际 = 上述公式。以
  stage322 时代画像（r=4 时 dense 乘加 ≈48%）估算 D+F+I ≈ 5.4A，
  (1+r)A = 5A ⇒ δ=2 在 r=4 边际 ≈ +8%（非 +30%）；**其有利域在
  r ≤ 2（分解主导区），与矩阵批处理（r ≥ 2 甜点）互补而非相乘**。
- **P-b（自由加数消除）**：指示子形式中"原地"项可作自由加数消除
  （4 项 → 3 项），这改变 F1 引理 F1-1 的表述；G1 检查器需相应扩展
  （4 项恒等式 → 恒等加数 3 项恒等式，工作量小）。
- **P-c（C5 升优先级的依据）**：stage322 时代全自举份额 = 盲旋转 EP
  57.6% / 物化+尾声 38.1%——**尾声占比远大于 F1 的理论边际**；联合
  packing（C5）攻击的是 38% 份额，期望收益 > F1。

**假设清单（stage373 必须校准）**：A1 均匀代价模型（忽略访存/缓存）；
A2 自由加数消除后噪声项按 2^δ−1 个选择子计（G2 义务）；A3 环绕源的
τ₋₁ 融合代价 ≈ 谱域一次置换（待 G2/G3 量化）；A4 (h+1) 步稀疏调度结构
不变。校准实验 = stage373（§3）。
