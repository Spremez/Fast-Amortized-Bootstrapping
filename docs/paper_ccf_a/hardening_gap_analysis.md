# σ+15 硬化下的完整性能对比（缺失分析 + 补测计划）

## 你发现的问题

### 问题 1: "stock 结构上不可能" 的说法不准确

我们只测了 stock + σ+15 (Bg=23 固定) → FAIL。但 stock 的 Bg 是可调参数：

- Bg 从 2^23 降到 2^8: KS 噪声回到预算内
- 代价: KS 分解层从 ~3 层增到 ~8 层 → 更慢
- 我们没测这个代价

### 问题 2: 全优化 r-lane 的 1.68× 是在不修正安全下测的

路径 A 在 σ+15 下同样面临 KS 噪声问题。9 个优化旗标都是针对 Bg=23 调的。修正安全后性能降多少——完全未知。

## 正确的论文叙事

```
                    不修正安全(假128)     修正安全(真128, σ+15)
────────────────   ──────────────────   ─────────────────────
686 标量              6.40 ms/msg          FAIL / ??? (Bg调小后多慢?)
SQ 标量               5.74 ms/msg          5.80 ms/msg (+1.1%)
全优化 r-lane r=4     ~3.8 ms/msg          ??? (需测)
SQ r-lane r=4         5.88 ms/msg          ~5.94 (估)
────────────────   ──────────────────   ─────────────────────
安全声明              117-122 bit ✗        ≥128 bit ✓
```

**关键论点变化**：
- 原叙事："SQ 是唯一能硬化的" ← 不准确（stock 调 Bg 也能硬化）
- **正确叙事**："SQ 是唯一以近零代价(+1.1%)硬化的；stock 和路径 A 的硬化代价未知但可能很大"

## 补测实验（三个）

### 实验 A: stock 标量 + σ+15 + Bg 调小
- 设 σ=2^{-35}，Bg 从 23 降到 8/12/16
- 测 gate 是否 Pass + 时间
- 预期: 能工作但显著变慢（分解层 ×2.7）

### 实验 B: 全优化 r-lane + σ+15
- stage355 旗标集 + σ=2^{-35}
- 需要同时调 Bg（否则 FAIL）
- 预期: 优化旗标可能对新 Bg 不再最优

### 实验 C: SQ r-lane + σ+15
- SQ + σ=2^{-35} + SQKS_AUT 联动
- 预期: +1.1%（SQ 的 ∆ 抑制几乎不受影响）

## 论文最终叙事（取决于实验结果）

**如果 A 和 B 都显著变慢（>10 ms/msg）**：
> "在真实 128-bit 安全下，SQ 是唯一的高性能方案（5.80 ms/msg）。
> 所有基于 gadget 分解的方案（stock 标量、优化 r-lane）在硬化后
> 都面临显著的性能退化。SQ 的 ∆ 抑制使其硬化代价仅 +1.1%。"

**如果 A 或 B 在硬化后仍然很快（<6 ms/msg）**：
> "存在速度-安全 trade-off：工程优化在不修正安全时最快（1.68×），
> 但在修正后退化。SQ 在两个维度都保持竞争力。"
