# 完整实验矩阵规划（2026-08-31 最终版）

## 设计原则

1. **安全完整性**：每行实验在相同的 (h, σ) 下对比所有方案
2. **方案覆盖**：stock 标量 / SQ 标量 / stock r-lane / SQ r-lane / 优化 r-lane（路径A）
3. **σ 梯度**：从 0（原参数）到 +15（保守），覆盖实际差距和理论上界
4. **补救路径**：stock 调 Bg / 路径A 调参数后的表现
5. **多维指标**：gate / 噪声 / 时间 / 每bit 分摊

## 第一部分：stock 在 σ 梯度下的生死线（Phase 1）

**目的**：确定 stock 标量在不同 σ 修正量下的 gate 和性能

| # | h | σ shift | 方法 | Bg | 预期 | 优先 |
|---|---|---|---|---|---|---|
| 1.1 | 42 | +0 | both | 23 | 都 Pass（已测） | ✓ |
| 1.2 | 42 | +1 | both | 23 | 都 Pass（宽松） | |
| 1.3 | 42 | +6 | both | 23 | 都 Pass（中等） | |
| **1.4** | **42** | **+11** | **both** | **23** | **stock 边界** | ★★★ |
| 1.5 | 42 | +15 | both | 23 | stock FAIL（已测） | ✓ |
| 1.6 | 42 | +11 | stock | 16 | 如果 1.4 FAIL | ★★ |

**关键问题**：1.4 的 stock 是 Pass 还是 Fail？
- Pass → stock 在真 128-bit 下能工作，对比性能
- Fail → 进入 1.6/1.7 的调参补救

| 2.1 | 42 | +0 | opt-rlane | 无 | ~3.8ms/msg | ★ |
| **2.2** | **42** | **+11** | **opt-rlane** | **待定** | **??? ← 论文核心** | ★★★ |
| 2.3 | 42 | +6 | opt-rlane | 待定 | 中间数据点 | ★ |

**关键问题**：路径 A 的 1.68× 在 σ+11 后降多少？
- 如果还较快（<6ms）→ 路径 A 是修正安全下的最快方案

**构建注意**：优化 r-lane 需要 stage355 旗标集 + 可能的 Bg 重调。

## 实验依赖关系

```
Phase 1 (stock σ 生死线)
  ├── 1.4 Pass → Phase 4.1 用 1.4 数据
  └── 1.4 FAIL → Phase 1.6 (Bg=16) → Pass → Phase 4.1 用 1.6 数据
                                └── FAIL → Phase 1.7 (Bg=8)

Phase 2 (路径 A)
  ├── 2.2 Pass → Phase 4.3 用 2.2 数据
  └── 2.2 FAIL → Phase 2.4 (Bg 调整)

Phase 3 (SQ 确认) → Phase 4.2/4.4 数据

Phase 4 (综合对比) ← 依赖 Phase 1-3 的结果
Phase 5 (融合尝试) ← 可与 Phase 4 并行
Phase 6 (多集验证) ← 依赖 Phase 4 确定最优配置
```
