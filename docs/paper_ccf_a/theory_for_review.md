## 1. 686 原始算法（基线，scalar）

**输入**：TRLWE in=(a,b)（s_in 下）；TV：TRLWE 平凡加密 LUT。
**Setup**：acc[i] = X^{b[i]} · TV，i∈[n)。
**盲旋转**：对 s_in 的 h+1 个稀疏步，每步对**整个 n 数组**做单项乘
（每精度位：换位槽 NCMUX（X⁻¹ 自同构 + aut-KS）、直达槽 CMUX）+ SubA 数位减。
外积计数 S=(h+1)·ρ·n。**尾声**：逐槽抽取 + packing KS + hw-KS。

## 2. 矩阵外积拓展（本工作贡献 1；路径A=其工程优化）

**改变**：累加器数组元素 TRLWE → **PVW_TMLWE**（1 掩码 a + r 个体 b_j 共享）；
选择子 TRGSW → **MAT_TRGSW**（(1+r)ℓ 行）。矩阵外积
MV-EP(c, C) = Σ_{i≤r, j<ℓ} Decomp_j(c_i) ⊗ C[iℓ+j]。
**一次盲旋转服务 n×r 个消息-LUT 查询**；外积计数不变、每 lane 摊销 ÷r；
分解行数 2r → (1+r)（共享掩码的结构性节省）。

**正确性**：每 lane 的噪声路径与 scalar 逐项相同（同一选择子、同一调度）；
实测：路径A↔SQ 交叉一致性 gate 27/27（stage358）+ 噪声 10-trial
pair σ −6.601 vs stock −6.535（stage359，旗标噪声中性）。

**蝶形 MonomialMul 与 dual-sub**：每 bit 换位槽 j<power 经 X⁻¹ 旋转后与
直达槽配对，(rot−p, rot−q) 一次向量化双减，两输出各一次矩阵外积——
拓扑上 k=2 是共享上限（每个 rotated tail 恰参与 2 个输出的代数恒等式）。

## 3. SQ 尺度量化外积（本工作贡献 2）

### 3.1 算法（语义）

- **不变量 I1**：盲旋转全程累加器为 Q 尺度整系数多项式
  （setup 量化 ×2^q；每步外积后融合重缩放 >>=64−q 保持）。
- **不变量 I2（无回绕）**：|系数|_∞ ≤ 2^{q−1}+累积噪声 ≪ 2⁶³（q=16）。
- **外积核**：Acc 的整数谱（spqlios 低字精确卷积）⊗ 选择子谱（Bg_bit=q 加密）
  ——**gadget 分解被消除**：Q 尺度累加器本身就是单一数位。
- **NCMUX**：精确升移 <<(64−q) → 复用 stock aut-KS → 舍入降移（一次 q-bit 舍入）。
- **末尾**：torus 提升（一次移位）。

### 3.2 Theorem 1（消息路径精确性）

**陈述**：在 I2 下，μ·2^{64−q} ⋆ c >> (64−q) = μ·c 对所有调度步精确成立；
SQ 盲旋转的输出消息 = stock 盲旋转的输出消息（同 TV、同密钥）。

**证明**（归纳于步）：
1. *基础*：setup 量化 c₀ = round(torus·2^q)，消息位于高 p 位，|c₀|_∞ < 2^q ✓ I2。
2. *归纳步*：外积 = 整数卷积（mod 2⁶⁴ 低字）+ 移位。整数卷积对消息线性且
   I2 保证乘积不回绕 → (μ·2^{64−q} ⋆ c) >> (64−q) 中消息项精确还原为 μ·c；
   噪声项见 Lemma 1。融合重缩放的舍入 R 满足 |R|_∞ ≤ 2^{q−1}（单次 q-bit 舍入），
   归纳维持 I1/I2。
3. *终止*：ρ(h+1) 步后累加器仍在 Q 尺度；末尾提升精确（移位）。
   总消息路径舍入 = 0；总舍入噪声 = 每 NCMUX 一次 q-bit 舍入的累积。
∎（对应 `sab_sq.c` 的 assert 与 24/24 gate）

### 3.3 Lemma 1（∆ 抑制）

**陈述**：选择子噪声 e（σ_G）对累加器的贡献系数：
stock 为 σ·2^{27.1}（KS 噪声 ∝ σ·2^{Bg}，~140 次/slot），SQ 为 σ·2^{q+3.5}；
比值即 ∆ = Q²/T = 2^{2q−64}（q=16 → 2⁻³²）。**q 每降 1 bit 换 2 bit σ 余量。**

**推导要点**：Q 尺度下选择子的有效噪声进入累加器需经
（×2^{64−q} 谱乘）与（>>64−q 重缩放）对消，净系数 2^{−(64−q)}·2^{q}=2^{2q−64}；
而 stock 的分解数位放大（Bg/2 ≈ 2^{22}）与 ~140 次 KS 累积给出 2^{27.1}。

**实验闭环**：σ 梯度三档（2⁻⁵⁰/2⁻³⁵/2⁻³⁵+15）噪声均在预测 ±1 bit；
σ+15 后 SQ 59.36（预测 ≈59.1）。

### 3.4 理论优势（三线，均有实测）

1. 速度：消分解 → 标量 SQ/686 = 0.897（三配置 0.894–0.898 稳定）；
   r-lane 平价（分解成本占比 ∝1/r）。
2. 余量：σ+15 仍 Pass；与 stock 的余量差在硬化后扩大（+1.0→+2.6 bit）。
3. 结构解耦：SQ 对 σ_G 不敏感 → 平衡档实验中 stock 付 17% 买 0.9 bit、SQ 零收益。

## 4. 安全推导链（贡献 3）

1. **攻击组合**（min，不叠加）：uSVP / dual-hybrid / HD（合并论文公开代码）/
   lattice-MITM-hybrid（新 lattice-estimator）/ 组合层 T3′（本工作闭式）。
2. **条件熵修正**：rejection 采样 ⇒ 条件分布均匀于接受族 ⇒
   熵损失 = −log₂ p_accept（p 由逐行复刻 `get_min_prec` 的 MC 计算）。
   T3′(n,h,t) = (log₂C(n,h) − loss(n,h,t) − log₂n − δ)/2，δ=7.38。
3. **结论**（§1.1 表）：h=39 → 124.5 失败；**h=42 → 131.8 ✓**（两条独立攻击线
   相差 <2 bit 互证）；BSK 在原 σ 即 136.2（论文自身代码实测）。
4. **分布如实声明**：三元交替符号（熵损 h−1，不改绑定层）；gap 条件化已计入。
