## 二、BatchBoot 的关键数据（最危险竞品+最佳方法论模板）

**BatchBoot 在他们机器上同机测了 686（本仓库）**：
- Boot2 (n=2048): 686 = 8.09 ms/msg, BatchBoot = 3.57 ms/msg (2.3×)
- Boot4 (n=2048): 686 = 8.65 ms/msg, BatchBoot = 3.60 ms/msg (2.4×)
- Boot8 (n=4096): 686 = 57.34 ms/msg, BatchBoot = 25.11 ms/msg (2.3×)

**但另一个组（068/Lin-Wu）测同一代码**：
- n=2048: 686 = 2.53 ms/msg（比 BatchBoot 测的快 3.2 倍！）

**→ 同一代码跨机器差 3.2×，这是论文最强的"为什么只用同机数据"论据**
