## 〇、出处与诚实性（2026-09-01 核实 ePrint 2026/279 原文）

**279 原文（Tabitha Ogilvie, "On the Concrete Hardness Gap Between MLWE and LWE",
ePrint 2026/279, 2026-02）实际给出的**：
1. **系数等距（coefficient isometries）攻击**：2 的幂分圆环中使系数向量发生带符号置换
   的环元素乘法，保持秘密/误差分布不变 → 派生样本与原样本共享公开矩阵，
   与 primal/dual hybrid 攻击的离线预处理兼容
2. **对稀疏秘密 RLWE（FHE 常用参数）**：等距 hybrid 相比 LWE 等价估计
   **最多 15 bit 的间隙**（论文摘要原文数字）；对 Kyber/ML-KEM 一致 2–3 bit
3. 结论：2 的幂分圆环上 MLWE≠LWE 等价性失效

**279 没有给的（不能归于 279 的部分）**：

- ✗ 没有说 +11

**结论**：σ+15 是最坏情况上界。实际差距仅 0.77–6.15 bit（逐集不同）。

- 论文应报 σ+11（统一、紧凑、可辩护）而非 σ+15（过度保守）
