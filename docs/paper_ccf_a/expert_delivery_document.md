## 1. 背景与问题

摊销自举一次刷新 n 条消息（MS18→GPV23→686）。686 用 MPmul（逐位
CMUX/NCMUX 蝶形）把同态解密 b−a·s 化为 O(h·n·logB) 次外积，钥缩回
MB 级，是唯一公开实现。遗留三个问题：
(P1) **安全**：CRYPTO'26 环同构混合攻击（279+366 合并）使稀疏密钥
参数需系统性重校准（686 原参数 h=39 → 我们实测 124.5 < 128）；
(P2) **吞吐结构**：重复标量执行浪费可共享的计算（掩码演化/分解/谱
变换），矩阵形式（Mul-LWE/Mul-GSW）可一次服务 r 条 lane，但缺稀疏
小钥域的完整适配与可证正确性；
(P3) **参数耦合**：安全修正（σ、h、KS gadget）与速度/精度域的联动
缺少闭环方法。

## 2. 算法（四层架构，T1 形式化）

```text
L1 调度层   686 蝶形（per-bit wrap/direct）+ DualSubCMUX 双亚共享（k=2 拓扑上限）
L2 结构层   PVW_TMLWE 多体（共享掩码，1+r 分量）× 对角 MAT_TRGSW（Mul-GSW）
L3 核算术层 抽象契约 ⊡：φ_q(M⊡c)=m'_q·φ_q(c)+ε_q —— 两种可证实现：
           (a) 标准 gadget 分解核（Bg=2^23）；(b) SQ 尺度量化核（Q=2^q）
           统一族：标准核 ≡ SQ(q=23)；核选择规则 q*=max(p+10, 23−m_sec/2)
L4 工程层   7 融合旗标（SUB_DECOMP/DIRECT-DFT/COEFF_ONE_FAST 等；include-zero
           路径真实生效：1.5×，binary 路径 0 处引用——两口径分别报告）
```

**主算法 O1（Matrix-SAB）**：acc_j ← X^{b_j}·TV_j（r 体平凡测试向量）；
for t<h：MonomialMul^r（O2 蝶形，MatCMUX/MatNCMUX）→ SubA^r（O3 三分支：
binary 明文单项式 / ternary s_sign / 一般稀疏 sub_a_ga = 双多体自同构
+ MAT 外积，T4）；终旋；逐 lane 提取 + packing KS。
逐步相位不变量：φ_q(步(PVW)) = 步_scalar(φ_q(PVW))，全域 oracle 验证。

## 6. 否定性结果与勘误史（可信度章节）

1. F1/δ=2 多比特调度：正确性门全 Pass 但实测 1.38–1.58× 慢 → 暴露
   T2 种子公式的分解共享建模错误（形式 A 无共享）→ 修正胜利条件
   DFI>2(1+r)A → G3 失败关闭（资产保留：G1' 检查器 + 修正模型）；
2. C5 联合 packing：尾声份额 FINAL 实测 3.0% < 15% 门 → 关闭
   （stage322 时代 38% 为过时配置）；
3. σ 单旋钮硬化双败（SQ 与 stock 同时失效）→ σ+KS 联动闭环；
4. **M3 勘误**：行账漏 (k+1) 因子，上限 1.25×→1.6×（stage380 实测
   触发）；所有下游引用同步更正；
5. 数字演变对照表十家族定稿（1.48× 幽灵清除、口径反转、双录单源化）。
