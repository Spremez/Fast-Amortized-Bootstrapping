### 关键发现

1. **公平点 SQ 优势在全部 Pass 集上保持**：0.891–0.989（中位 ~0.92），比原 h 的 0.893–0.968 略有收窄（公平 h 增大后两方案同担 +8% 外积成本）
2. **5-bit 集（SET_4_5_2048）每 bit 最低**：1.19 ms/bit（SQ，公平安全）
3. **大 N 集优势收窄**：8192 集比值 0.989 接近平价——分解消除在更大环上的占比更小
4. **探针精度适配是下一优先级**：6/10 集完整数据已足够论文主表，4 个集修复后补充
