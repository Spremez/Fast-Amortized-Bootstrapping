## 0. 分层架构与内外层边界（本工作的坐标系）

四层正交分解（每层可独立替换，层间以消息路径精确性衔接）：

| 层 | 回答的问题 | 当前实例 | 归属 |
|---|---|---|---|
| L1 调度层 | 单调位移 v 如何拆成选择子事件序列 | 686 蝶形（per-precision-bit，wrap/direct 两段）+ DualSubCMUX（k=2 拓扑上限已证） | **外层（本工作设计空间，§2）** |
| L2 结构层 | 一次外积服务几条 lane | PVW_TMLWE 多体（共享 mask，Mul-LWE/1711 Vec-MLWE 形式）+ 对角 MAT_TRGSW | 内层形式来自 1711（本团队前作）；稀疏域适配/定案为外层贡献 |
| L3 核算术层 | 外积内部怎么乘 | (a) 标准 gadget 分解外积（Bg=2^23, l=1）；(b) **SQ 尺度量化**（Q=2^q，量化→整卷积→重缩放，消除操作数分解；亦源自 1711） | (a)=686 原语；(b)=1711 内层核 |
| L4 分解工程优化层 | 标准 gadget 分解怎么算得快 | pathA 7 旗标（SUB_DECOMP 融合/direct-DFT/批量分解/clear-elision/DualSubCMUX 实现等） | 工程层，语义不变 |

关键澄清（回答 2026-09-04 用户问题，正式入册）：

- **SQ 与矩阵外积是两个不同层的算法，正交且可组合**。矩阵外积（L2）改的是
  密文结构与批处理（一次事件服务 r lane）；SQ（L3）改的是单次外积内部的
  算术（消除操作数 gadget 分解）。组合实例已在库中：`sab_pvw_sq.c` = SQ
  语义跑在多体路径上（SQ r-lane，stage371 实测与矩阵基线平价 1.004–1.016，
  门全 Pass）。四个构建组合：686 标量 / SQ 标量 / 矩阵基线 r-lane /
  SQ r-lane（+ pathA = 矩阵 + L4 旗标）。
- **SQ ≠ PPT/686 的"gadget 分解"**。0904 PPT 第 3-10 页仅有的两处"分解"
  指 **BSK 对 d[i] 的逐位 GSW 加密**（密钥结构），其外积是标准 gadget 分解
  外积并作为黑盒原语使用。SQ 是替换该原语算术的 1711 内层核：消息路径
  精确（定理 1），噪声系数 σ·2^{q+3.5} vs 标准 σ·2^{27.1}（q=16，实测
  2^{q+3.5} 标定）。L4 的分解融合旗标优化的是标准机制的计算顺序，语义
  与噪声结构不变——与 SQ 的"消除分解"本质不同（E-PF 实测旗标近乎免费，
  但 SQ⊕全旗标构建不兼容，已作否定性结果入册）。

外层设计空间 = L1 全部 + L2 稀疏域适配深化 + L3/L4 的选择与组合策略 +
尾声与噪声/精度域管理。以下按 D1–D4 展开。

## 1. 现状基线（可替换项的锚点）

- L1：`sab_pvw_RGSW_monomial_mul_state`（sab_pvw.c:861）：ρ 位 × n 槽蝶形，
  每位 2^i 个 NCMUX + (n−2^{i+1}) 个 CMUX；M3 行积定律给每输出乘法数上限
  (1+1/r)×（r=4 结构上限 1.25×，实测 1.21×）。
- L2：PVW_TMLWE(k=1, 1+r 分量)；BSK=(h+1)·ρ 个对角 MAT_TRGSW + 1 多体
  aut-KS；FINAL h=42/t=7/σ_G=2⁻⁴⁹ 定案（stage371 全量闭环）。
- L3：stock（gadget Bg=2^23）与 SQ(q=16) 双核，实测：标量 686/SQ=1.117×，
  r-lane 内两核平价；SQ 域 p≤5@q16（定理 3）。
- 尾声：逐 lane 提取 + 逐 lane packing KS（O(r) 尾，未摊销）。
- 缺口：G-ρ（ρ-SAB 矩阵分支未接入）；ternary 矩阵缺 FINAL 性能数据；
  调度最优性无形式化。

## 2. D1 调度层（外层核心创新区）

### 2.1 形式化框架（先立问题）

调度实例 = (n, ρ, v_t 的位模式, r)。调度 Σ = 事件序列，每事件 = 一次
MV-EP（服务 r lane）。目标函数（M3 约束下）：

```text
minimize  Rows(Σ) = Σ_events (1+r)·ℓ          # 行积（乘法数）
s.t.      Σ 实现 MonomialMul 语义（每位移 v 的同态乘）
          每事件 wrap 源的 τ₋₁ 由多体自同构承担
```

686 蝶形是 radix-2 解：ρn 个事件。**开放问题 Q1**：行积意义下 radix-2
是否最优？已知上界工具：M3（(1+1/r)/输出）、DualSubCMUX k=2 拓扑上限。
待做：radix-δ 的一般行积公式 + 下界论证（换位/直达槽比例的信息论或
代数下界）。

### 2.2 候选 C1：F1 的 δ=2 多比特矩阵 CMux（radix-4 步）——已立项

- 机制：每步消化 2 个位差 bit（四路选择 B⁺/B⁻ 选择子族，环绕行存 τ₋₁
  变换版），FFT 域自同构融合（hoisting）。事件数 ρn → ρn/2。
- 行积账（投影，须推导定稿）：每事件选择子行 4 路 vs 1 路；操作数分解
  仍 (1+r)ℓ 行/事件；总行积 ≈ (ρn/2)·[(1+r)ℓ·(共享度) + 4ℓ 选择子行]——
  选择子行是预计算 DFT（密钥侧），热路径只增加每事件 4 次点乘累加 vs
  2 次事件各 1 次——**净效应取决于行积公式，为 G3 的核心推导义务**。
- 已有资产：G1 引理 F1-1 机器验证通过（`scripts/check_f1_empmul_equivalence.py`，
  160 项，δ=2 步 = 两单 bit 步复合，GF(257) 精确）。
- 立项门（继承 f1_mat_empmul_theory.md §6）：
  - G2 噪声门：四路和中 3 项 0-选择子外积的噪声上界推导 + 与 M2 对账
    （预测/实测 <1.3，参照 Stage331 口径）；
  - G3 Amdahl 门：完整自举投影 ≥ 矩阵基线 +30%（同构建口径）；
  - G4 资源门：钥 ≤2.5× 标量（四路钥匙 ≈2× BSK，仍远低于 BatchBoot
    3.2–3.5×）；RSS 预算核算。
- 与 L3 组合：δ=2 步在 SQ 核上的语义（SQ 单数位 ⇒ 四路选择子直接
  Bg_bit=q 采样，无需分解融合）——理论上有简化红利，列为 C1 的子项。

### 2.3 候选 C2：mixed-radix / 位段自适应 radix

- 依据：位差 d[i] 高位段稀疏（B=O(n/h) 的间隙条件），高位 radix 可更高、
  低位保守；t-ρ 耦合轴（stage E1 发现）提供钥分布自由度。
- 义务：radix-δ 一般化的 G1 检查器扩展（δ∈{2,3}）+ 行积公式。
- 优先级低于 C1（先证 δ=2 再谈自适应）。

### 2.4 候选 C3：跨位选择子行/操作数分解共享

- 现状：SUB_DECOMP_DFT_DIRECT 已缓存操作数分解的 DFT；推广 = 同一
  MPmul 内跨位共享（同一槽 j 的 c_j 在多位间复用分解）。
- 义务：共享条件的代数刻画（哪些位的操作数谱可复用）+ 缓存失效分析。
- 与 M3 交互：不减事件数，减每事件分解行——作用于 (1+r)ℓ 因子。

### 2.5 候选 C4：wrap/direct 槽比例下界（理论项）

- 现状：每位 wrap 槽 2^i 个，累计 ≈2^ρ=B；direct 槽 n−2^{i+1}。
- 义务：证明（或反驳）任何正确调度的 wrap 事件数下界 ≥ Ω(B)——
  若成立，则 NCMUX/自同构开销不可调度消除，DualSubCMUX 已达 k=2 上限
  的结论从"共享减法"升级为"调度最优"。

## 3. D2 密钥—形式协同

### 3.1 G-ρ 立项：ρ-SAB 矩阵化（补齐 stage372 PPT 审计缺口）

- 语义（686 Alg 4）：每系数 k：Auto(c_k, −a_k^{-1}) → ⊙ V_i（系数选择子
  GSW(X^{s̃_j})）→ Auto(·, −a_k)。矩阵化 = 两次 `pvmtmlwe_eval_automorphism`
  + 1 次 MAT 外积；基础设施 aut_minus1 同族已有。
- 新义务：(i) 奇系数条件（a_k odd，mod switch 保奇）在多体下的复验；
  (ii) V_i 族（系数在指数上）的 MAT 物化——对角结构从"加密常数 bit"推广
  到"加密单项式 X^{s̃_j}"（`mat_trgsw_monomial_sample` 已支持 e≠0，主要
  工作在钥生成族与等价门）；(iii) 小规模 r∈{1,4} 逐步 oracle 等价 +
  噪声门（对照 sub_a_ga 标量）。
- 收益主张（投影）：矩阵路径获得"任意取值稀疏秘密"（Z₈ 等）完整语义
  （PPT 第 8 页三变体齐备）；安全上为 t-ρ 耦合轴提供更大钥分布空间。
- gate：等价 0 失配 + 噪声同阶（<1.3×预测）+ FINAL 参数一次 A/B。

### 3.2 支撑模式联合优化
