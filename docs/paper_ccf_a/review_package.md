## 二、SQ（尺度量化外积）算法详解与正确性

### 2.1 语义（`src/sab_sq.c`, `src/sab_pvw_sq.c`）

- 累加器维护在 **Q=2^q 尺度**（q=16）：torus 值 ×2^q 的整系数多项式，
  setup 量化 + 融合重缩放保证尺度不变量
- 选择子 TRGSW 以 **Bg_bit=q** 加密 → **gadget 分解被消除**（累加器本身即单一数位）
- 外积 = 原始 DFT（整系数谱）⊗ 选择子谱 → 融合 `(<<rescale)+addend` 尾声
- NCMUX：精确升移 `<<(64-q)` → 复用 stock 自同构 KS → 舍入降移
- 末尾 torus 提升（`sab_pvw_sq.c` 的 Q 尺度 setup 量化 + 最终提升）

### 2.2 Theorem 1（消息路径精确性）+ 证明骨架

**陈述**：`μ·2^{64-q} ⋆ c >> (64-q) = μ·c`（无回绕条件下精确）。

**证明骨架**（归纳于盲旋转调度步）：
1. 尺度不变量：每步后累加器系数满足 `|c|_∞ ≤ 2^{q-1}`（setup 量化与融合重缩放的
   舍入步共同维持；keygen/setup/assert 验证）→ 中间乘积不回绕 mod 2^64
2. 消息路径：整数卷积（spqlios 低字精确）在无回绕下对消息线性 →
   乘 2^{64-q} 再移位还原 = 恒等
3. 噪声路径：选择子噪声 e 以 ∆·e 进入（Lemma 1）
4. 归纳终止：ρ·(h+1) 步后累加器仍在 Q 尺度 → 末尾提升只含一次 q-bit 舍入

**证据闭环**：24/24 gate Pass（r=1/r=4 × 2 轮）+ 噪声不劣化实测
（57.60 vs 57.69，n=9，CI<1.5%）。

### 2.3 Lemma 1（∆ 抑制）与理论优势

**陈述**：选择子噪声系数 SQ=`σ·2^{q+3.5}` vs stock=`σ·2^{27.1}`；
∆=Q²/T=2^{2q-64}（q=16→2⁻³²）；**q 每降 1 bit 买 2 bit σ 余量**。

**优势三线**：
1. **速度**（标量）：消除分解 → SQ/686=0.897（三配置稳定），r-lane 平价（分解占比
   随 r 摊薄，收益 ∝1/r）
2. **噪声余量**：σ+15 后 SQ 噪声 59.36（预测≈59.1，±1 bit 内）——预测能力经三档 σ 验证
3. **结构性质**：σ 敏感项被压 32 bit → SQ 对 BSK 噪声解耦（平衡档实验实测：stock
   +0.9 bit 余量付 17%，SQ 零收益）

## 三、矩阵外积拓展的 686 自举算法（完整梳理见 pathA 文档）

**结构**（Algorithm 1/2，`src/sab_pvw.c` 逐函数对应）：
- 累加器数组：n=2048 个 **PVW_TMLWE**（1 掩码 + r 个体共享），选择子 **MAT_TRGSW**
  ((1+r)ℓ 行)，稠密矩阵外积一次更新全部体 → 一次盲旋转服务 n×r 个消息-LUT 查询
- **蝶形 MonomialMul**：按精度位 FFT 式旋转整个数组（换位槽 X⁻¹ 自同构 NCMUX、
  直达槽 CMUX；dual-sub：一对输出共享一次旋转+一次向量化双减）
- 调度：(h+1)·ρ·n = 43×7×2048 = 616,248 次矩阵外积（FINAL h=42）
- 尾声：每 lane 常数抽取 + packing KS + 共享 hw-KS
- 7 融合旗标（谱域驻留/双减共享/零数位跳过/r 特化核）——纯调度优化，噪声中性
  （stage359 实测：路径A 噪声 −6.601 vs stock −6.535，双 gate Pass，0/81920 失败）

**vs 686 scalar 的区别**（逐项表见 pathA 文档第三节）：共享掩码使一次分解/谱乘推进
r 个 LUT 体；外积计数不变但每 lane 摊销 ÷r；噪声逐 lane 等同 scalar（σ 不变性实测：
pathA/SQ 比值在 σ+0 与 σ+11 下同为 ~1.16）。
