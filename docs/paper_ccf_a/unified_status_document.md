## 6. Hom-Tr：需要你确认的 8 个精确问题

### 背景

我们的朴素自同构实现**语义错误**（独立 agent 已证明：自同构 σ_w(X^i)=X^{wi}
置换指数 ≠ 单项式乘法 M_v(X^i)=X^{i-v} 移位指数；f=1 反例）。正确 Hom-Tr
的参考变体已被独立 agent 推导（固定子群 H + 交织打包 + 迹提取 + 模数消耗）。

### 8 个问题

1. **αⱼ, α∨ⱼ, βⱼ 的环归属**：分别属于哪个环/张量因子？对偶基是迹配对对偶、内积对偶还是 CRT 幂等元？
2. **Hom-Tr 的类型**：是绝对迹、相对迹还是广义线性变换？源/目标环、trace subgroup、密文/密钥输出类型分别是什么？
3. **βⱼ 进迹的条件**：βⱼ 与旋转单项式为何可放入迹内？由哪个固定子环条件或独立张量因子保证？
4. **归一化**：迹是否含 1/r 因子？若含，在二幂 torus Q=2^64 上如何实现？有无模数/尺度消耗方案？
5. **Algorithm 2 第 8-11 行的变量**：应更新 c_k 还是 c_i？Hom-Tr 的返回值赋给谁？
6. **P-MPMUL 起始位**：最低位为何从 i=1 开始（而非 i=0）？v 的位重、边界上标 (−1)、Y 矩阵和 n/B 的关系？
7. **h 的定义**：diff(s) 的 h 是支撑大小、差分项数还是别的量？Algorithm 2 的 h 约束是否为排版错误？
8. **安全覆盖**：参数与噪声证明是否覆盖中间 KS 密钥和相同评估钥的重复使用？

### 独立 agent 推导的参考变体（供你校验）

```text
环分解：N = r·d，Y = X^r，A = Z[Y]/(Y^d+1)
打包：  m = Σⱼ X^j · mⱼ(Y)
目标：  L_a(m) = Σⱼ X^j · Y^{-aⱼ} · mⱼ(Y)
固定子群：H = {σ_{1+2dℓ} : 0 ≤ ℓ < r}  （不随 a 变化）
迹提取：T_H(X^{-j}·m) = r·mⱼ(Y)
整数版：U_a(m) = Σ_{w∈H} P_w·σ_w(m) = r·L_a(m)
       P_w = Σⱼ X^{j(1-w)-r·aⱼ}   （公开权重多项式）
Torus r^{-1}：预置 Q_in = r·Q_out，每步消耗 log₂(r) 模数比特
```
