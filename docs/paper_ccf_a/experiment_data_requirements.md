## 3. 公平性与一致性检查单（论文 §7 必须逐条声明）

1. **同机构建内对照**：一切加速比 = 同二进制内两臂（已有纪律）；跨构建
   漂移 −7~−23% 的证据入附录；
2. **安全口径统一列**：每行附 λ（估计器 + 攻击组合），并在对比表中为
   竞品换算/标注其口径（尤其 BatchBoot 的 MITM-dual-hybrid λ 与
   CRYPTO'26 稀疏钥修正的关系——A4 核对结论决定措辞）；
3. **摊销口径统一**：ms/消息（scalar）与 ms/消息/lut（r-lane）分列，
   r 语义声明（独立 LUT lane）；
4. **失败概率同预算**：统一 2^{-x} 列 + erf 公式 + 经验 Clopper-Pearson
   上下界注记；
5. **钥尺寸同范围**：含自同构钥（686 脚注口径）；压缩变体（种子扩张）
   可作可选列（1711 口径）；
6. **重复与统计**：≥6 试均值 + 离散度（已有），环境负载门控声明；
7. **编译器/后端敏感性**：spqlios vs spqlios_avx512 分离声明
   （stage8 已有方法论）。
