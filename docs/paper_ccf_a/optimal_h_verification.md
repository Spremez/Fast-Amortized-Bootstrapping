# h=39 + σ+11 最优性的严格验证计划（2026-08-31）

## 重要澄清：两个独立的安全维度

我们之前混淆了两个不同的安全参数：

| 维度 | 参数 | CRYPTO'26 攻击对象 | 修正方式 |
|---|---|---|---|
| **A: 输入密钥安全** | (n=2048, h, σ_in=2^-15) | ✓ 是 | 增加 h 或 σ_in |
| **B: 自举密钥安全** | (N=2048, h_out=512, σ_out) | 否 | 增加 σ_out |

**我们的 σ+11 修正只影响维度 B（自举密钥），不修复维度 A（输入密钥）。**

CRYPTO'26 攻击的是维度 A。要修复维度 A，必须增加 h。
