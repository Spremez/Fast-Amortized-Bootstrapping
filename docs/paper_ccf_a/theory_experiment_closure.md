## 一、SQ 尺度量化外积的理论-实验闭环

### Theorem 1（消息路径精确性）

| | 理论主张 | 实验证据 | 闭环状态 |
|---|---|---|---|
| 陈述 | `μ·2^{64-q} ⋆ c >> (64-q) = μ·c`（无回绕条件下精确） | 24/24 gate Pass（r=1: 0/16, r=4: 0/64, 各×2 轮） | ✓ **闭环** |
| 条件 | `|c|_∞ ≤ 2^{q-1}` 确保中间值不回绕 | 累加器 Q 尺度由构造保证（keygen/setup/assert） | ✓ **闭环** |
| 推论 | 消息零舍入 → 噪声不劣化 | 噪声持平（57.60 vs 57.69, n=9, CI < 1.5%） | ✓ **闭环** |

### Lemma 1（∆ 抑制 / σ 项系数）

| | 理论主张 | 实验证据 | 闭环状态 |
|---|---|---|---|
| σ 项系数 | SQ: `σ·2^{q+3.5}` vs stock: `σ·2^{27.1}` | 定量验证：σ+15 后 SQ 噪声 59.36（预测 ≈ 59.1） | ✓ **定量闭环** |
| 抑制因子 | ∆ = Q²/T = 2^{2q-64}，q 每降 1 bit 买 2 bit σ 余量 | q=16: 2^{2·16-64} = 2^{-32}（吸收 15 bit 后噪声仍 Pass） | ✓ **闭环** |
| 预测能力 | 给定 (q, σ) 可预测盲旋转噪声 | 三个 σ 档（2^-50, 2^-35, 2^-50+15）的噪声均在预测 ±1 bit | ✓ **预测验证** |

### 否定性结果（理论排除 + 实验确认）

| 主张 | 理论论证 | 实验确认 | 闭环 |
|---|---|---|---|
| σ 单旋钮不可行 | KS 噪声 ∝ σ·2^{Bg}，~140 次/slot | SQ/stock 双败（63.0/62.04） | ✓ |
| ¼ 谱域预缩放不可能 | `\|F\|·\|U\| ≈ 2^{125}` ≫ 53-bit 尾数 | 偏差 2^{62.81}（纯垃圾） | ✓ |
