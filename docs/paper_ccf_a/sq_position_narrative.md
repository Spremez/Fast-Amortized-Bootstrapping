## 1. 界面抽象：外层算法对核算术层只有一个契约

矩阵自举的外层（调度、结构、尾声）对"外积怎么算"只有一个接口契约：

```text
原语 ⊡：给定 Mul-GSW 选择子 C（加密对角消息 m'）与 Mul-LWE 操作数 c，
       输出 C ⊡ c 满足
         φ_q(C ⊡ c) = m'_q · φ_q(c) + ε_q     （M1，逐 lane 相位作用）
         ‖ε_q‖ 有多项式界，常数由核决定        （M2，无跨体放大）
```

凡是实现该契约的核都可插入。**外层算法本身不包含 G⁻¹，也不包含量化——
这两者都属于 L3 核算术层的两种可选实现。**

## 2. G⁻¹(c) 与 SQ 的关系：同一槽位的两种机制，非并列算法

**G⁻¹ 为什么存在**：标准外积要把"加密的乘子 m"作用到 c 上，同时把选择子
噪声的放大系数压在多项式界内。做法 = 把 c 的每个分量**数字分解**（提取
≤Bg 的小数位），用小数位去乘 gadget 缩放的选择子行。分解不是优化，而是
标准核中**噪声有界的使能机制**；矩阵化只是把分解对象从 k+1 个分量扩展为
k+r 个分量（1+r 行），机制本身未变。

**SQ 为什么可以不做分解**：SQ 更换的是**操作数的表示不变量**——累加器
全程维护在 Q=2^q 尺度（系数为 |·|≤2^{q-1} 的小整数）。操作数本身已经
"小"，噪声有界的职能由**尺度量化本身**接管：乘子对选择子噪声的放大系数
从"数位 ≤ Bg"变为"操作数 rms ≤ 2^{q-1}"，噪声系数 σ·2^{q+3.5}（q=16）
vs σ·2^{27.1}（Bg=2^23）。计算结构变为：整数卷积（mod 2^64，无回绕不变量
保证）→ 一次融合重缩放（>> 64−q）。消息路径**逐系数精确**（定理 1：
消息项低 64−q 位为零 ⇒ 所有 R_q 恒等，舍入只进误差项）。

**两者的精确数学关系**：l=1、Bg=2^23 的标准核就是 SQ 家族在 q=23 处的
成员——数字提取 ≈ 隐式 q=23 量化（每次外积对满 torus 破坏性执行），
gadget 尺度 h_0=2^{41} = SQ 的消息尺度 2^{64−q}；两噪声公式在 q=23 处
一致（sq_theory_rigorous 定理 2 已核）。SQ 的三步推进：

1. **显式化**：量化从"每次外积的隐式数字提取"变为"全程维护的尺度不变量"；
2. **参数化**：q 与 Bg 解耦成为自由设计旋钮（受 p 域与 σ 需求双约束）；
3. **可证明**：消息路径精确性（定理 1）+ σ_G 系数推导（定理 2）+ p 域
   闭环（定理 3，p≤5@q16 实测边界）。

一句话：**G⁻¹ 是标准核的噪声有界机制；SQ 用尺度不变量接管同一职能，
从而消除分解这一步。二者是同一契约下的两种核，不是两个层。**

## 3. SQ 对整个矩阵自举工作的地位与贡献（四条，按重要性排序）

### 3.1 安全硬化使能者（不可替代的贡献）

CRYPTO'26 稀疏密钥混合攻击修正下，系统需在 ≥128 bit 约束下恢复参数。
SQ 的 σ 余量 2(23−q) 是唯一实测可行的吸收通道：

- 否定性结果（命题 2.7，实测）：σ 单旋钮对 SQ 与标准核**同时失效**
  （KS/自同构噪声 ∝ σ·2^{Bg_ks} 线性放大，每槽 ~140 次 aut-KS 累计）；
- 正面闭环（σ+KS 联动，实测）：σ_out+15 时 SQ 通过（门 0 失配）而标准
  核失效；FINAL 定案（h=42/σ_G=2⁻⁴⁹，stage371 全量）下 SQ 标量
  **686/SQ = 1.117×**，噪声仅 +0.08 bit；
- 对照：若无 SQ，标准核只能靠 h 上调（h=52 平衡层实测 r-lane +17% /
  标量 +32–45%，且 σ 收益归零——stage363）。

**定位：SQ 使"修正安全下的快速矩阵自举"成为可能——这是整个系统在
≥128 bit 口径下仍然快于 686 的原因。**

### 3.2 速度（次要、诚实的主张）

- 标量：内核消除分解通道，−4.5%~−7.3%（9 轮中位/min），全自举 1.117×；
- 矩阵 r-lane：分解已被矩阵批处理共享（1+r 行），SQ 边际收益归零
  （实测平价 1.004–1.016）——如实声明，不作为矩阵侧速度主张。

### 3.3 理论贡献（"prove" 的一半）

1711（本团队前作）给出尺度化外积思想；本工作在稀疏摊销 SAB 语境下
实例化并补全可证性：定理 1（消息路径精确性——NCMUX 蝶形调度下逐原语
归纳，此为 1711 未覆盖的调度形态）、定理 2（σ_G 系数闭式，实测标定
2^{q+3.5}）、定理 3（无回绕不变量与 p 域）。口径：instantiate/adapt/prove
+ 作者重叠披露。

### 3.4 适用域边界（诚实边界，本身是结果）

SQ@q16 的舍入地板 2^{−56.6} 使 p≥7 失效（stage369 实测 46/2048 失配 +
定理 3 闭环）；标准核仍是 p≥7 的回退。SQ 与标准核是**互补域**而非替代：
外层算法按消息精度选核（设计文档 D4/C6 的混合核调度即此边界的利用）。
