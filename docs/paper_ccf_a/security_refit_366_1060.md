**实现侧新发现（此前所有安全分析未覆盖）**：
- **F1 条件分布**：输入密钥 = 均匀 h-子集 **条件于 max-circular-gap ≤ B**。T3 界用的
  log₂C(n,h) 是**无条件熵 → 高估安全**。B 越紧熵损失越大（我们的 B=128 远紧于外部框架的 N/4=512）。
- **F2 交替三元符号**：输出密钥（h_out=512）与 packing 的三元符号按生成次序交替，
  符号熵 ≈ 1 bit 而非独立符号的 h bit。1060 恰好攻击稀疏三元 → 这些层必须按真实分布重估。
- **F3 探针间不一致**：probe_sq 的 packing 是三元 h=256，probe_pvw_sq 是二值 h=256 —— 需按 686 规格统一。

### 保留意见（有理由，非拒绝）

1. **其 h=52≈152 bit 与我们 h=41≈131.75 bit 不矛盾**：不同攻击层（279-H2 格侧 vs 我们
   T3 组合侧），组合 min 下各自在不同 h 处成为瓶颈。其平衡档预留 ~20 bit 是给未整合的
   366/1060 的**占位余量**；我们的 h=41+σ+11 是**最小修正点**。两者都是 Pareto 候选——
   E2 实测平衡档的代价（预期 ~+26% EP 计数），不预设谁优。
2. **SQ 部分解耦三难**：外部框架的 ρ-方向论证假设 686 型噪声耦合（σ_G 进主导项）。
   SQ 的 ∆ 抑制使 σ_G 项被压 32 bit——对 SQ 而言 h↑ 的代价近乎纯速度、噪声几乎不动。
   这是我们的结构性优势，框架未覆盖，论文应明确写出。
3. **工作量代理（1.47–1.84×）不采信**：直接实测（stage363）。

### E1 结论
1. **686 原参数 h=39 在正确条件熵建模下 T3′=124.5，本就不达标**
   （此前"128.13 边缘"因未计条件熵而偏乐观 3.6 bit）。
2. **h=41@t7 余量从 3.75 缩至 2.5 bit**——在 366/1060（E4）未整合前偏薄，降级为"最小修正"。
3. **h=42@t7 上位为推荐**（133.5 @ 1.07×）：h=42 的全套实测已在手
   （标量 13.3s、SQ 噪声 57.46、stock 58.66）；r-lane h=42 是唯一小缺口。
4. **(t, ρ) 耦合是新显式 Pareto 轴**：放宽 t 消条件熵损失但抬 ρ（h=41: t8 零损失换 ρ=8/+14%）。
5. 4096 参数集（h=32@t8）组合层 117.5 + 接受率 0.03%——686 该集需要重新设计。
6. **交替三元符号**：组合层 822.9 bit（交替）仍 ≫ 格层 117–128 → 绑定层不变，
   但论文必须如实报告分布（1060 以稀疏三元为目标）。
7. **确定性 RNG 种子巧合**（数据解释警示）：固定种子下所有 run 接受同一首个候选密钥
   （h=52 恰为 distance 7）——stage363 的 rp=9 时间读数对应 ρ=7 密钥，
   全新部署密钥在 t=9 下典型 ρ=8（+14%）。所有"平衡档 t=9"计时需此标注。
