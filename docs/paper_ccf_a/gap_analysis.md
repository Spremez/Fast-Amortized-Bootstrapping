```c
size_t key_bytes(SAB_SQ_Key sq) {
  // selectors: (h+1)·ρ 个 TRGSW_DFT, 每个 4 polys × N × 8B
  // aut KS, packing KS, HW KS keys
}
```
**预期数字**：686 自报 ~18-150MB（参数集不同），我们 h 修正后 +~8%
**工作量**：0.2 会话（代码 + 运行时打印）

### P0：失效概率（欧密必须项）

**理论**：从噪声 log2 和消息预算计算
- 噪声 57.6，预算 60 → 余量 2.4 bit → p_fail ≈ 2^{-2.4} ≈ 0.19?? 太大
- 但这是 **max** 偏离，不是 σ。实际 σ 更小 → p_fail 更小
- 需要用多 trial 统计：跑 1000 次自举，数失败次数

**实测**：在 probe 中加 counter，跑 N 次统计 mismatch
**工作量**：0.3 会话（代码 + 服务器运行）

### P1：内存占用（RSS）

**方法**：`/usr/bin/time -v ./probe_sq.exe` 取 Maximum resident set size
**工作量**：0.1 会话（一条命令）
