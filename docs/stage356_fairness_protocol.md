## 三、公平点推导（消费理论线数字）

- SET_2_3_2048 输入密钥 = 理论线 B1（n=2048, h=39, σ=2^-15, δ=7.37）：纯组合 T3 天花板 128.13（贴 128 线，−0.77 vs 686 声明 128.90）；279 Table 8 估计器档（MitM-H2，含格约减成本）把 686 全族压到 117.3–122.4。
- **公平点 h=42**（= B2 重量，n 不变）：T3 天花板 +8.4 bit（(291.48−274.64)/2），按 MITM 档 λ≈(H−损失)/2 的标度恰好覆盖估计器档 6.7–10.5 bit 的亏空 → 两方案（SQ 与 stock scalar）同在"估计器档 ≥128"的保守公平点上实测。
- **锚点 h=39**：T3 组合档 128.13 的原点，1 轮连续性对照。
- 注：h↑ 使两方案外积数同增 ~8%（(h+1)·ρ·N 标度），绝对时间变慢、比值预期保持——这正是公平对比的意义：**同真实安全级下比速度**。σ 侧（输出密钥 2^-50）两方案相同，不动。
